# The Eroticization Operator — phase 0

Question: is "sexual" a content category, or a value operator applied to ordinary
world-representations? Private curiosity project. Not for publication.

Phase 0 uses the Big Kink Survey public subsample (Zenodo 10.5281/zenodo.18625141,
15,503 respondents x 365 columns, heavily binned + noised) to ask what can be settled
with data that already exists, before any new collection.

Env: self-contained `.venv` (python 3.14, pip bootstrapped via get-pip; system python
has no ensurepip). Data not committed — `src/` re-downloads it.

Pipeline: 00 schema -> 01 inventory -> 02 explode multiselects -> 03 branching ->
04 reliability ceilings -> 05 options -> 06 residual spectrum -> 07 transfer ->
08 CCA+rarity -> 09 agent/patient -> 10 axis prediction -> 11 role variance ->
12 placebo contrast.
