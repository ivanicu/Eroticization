# `E02·A12·R670` — 七张性严厉度码表的人工普查

**行动类型:FRONTIER(换方向,回到对象)**。无脚本产物 —— 本轮是**人工普查**,
理由是 `#618` 已证明三个自动搜索版本的正对照全部失败,**它们的零不可采信**。

**判据在读之前定死**:一张量表带有「对谁」,当且仅当**它自己的码**区分 ≥2 种**对象**类别 ——
不是行为者性别、不是谁承受惩罚、不是情境。
**正对照**:同一条判据施加在暴力三题上说「有」⇒ 它不是一条只会说「没有」的判据。

**结果:七张,零张。** 而普查查出了更锋利的东西:
`SCCS959` 记录乱伦禁忌延伸到哪些亲属 —— **「对谁」确实存在,只是从没和严厉度乘在一起**;
`959 × 960` 同时有值的社会 **25** 个。
