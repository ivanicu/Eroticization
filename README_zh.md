> ### 这一切到底有多大?(`#264`,先读这一段)
> 这个项目建立的**每一个**人层维度,**放进同一个模型**去预测同样那 29 个结局,
> 联合解释的**中位是 1.4%** —— **最好的一格 7.8%**(`animated`),**羞耻 2.8%**。
> 自由度地板是 **0.14%**,而同一条管道在加入一个故意做强的预测量时能到 **49%** ——
> 所以仪器不是瞎的,这些维度也不是噪声:它们是真的、可复现的、跨仪器的、控制过的,**而且它们很小**。
> **两种读法这段话不支持。** 它**不**意味着这些发现是空的(地板是 0.14%,每个维度都过了自己的全族阈值);
> 它也**不**意味着性偏好基本随机 —— **1.4% 是这六个坐标的射程,不是可解释性的上限**。
> ⚠ 另外注意排序:**最不可靠**的那个仍站着的维度(位置分,0.432)贡献了**最大**的增量 R²(0.715%)。
> **信度与解释力是两回事 —— 一个量可以稳定地测到一个几乎不影响任何事的东西。**
> ⚠ **`#301` `#302`:**样本内 1.4% / 样本外 0.87%**。留出来算 —— 5 折人层交叉验证,**六个坐标在每一折内部重估** ——同一条流水线的中位是 **0.869%**;坐标固定时是 1.087%,岭+CV 是 1.056%。29 个结局里有 **2 个的留出 R² 为负**。**已发表数字的三分之一以上是拟合。**估计量是 [`CALIBER.md`](CALIBER.md) 里最大的单个旋钮(**0.52pp**,而每一个分析旋钮都不超过 0.18pp)。两个数都合法,而且回答的不是同一个问题 —— 1.390% 是这六个坐标在**建造它们的那批人**身上解释了多少,0.869% 是它们交到**从没见过的人**身上时兑现多少。

## 被分离的三个模型

Ivan 的原始框架,逐字保留,因为整个仓库都被它划定范围:

| | |
|---|---|
| **A** 专用性内容系统 | `Y_i(s) = f_i(h_sex(s))` —— 「性」是一个内容类别,像视觉里的*人脸* |
| **B** 对普通表征的情欲估值 | `v_i(s,c,t) = w_i(c,t)^T h(s)` —— 普通场景,施加其上的一个读出 |
| **C** 递归混合 | 价值回流,重塑它作用过的那个表征 |

> ### 三个模型现在的处境(`#234c`)
> **B 已死**(`#179`:位置不是一个不带立场的坐标 —— 它带着羞耻)。
> **C 唯一可分的预测没有支持**(`#234a`:按羞耻分层、匹配勾选数,宽度剖面的两半复现是
> **0.4672 / 0.4611 / 0.4718** —— 平的,而这个设计的正对照在比 C 所预测的小 **7.4 倍**的梯度上就能点着)。
> **但诚实的读法不是「A 赢了」。** 这份数据里最可靠的人层结构 —— 分半信度 **0.56–0.72**,
> 远高于位置分的 0.432 —— 是**一个人在哪些领域敞开、以什么形状敞开**(`#229`–`#232`)。
> **A、B、C 三个都没有预测它**,因为三个问的都是「什么使一样东西成为性的」,
> 而它是关于**这个人**的事实,不是关于刺激的。
> **A/B/C 这个分解没有沿着这份数据的关节切下去。** 这是关于**分解是否完备**的主张,不是对 A 的证伪。

## 共享信号是怎么累积的

**[RETRACTIONS #60]** `增量 = 0.00723 × √(源领域数)` —— 跨 n=1…31 的 CV **6.4%**,
对数形式 11.2%、线性形式 51.9%(`#60`),而置换标签的零在每一个 n 上都恰好是 0.0000。
**[机制被反转 —— #61、#64]** 块**不是**可互换的(子集方差是种子方差的 58 倍),

累积跟踪的是**总样本量**,不是块数 —— 那个 √ 形状就是普通的 √N。
块边界是对估计的一道税,不是它的来源。新采集的价目表:
0.06 需要 69 个领域,0.08 需要 122 个,0.10 需要 191 个 —— 已外推出实测范围。
