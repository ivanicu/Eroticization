## 被分离的三个模型

Ivan 的原始框架,逐字保留,因为整个仓库都被它划定范围:

| | |
|---|---|
| **A** 专用性内容系统 | `Y_i(s) = f_i(h_sex(s))` —— 「性」是一个内容类别,像视觉里的*人脸* |
| **B** 对普通表征的情欲估值 | `v_i(s,c,t) = w_i(c,t)^T h(s)` —— 普通场景,施加其上的一个读出 |

> **C 唯一可分的预测没有支持**(`#234a`:按羞耻分层、匹配勾选数,宽度剖面的两半复现是
> **0.4672 / 0.4611 / 0.4718** —— 平的,而这个设计的正对照在比 C 所预测的小 **7.4 倍**的梯度上就能点着)。

> 远高于位置分的 0.432 —— 是**一个人在哪些领域敞开、以什么形状敞开**(`#229`–`#232`)。
> **A、B、C 三个都没有预测它**,因为三个问的都是「什么使一样东西成为性的」,
> 而它是关于**这个人**的事实,不是关于刺激的。
> **A/B/C 这个分解没有沿着这份数据的关节切下去。** 这是关于**分解是否完备**的主张,不是对 A 的证伪。

# 第二台仪器,以及它定下的一件事

上面所有内容来自一份问卷。2026-08-05 加入了两份公开数据,好让一个说法能被一台**不共享方法**的
仪器追问:**GSS**(美国概率样本,1972–2024)与 **SCCS**(186 个被民族志编码的社会)。
两者都不能被推动;都是照原样读的。

**在美国,对色情的谴责崩塌了,而它标记的那道差距一动没动。** 25–54 岁成年人里,
认为色情应对所有人非法的比例在 30 次调查中从 **0.38 掉到 0.18**。而谴责者与非谴责者在
**自报**过去一年看过 X 级影片上的对数优势差,1973–1988 年是 **−1.34**,2006–2024 年是 **−1.44**:
**Δ = −0.10,95% CI [−0.29, +0.09]**,而**最小可检出效应是 0.27** —— 一个真正要紧的位移(0.5)
本会被看见,而它没有出现。在 36 格网格上(3 个年龄带 × 3 种时代宽度 × 2 个统计量 ×
含/不含 2021 年起的施测方式变更),**35/36 格同号,3 格超过 MDE、全部落在 35–64 岁带**,
方向是差距**略微变宽**。

**它排除了什么,没排除什么。** 它排除了「羞耻压低的是报告」最朴素的那个版本:若谴责的崩塌
一直在释放一个被隐藏的人群,差距应当收窄,而在这个分辨率下那是看得见的。
⚠ 它**不**排除隐瞒本身 —— **接触机会没有被固定**。同样这 51 年里材料的可得性剧变,
若这个变化在谴责者与非谴责者之间不对称,一次真实的收窄可能被它掩盖。这条结论说的是
**在这台仪器里、固定人生阶段上的时代对比**,不是「隐瞒」这件事本身。

**而量它用的那道题,并不是这份问卷唯一的一道。** 2022 与 2024 年,GSS 把样本**随机劈成两半**,
分别问两道行为题 —— *「过去一年看过 X 级电影吗」*(是非)与 *「过去一年看过色情内容吗」*
(十级频率)。两臂人口学平衡(五项里最大 |z| = 1.95)。它们报的不是同一件事:
**阳性率 0.320 vs 0.425,Δ = +0.105,95% CI [+0.079, +0.135]** ——
**十分之一的人算不算「看过」,取决于他被递到哪一道题。**
但**谴责差距本身**在两臂之间量不出区别:**Δ 对数优势 = −0.27,95% CI [−0.61, +0.08]**,
而 MDE 是 **0.50**。⚠ 两臂之间**同时变了两件事**(所指的对象、作答格式),
所以这个差**不可归因于任一个**;且两臂都是同一份问卷里的**自报**,
**它们的一致不授权任何东西** —— 只有上界 **|Δ| < 0.50** 可报。
在频率量表的八个切点与四个子群上,**12/12 格把差距放在同一侧**,
且随切点移向重度使用**单调变宽**(*一年数次* 的 −1.57 到 *每周* 的 −2.19)。

**而同一个形状,换一个机构、换一个话题、换一种被问的方式,依然在。** NSFG 由不同机构执行、
不同抽样,而它的敏感题是**在电脑上自填,而不是对着访员说** —— 这正是 GSS 无法变动的那一样。
它带着同一对:*「两个同性成年人之间的性关系是可以的」*(同意/不同意)与「是否曾有过同性性接触」。
2017–2019 年的女性受访者中,**对数优势 = −1.22,95% CI [−1.41, −1.05]**(n = 5,895),
而 GSS 色情那一对是 **−1.42**。跨两波、两种「谴责」定义、两种行为定义,
**8/8 格同号**(范围 −1.41 至 −0.41)。⚠ 话题也变了,所以「大小接近」可能是两个不同话题恰好落在附近;
而较弱的那几格是**过去 12 个月**那一版,它来自一道被筛过的题(n ≈ 1,260 / 6,141),
弱可能来自这个筛选,而不是来自任何真实的衰减。

⚠ **多近算近?** 后一轮(`#490`)把**同一份 NSFG 问卷、同一批人、同一模式**里的三个
「态度×行为」对并排放:同性性关系、未婚生育、未婚同居。它们的对数优势是
**−1.22、−0.73、−0.31**,三条区间**互不重叠**,极差 **0.90** ——
**是上面 GSS 与 NSFG 之间那 0.20 的 4.5 倍。**
⚠ 那一轮判 UNVERIFIED(三个正对照里有一个失败),所以这是一个**扣住不读**的理由,不是一个发现。
但它意味着「大小接近」这句话**背后没有一把已建立的尺子**,在有尺子之前不应被读作一致。

**「那道差距」是一个数吗?** 不是 —— 而最锐的一格只差一个词。在**同一份 NSFG 问卷、同一批人、
同一模式**里,六个「态度×行为」对给出的对数优势从 **−0.47 到 −1.33**。其中三对是**先写下再计算**的:
*「离婚是最好的解决办法」*(−0.77)、*「未婚 **18** 岁若有强烈感情发生性关系可以」*(−0.52)、
*「未婚 **16** 岁…」*(−1.07)。**后两道问的是同一批人、同一件行为(16 岁及以前初次性交),
只差问题里印着的那个年龄。** 两条区间不重叠([−0.64, −0.41] vs [−1.25, −0.90])。
⚠ 谴责者占比也差很多(43% vs 85%),所以「谁算谴责者」没有被固定;
六对里谴责占比并不单调地排出差距的大小,但那是观测,不是检验。
⚠ 而区间越宽越偏向「重叠」,所以一个「不重叠」是在保守方向上得到的。

**而它不是由「有多少人谴责」带着的。** 跨六个话题,差距确实跟着谴责者占比走 ——
斜率 **+0.60,95% CI [+0.27, +0.93]**。但那个关联是混淆的:占比与话题一起变。
**固定话题与行为、只移动「算不算谴责者」的门槛**(强烈反对 / 反对 / 有点反对以上)后,
话题内斜率是 **−0.18,CI [−0.39, +0.01]**,而 **MDE = 0.28** ——
一个本来足以看见 +0.60 的设计,没有看见它。
**所以跨话题那个关系是话题带的,不是人数带的。**
⚠ 移动门槛同时改变了谴责者的**强度构成**与**规模**,所以「规模无关」与「强度无关」纠缠在一起;
而 —— 这是更大的那条保留 —— **那个合并斜率是在真正互相矛盾的话题之间取的平均**。
逐话题各拟一条斜率,得到同性性关系 **−0.61**、同居 **−0.68**、18 岁 **−0.35**,
对上离婚 **+0.43**、未婚生育 **+0.23**、16 岁 **+0.01**;
以「六个话题共用一条斜率」为零的异质性检验给出 **Q = 22.3,p = 0.001**,
且没有任何单一话题在驱动它(逐一剔除后 Q 仍在 12.7–21.9)。
**所以「门槛无关」只在平均意义上成立,而平均意义上不等于处处。**
⚠ Q 自身的重抽精度为 UNCOMPUTED。

**跨社会看,同一种耦合不是一个事实,而是好几个。** SCCS 里,**同一实践**的态度与频率是分开编码的,
所以谴责与稀有可以用社会作单位来比。**女性婚前性**上两者绑得极紧(ρ = **+0.797**,n = 97);
而**同性**(−0.371,n = 34)与**强奸**(−0.519,n = 17)符号相反,且都没有越过族内置换零。
⚠ 婚前性那个数**不是机制断言**:态度与频率由同一批人从同一批民族志编出,
**一句话可以同时产生两个码**。这个混淆现在是**被界定的,而不只是被点名的** ——
在同一份出版物内部,任意两个变量之间的典型耦合是 **|ρ| 中位 0.217**,
而唯三比头条更紧的对,**全是同一个问题问了男女两遍**。它仍然带着降级。

## 每个大轮确立了什么(R = 一次迭代、一次信念更新、一次提交)

**[R01 · 对象](A01_object_and_structure)** —— 题目层数据不是那 68 个类别评分,而是 **101 个多选列
展开成 1,332 个选项、15,468 个人**。进入每个块都被一个父评分把着门:
**P(进入 | 父评分 > 0) = 0.99**。这一点没有任何文档写过,而它约束下游每一个设计 ——
天真的跨块留出是**条件在「喜欢那个父类别」上**的。人剖面分半信度 **0.727**;
题目基率信度 **0.999**。加噪没有毁掉个体信号。

**[R02 · 有没有共享的语法](A02_is_there_a_shared_grammar)** —— 有,而前两件仪器看不见它。
PC1 对 PC1 给 0.064(撤回 #2);留出 CCA 给 0.272 对 0.055 的地板;留一块给 **32/32 块为正**,

## 共享信号是怎么累积的

**[RETRACTIONS #60]** `增量 = 0.00723 × √(源领域数)` —— 跨 n=1…31 的 CV **6.4%**,
对数形式 11.2%、线性形式 51.9%(`#60`),而置换标签的零在每一个 n 上都恰好是 0.0000。
**[机制被反转 —— #61、#64]** 块**不是**可互换的(子集方差是种子方差的 58 倍),
而且在**总受访行数固定**时,**块越多越差**:n=8 给 0.0042,n=16 给 0.0028,n=31 给 0.0025。
累积跟踪的是**总样本量**,不是块数 —— 那个 √ 形状就是普通的 √N。
块边界是对估计的一道税,不是它的来源。新采集的价目表:
0.06 需要 69 个领域,0.08 需要 122 个,0.10 需要 191 个 —— 已外推出实测范围。
