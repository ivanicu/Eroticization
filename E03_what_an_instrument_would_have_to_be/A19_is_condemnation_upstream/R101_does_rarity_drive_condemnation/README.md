## 本轮真正的产出:差分没有把共同成分去掉

**谴责婚外性**与**支持死刑** —— 道德上不相干的两件事 —— **一阶差分之后仍然同步在 +0.57。**

> **所以 −0.3413 不可解释:一条与无关道德序列同步 0.57 的序列,带着一个大的年份层共同成分。**

而序列本身指出了嫌疑人:谴责份额三十年稳定在 **0.78–0.82**,**2021 年掉到 0.6291** ——
**那正是 GSS 改成网络作答的那一年**,而 2018→2021 这一跳是全序列最大的一跳。
