# R107 · 那条 +0.80,换掉谴责那一侧的编码项目还在不在

**类型:FRONTIER**。**判决:W1 —— 构念稳健。而我下注它是同项目伪影,第四次下注下反。**

## 硬规则①做完之后,这一轮不是原来那一轮

**`EA078` 已经在 SCCS 里** —— 它就是 `SCCS282`(来源 Murdock (1962-1971); Gray (1999),
标题里直接注明 *identical to EA078*)。**所以「第二具仪器」不是新的库,是同一批社会上的另一个编码项目。**
而 SCCS 里同一个构念被四个项目各编过:`SCCS165` Broude · `SCCS282` Murdock · `SCCS961` Frayser · `SCCS596` Whyte。

**⚠ 而页面那条 +0.80 是 `SCCS165 × SCCS167` —— 谴责与频率都出自 Broude 同一个项目。**
`#528` 已量过:**同队变量对的相关强度是跨队的 2.14 倍。** ⇒ 真正该问的是换掉谴责那一侧。

## 硬规则①救了这一轮两次(读码,不读变量名)

- `SCCS282` 的**极性是反的**:`2` 禁止严惩 → `6` 允许无制裁,**越大越宽容**;
  而 `1`(早婚排除)、`5`(试婚)**不在这条尺上,剔除**(与 `#529` 丢 `SCCS172` 同一条规矩)。
- **`SCCS961` 的码 `7` 写着 *strongly disapproved **and rare*** —— **码本身把谴责与稀有捆在一起**,
  与稀有度相关是**定义上的必然**(realstat 的算术陷阱)⇒ **主检验剔除,单列并标注。**

## 关键在比例,不在差值

`#528` 量过:**同队变量对的中位 |ρ| 是跨队的 2.14 倍**(0.224 对 0.105)。

## 站得住的那一句

> **一个社会里婚前性越少见,它就越被谴责 —— 而这不是一个编码者的笔迹。

## ⚠ 跨仪器闸在本轮开火了,而它抓对了一件我差点糊过去的事

`#658` 的闸判本轮 **single_instrument**,而它是对的:**这一轮只用了 SCCS 一具仪器。**

> **「跨编码项目」不是「跨仪器」。**
> 我在 `#664` 里把 `EA078` 当成第二具仪器,而它其实是 `SCCS282` —— 同一批社会、同一个发布、同一批民族志,
> 只是另一组人打的分。**编码独立 ≠ 观察独立 ≠ 仪器独立。三者是三件事,而闸只认第三件。**

**换不了仪器,只此一具**(已验证):`#664` 穷举过 D-PLACE 的五个库 ——
**WNAI 429 个变量里只有 `WNAI343`「政治组织与罪的惩罚」,Binford 40 个变量 0 命中,
EA 唯一那道性道德题就是本轮用的 `SCCS282`。** 没有第二具仪器同时具备婚前性的**谴责与频率**。
**可证伪形式:若任一跨文化库出现婚前性的谴责与频率各一列且共同 n ≥ 60,这一条即被推翻。**
