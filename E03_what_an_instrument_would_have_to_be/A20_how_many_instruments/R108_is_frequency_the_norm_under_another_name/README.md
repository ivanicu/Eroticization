## ⚠ 但码文干净 ≠ 编码者没从规范里推 —— 而这一层可以直接测

**若 Broude 的频率只是他自己的态度换个说法,控制住他的态度之后,频率对 Murdock 那一侧的预测力应当消失。**

| 【女】n=81 | 值 |
|---|---|
| 原始 频率 × Murdock | **+0.6511** |
| 原始 态度 × Murdock | +0.6919 |
| 原始 频率 × 态度 | +0.7857 |
| **偏相关 频率 × Murdock \| 态度** | **+0.3094** · 95% CI **[+0.0934, +0.5198]** |
| ✅ 正对照 态度 × Murdock \| 频率 | +0.3180 · [+0.1091, +0.5371] |

**⚠ G4 不同意的那一格,一起发**:【男】n=29,偏相关 +0.4205 [+0.0412, +0.6763],
**但它的正对照失败**(态度×Murdock|频率 = +0.0435,区间跨零)⇒ **该规格功率不足,不可用。**

## ⚠ 一处标注的更正:我把控制工具的方向用反了

预注册写的是「换一个与性无关的控制变量,主量应**基本不动**」—— 那是**不变性检查**;
而我调用了 `offset_control`,它检验的是「效应必须**超出**系统性基线」。**方向反了。**

> **与 `#639` 的单位错配、`#654` 的转录漏 `|·|` 同族:预注册的文字是对的,代码实现错了。**

改用正确的 `negative_control`(零 = 无关控制造成的变化,效应 = 真控制造成的变化)后,两道全过。

## 站得住的那一句

> **一个社会里「有多少人真的这么做」和「这件事被怎么说」是两件事。**
> 把 Broude 自己的态度码整个控制掉,他的频率码**仍然**预测得了 Murdock 另一套规范码(+0.3094,区间不含零)。
> **稀有度不是谴责的影子 —— 而 `#665` 的 +0.6725 因此不是同义反复。**
