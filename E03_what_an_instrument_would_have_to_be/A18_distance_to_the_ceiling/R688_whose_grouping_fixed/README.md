## 而这缩小了 `#650` 自己的措辞

`#650` 说「`#528` 笔迹 · `#642` 光环 · `#650` 袋子是同一个错误类,三次」。**那是把三种机制混成了一类:**
- **笔迹** = 编码者风格污染**跨变量**相关(`#528`)
- **光环** = 编码者给**同一对象**的所有栏打相近分(`#642`)
- **袋子** = **名义块大于真实块**(`#650`)

**只有第三种是本轮测的东西,而它现在有 3 个实例(14 块里)。**
⇒ **`#650` 那句「三次同一个错误类」应读作:三次同一个**主题**,三种不同的**机制**。**
