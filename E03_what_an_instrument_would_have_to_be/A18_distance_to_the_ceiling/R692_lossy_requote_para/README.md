## 诊断:这个「比率」是一个穿着比率外衣的伯努利

**原侧限定数中位 = 1.0** —— 即使换成段级并集,源侧通常也只携带**一个**限定词。
**分母 = 1 ⇒ 丢失率只能取 0 或 1**,于是中位在「过半数的对丢掉了那唯一一个词」时必然是 1.000,
**而真假两边都接近抛硬币。**

> **一个分母几乎恒为 1 的比率,不是一个比率。**
> `#655` 诊断成「单位错了」,**只对了一半**:换单位把可量对从 108 提到 163,**却没有改变分母。**
