# R685 · 分诊,而分诊器自己要先能失败

**类型:FRONTIER**。`#648` 说「按天花板分诊,不是一律重算」——
**而一句「分诊」如果不能失败,它就只是一次重新措辞。** 所以本轮先给分诊器造一个能失败的正对照。

## 判据(先写死,只留能分辨的那一刀)

天花板中位 **≥ 0.85 → 无需重算** · **< 0.60 → 必须重算,可能改写** · **0.60–0.85 → 待定,不硬判**
