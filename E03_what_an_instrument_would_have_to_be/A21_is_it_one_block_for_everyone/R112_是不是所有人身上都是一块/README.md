## ⛔ 两处判据是我自己设坏的

**① 跨仪器一致性要求「最高层必须是同一层」** —— **而 GSS 的年龄最高档是 `65+`,NSFG 的样本上限就是 45 岁。**
**这个判据在年龄上永远不可能通过。**
> **又一次「control that cannot PASS」** —— 与 `#651`(阈设在设计能返回的上限之外)、
> `#666`(工具方向用反)同族:**判据的文字对,而它在这个设计上不可满足。**

**② 安慰剂比错了量**:非性道德题的最弱一环**全是负的**(−0.0662 ~ −0.3672)——
**它们根本不成块**,所以那个量是「最反相关的一对」,**不是「最弱的正内聚」。两个量不可比。**

## 按方向读,能说的只有描述

**年龄:两具仪器同向** —— GSS 最老档 `65+` 最紧(+0.4781),NSFG 最老档 `35-45` 最紧(+0.3635)。
**教育:不一致** —— GSS 单调向上,NSFG 在「部分大学」见顶而「大学+」回落(n 仅 389)。

> **年纪越大,性道德越像一整块 —— 两具仪器都指向同一个方向。**
