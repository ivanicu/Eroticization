## 撤回:`#671` 的命名

`#671` 用「作答一致性特质」统一了两次失败(`#663` 与 `#671`)。
**而那一轮自己写着:「『作答一致性特质』是本轮命名的解释,不是被独立测量的构念。」**
本轮去测它:**九组、八个内容族,ρ 从 −0.80 散到 +1.00,而零等于观测。**

> **⇒ 我当时手上只有两组碰巧同向的题,就把它命名成一种特质。撤回这个命名。**
> **这不是一次「假撤回」** —— 撤回的是**一个从未被测过的解释**,而不是一个被测过的数。
