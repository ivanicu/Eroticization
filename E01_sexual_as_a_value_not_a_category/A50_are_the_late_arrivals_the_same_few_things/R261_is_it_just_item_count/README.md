## ⚠ 两件必须说的

**① 我跑之前写的代数预测,符号错了。**
我写的是「双向去均值让人内残差和 ≈ 0,所以 `corr(y,x)` 带一个约 **−1/(k−1)** 的负偏」。
**实测的置换零全是正的**(+0.048 / +0.014 / +0.007 / +0.015 / +0.020 / +0.021),
而且**随 k 减小而变得更正**,不是更负。**预测写在跑之前,错了就记着,不改。**

**② 这一轮的置换零与 `#214c` 的不是同一个零。**

    `#259`(`#214c`)用的是 **题内跨人置换** —— 毁掉人层配对,保留每题的值分布 -> `c=18` 零 **−0.0792**
    本轮用的是 **人内置换** —— 毁掉"这个人的哪个类别配到哪个年龄" -> `>18` 零 **+0.1309**

**两个零符号相反,因为它们问的是两个不同的问题。**
所以本轮的净 **−0.4344** 与 `#214c` 的净 **−0.2243** **不是同一个数**,
**不能并排引用** —— 每一个只在它自己的零下有意义。

## 结构上做不到

k 与"晚"在数据里天然相关(晚半条目少),所以匹配后的 `≤16` 子样本不是随机子集 ——
**只能用来证伪"k 解释了它",不能用来立别的。**
