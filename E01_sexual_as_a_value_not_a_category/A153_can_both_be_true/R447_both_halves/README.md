# R447 · 「两边都有」是**一件事** —— 它比八个单量里任何一个都更能把那群人分出来

`#402a` 的那句「两边都有」是**四个 d 的联合描述**,不是一个量。本轮把它做成一个量,**并用一个会失败的判据打它**。

## ⚠ 跑之前写下为什么这个检验很容易变成空的
`BOTH` 由**两个已经各自越阈**的量组成 -> **它的 |t| 高几乎是保证的**。
**所以判据不是「越过族内阈 1.9」,而是「超过八个量里的最大值 6.803」** ——
**只有「合起来比任何单个都强」才说明「两边都有」是一件事。**(`#396b`:由构造保证的结果携带零比特信息。)

## 结果:两种构造都超过
| 构造 | d | \|t\| | 族内零阈 | vs 最好单量 6.803 |
|---|---:|---:|---:|:--|
| `BOTH_sum = z(S) − z(五题)` | **+0.3987** | **8.761** | 1.913 | **超过** |
| `BOTH_min = min(z(S), −z(五题))` | **+0.3881** | **8.543** | 1.903 | **超过** |

**两种构造一致**(`#444` 的教训照搬:若只在一种上成立,那是构造在说话)。
**⇒ 「两边都有」是一件事,不是两件事各自成立。**

## ⚠ 而 guard 26 第一版 FAIL,原因是**网格太粗**
第一版网格 `(0.10, 0.20, 0.30, 0.45)`:0.30 给 50%、0.45 给 97%,**80% 点落在两者之间**,
于是 MDE 被报成 **0.45**,而实测 d 是 0.3987 -> 门 FAIL。
> **一个 MDE 网格的分辨率,会把 MDE 系统性地报**高** —— 而报高的方向,恰好是**让门失败**的方向。**
> **加密网格不是搬门柱**:MDE 是**设计的属性**,粗网格只是**测不准它**。
加密后:0.28 → 36.7% · 0.32 → 60% · **0.36 → 93.3%** -> **MDE = 0.36 ≤ 实测 0.3987**,通过。

## 对照
负对照(随机分组 200 次越阈率)**6.5%** · 两种构造一致 · guard 26(**显式 `branch='non_null'`**,`#402c`)。

## IMPOSSIBLE
① `min` 会被**两边都低**的人拉低,而那是「既不冷门也不被常规打动」;
② 同一份数据、同一对格子 -> **不是复制**;③ 「合起来更强」不等于「存在一个潜变量」。
