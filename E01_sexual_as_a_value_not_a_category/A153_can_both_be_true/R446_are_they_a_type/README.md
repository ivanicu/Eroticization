# R446 · 那群人不是「羞耻者里随机的一部分」—— 他们有自己的形状

`#401e③`:「存在这群人」不等于「这群人是一个类型」。本轮问那一句。
比较的是**两格**:**「都高」**(羞耻高+疗愈高)vs **「只羞耻」**(羞耻高+疗愈低)。
**两格的羞耻都高** -> 差别只可能来自「疗愈」那一维。

## ⇒ 世界 A:他们有形状,而且形状是连贯的
与「羞耻但不觉得疗愈」的人相比,「都高」的人:
- **口味更冷门**(`S` +0.24 sd)
- **而普通的东西对他们**也**有用**(五题 −0.31 sd —— 分数低 = 常规**更**色)
- **兴趣来得更早**(`EARLY` −0.16 sd)
- 轮廓略更清楚(清晰度 +0.13 sd)

**⚠ 而 `c3⁻` —— 页面上最大的那条羞耻路径 —— 完全分不开他们(|t| 1.19)。**
**⇒ 区分他们的不是「口味的内容」,是「他们同时也拥有普通的那一半」。**

## ⚠ 而 guard 26 本身也被改了接口
这是**第三次**把「零的争议幅度」传给它、而结果是**开火**的(`#372c①` · `#384d` · 本轮)。
**一个零的争议幅度是「有意义的效应量」;一个非零结果的争议幅度是「实测到的效应」。**
> **按 `#383a`:不是记住,是改接口。** `guard 26` 现在**要求显式声明 `branch`**(`null` / `non_null`),
> 打错直接 `ValueError`。**6 个攻击向量,旧调用逐字节不变。**
本轮是**非零支**,争议幅度 = 实测 **0.3081**,而 MDE **0.25 ≤ 0.31** -> 通过。
