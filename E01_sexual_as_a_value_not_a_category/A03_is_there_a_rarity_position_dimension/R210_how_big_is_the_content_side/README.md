# R210 · 「内容」这一侧到底有多大

**问题**:`#163b` 说位置倾向里有一个小的**内容**成分,`#159` 说「何时」的结构几乎全在类别上。
那么一直没被问过的第三件事是 —— **「这个人勾了哪些具体选项」本身,作为一个人层性质,有多稳?**
若它明显高于位置的 0.60,本项目一直在测的「位置」就只是更大的一个「内容」的投影。

**估计量**:把块劈成不相交两半,在每半的**选项矩阵**上取主成分给每个人打一个内容分,
跨人相关 + Spearman-Brown;并在**把同一半上的位置分数回归掉之后**再量一次。
两半在**块**上不相交,所以没有共享题目。

**预注册阈值**:0.60(位置侧的信度)。

**格**:k ∈ {6,8} × 3 个劈分种子 × {真实, 每块独立跨人置换, 纯内容种植, 纯位置种植},整格发表。

## 结果

| | 内容 SB | 去位置后 | 位置 SB |
|---|---:|---:|---:|
| **真实** | **+0.278** | **+0.262** ± 0.110 | **+0.598** |
| 置换零 | +0.072 | +0.079 | +0.048 |
| 纯内容种植 | +0.799 | +0.672 | — |
| 纯位置种植 | +0.570 | +0.362 | +0.916 |

**位置 > 内容**,差 −0.335,是自身展布的 3.1×;预注册的 0.60 也在噪声带外(3.1×)。
`results/content_vs_position.csv`。

## 泄漏底噪 —— 这个零不该是 0

回归掉一个**有噪声**的协变量会留下衰减残留,而主成分会把那个残留读成「内容」。
所以造一个**构造上内容为零**的合成世界(置换背景 + 纯位置种植),把强度调到它的
位置信度匹配真实的 0.60,读它的「去位置后内容」:

| 种植强度 | 位置 SB | 去位置后内容 |
|---:|---:|---:|
| 0.00 | 0.048 | 0.079 |
| **0.05** | **0.686** | **0.076** |
| 0.10 | 0.845 | 0.043 |
| 0.25 | 0.905 | 0.263 |
| 0.60 | 0.915 | 0.255 |

**泄漏是非线性的** —— 强度 0.6 处漏 0.26,而匹配真实信度的 0.05 处只漏 0.076。
真实 +0.262 − 底噪 +0.076 = **+0.187,1.6× 展布 → UNVERIFIED**。
`results/leak_calibration.csv`。

## 两个分数彼此相关吗

|r| = 0.319 ± 0.180(共享方差 10.2%)。既**不可分辨地非零**(1.8×),
也**不可分辨地小**(等价界只能界到 0.678,边界 0.30)。设计在这个 k 上分辨不了 → UNVERIFIED,
按盆地规则不追第三轮。`results/content_position_corr.csv`。

## 本轮修掉的两个自己的错

- **种植向量在两半里各抽一次** → 种下去的不是人层信号而是两半各自的噪声,只会稀释;
  正对照因此反向开火(+0.31 → +0.085)。`u` 必须是**全局人层的同一个向量**。
- **四个臂各自劈块** → n 从 682 跳到 1346,臂之间根本不可比。劈分必须由 k 与种子决定,与臂无关。

## 结构上做不到

「内容」由跨人主成分定义,所以测的是**共享的**内容维度。
一个完全特异的组合(只有他一个人这么勾)对任何跨人成分都不可见。
