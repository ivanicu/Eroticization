# R05 · Δ 的机制是审查吗?—— 不是,而且顺手量到了一件更大的事

`#130a` 的 Δ = −0.2345 是本弧最大的效应(49×),而它的两个候选机制都死了
(左尾 `#130d`、中位数时间表 `#131c`)。剩下最便宜的候选是**审查**。

## 审查:UNVERIFIED

| 年龄档 | n | 类别数 | Δ | 人内置换零 | 倍数 |
|---|---:|---:|---:|---:|---:|
| 14-17 | 1,749 | 12.4 | −0.2259 | −0.0068 | 21.3× |
| 18-20 | 1,502 | 12.4 | −0.2274 | −0.0001 | 20.9× |
| 21-24 | 2,037 | 12.6 | −0.2359 | +0.0048 | 25.7× |
| 25-28 | 2,151 | 12.8 | −0.2380 | −0.0022 | 26.4× |
| 29-32 | 2,209 | 12.9 | −0.2414 | −0.0009 | 26.7× |

各档极差 **0.0156 = 1.6× 单档自助展布** —— 低于分辨率。

⚠ **我预注册的审查方向是错的。** 人为审查(删掉每人最晚获得的 f 比例类别)让 Δ **更不负**
(−0.2345 → −0.2110),所以审查预测的是「年轻 → 更不负」。观测到的方向**一致**
(14-17 档 −0.2259 vs 29-32 档 −0.2414),但幅度只有 1.6×。**UNVERIFIED,不是无罪释放。**

这是 Δ 机制上连续第二轮 UNVERIFIED。按 `#111c`,**换方向,不追第三轮**。

## 这一轮真正的产出:性版图在青春期结束时就基本定型

审查的**前提**本身可以直接测,而它很弱:

| 年龄档 | 类别数 | ≤17 岁获得的比例 | 最晚获得的那个 |
|---|---:|---:|---:|
| 14-17 | 12.4 | 91.7% | 17.3 岁 |
| 18-20 | 12.4 | 88.5% | 18.7 岁 |
| 21-24 | 12.6 | 79.7% | 20.1 岁 |
| 25-28 | 12.8 | 74.1% | 21.1 岁 |
| **29-32** | **12.9** | **68.4%** | **22.6 岁** |

- **人内、不依赖任何横断面假设**:29–32 岁的人,他们自己报告的性兴趣有 **68.4% 是 17 岁前
  获得的**,而最晚的那一个平均落在 **22.6 岁**。
- **横断面(队列混淆,较弱)**:15 年里类别数只从 12.4 长到 12.9(**+4.5%**)。

前几档的「≤17 比例」在机械上被年龄本身限制(14–17 岁的人不可能在 18 岁获得任何东西),
所以**只有最年长档那一行是可读的**。
