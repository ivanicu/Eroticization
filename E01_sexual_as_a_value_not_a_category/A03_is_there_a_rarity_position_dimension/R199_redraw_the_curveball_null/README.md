## 但那 10 抽仍然回答了本来的问题

| | 值 |
|---|---:|
| curveball 零臂的人格 max\|r\|,10 次独立实现 | **0.0320 .. 0.0543** |
| 它的实现 sd | **0.0068** |
| 零臂的性别 \|r\| | 0.0075 .. 0.0298 |

**一次** curveball 零,自己就能在人格上产生高到 **0.054** 的相关。
`R15` 平均了**三次**,残余实现噪声 ≈ 0.0068/√3 = **0.004**,而效应是 **+0.0930**
—— **23 倍余量**。

> **这条声明是安全的,而它安全的原因正是 `R15` 把零平均过。
> 用一次抽样的零,它不会安全。**
