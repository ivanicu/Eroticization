# R01 · 重抽 `#114` 的零

## 扫描

139 个持久化结果文件 → **53 个含零臂** → **17 个的零臂没有 seed 列**。
分诊后,两个支撑**现存声明**的零确认是单次抽样:

- **`#114`**(A12/R166,「人把最爱的性兴趣记得更早,约九个月」):`np.random.default_rng(9)`,
  **一次**同类别内打乱。
- **`#101`/`#102`**(A11/R148,「唯一挂得住的外部锚是性别」):`curveball(M, default_rng(8100))`,
  **一次**保边际实现。

## 重抽 `#114` 的零 20 次

| | 值 |
|---|---:|
| 效应臂 | **−0.2000 ± 0.0096(20.8×)** —— 与原轮逐位复现 |
| **原轮那一次(seed 9)** | **−0.00035 = 效应的 0.2%** |
| 20 抽:均值 / sd | −0.00244 / **0.01108** |
| 20 抽:范围 | −0.02273 .. +0.01972 |
| **占效应的比例范围** | **0.2% .. 11.4%** |
| **零的实现 sd ÷ 效应** | **5.5%** |

**原轮那一抽是 20 次里最小的。** README 写的「同类别内打乱零 = 效应的 **0%**」
是那一次的运气。

## 但声明站住

**最不利的那一抽也只有效应的 11.4%**,`negative_control` 通过(门槛 50%)。
**`#114` 不动,改的是它旁边那个数:「0%」→「0–11%,零的实现 sd 是效应的 5.5%」。**

## 而这给出一条比 `#152e` 更平衡的规则

> **单次抽样的零不自动致命。伤害的大小 = 零的实现 sd ÷ 效应。**
> `#148`:基准 sd **44 个百分点** vs 净额 61 个百分点 → **毁掉了那个比值**。
> `#114`:零的 sd **5.5%** vs 效应 100% → **无害,只是让数字看起来比实际好**。
> **所以报单抽零的时候,必须带上这个比值。**
