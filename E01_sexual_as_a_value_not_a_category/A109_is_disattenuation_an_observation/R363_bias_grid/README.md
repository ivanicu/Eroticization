- **正对照**(信度 1.0 一列):max |绝对上偏| **0.0044**。

## ⇒ 两条
1. **`#317b` 撤回。去衰减在这个网格上没有系统性上偏。**
   `#317a`(去衰减对 4 倍信度变化不变)**不受影响,它是另一个量的另一次测量。**
2. **能用的那个数是绝对上偏的展布:sd = 0.0073。**
   **任何一个去衰减数字,除了它自己的抽样误差之外,还要再带 ≈±0.007 来自这次校正本身。**
