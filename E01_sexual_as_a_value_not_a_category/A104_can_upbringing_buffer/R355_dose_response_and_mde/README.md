# R355 · 性开放的成长环境最多能挡掉多少羞耻 —— 这个设计答不了,而这就是答案

`#309c` 我写的是「**一个性开放的成长环境,并没有把这条路上的羞耻挡掉**」。
**那句话太强了。** 本轮报界与 MDE,并纠正它。

## 剂量-反应(U = −1 压抑 / 0 中性 / +1 开放),同一模型里控制了年龄与关系风格**及其交互**
| | 交互系数 | 95% CI | 从压抑到开放的变化 | 相对主效应 |
|---|---:|---:|---:|---:|
| `zRS × U` | −0.0077 | **[−0.0318, +0.0164]** | −0.0154 | **−12.3%** |
| `zRC × U` | −0.0015 | **[−0.0257, +0.0227]** | −0.0030 | −2.4% |

主效应(U=0):`zRS` +0.1257 · `zRC` +0.1238。
95% CI 换算成缓冲比例:`zRS` **[+26.1%, −50.6%]** · `zRC` **[+36.6%, −41.5%]**。

## ⛔ 而这个界没有内容,因为 MDE 是 55%
| | 交互的 MDE | 换算成缓冲比例 |
|---|---:|---:|
| `zRS × U` | 0.0344 | **54.8%** |
| `zRC × U` | 0.0346 | **55.8%** |

**这个设计只看得见「挡掉一半以上」的情形。** 一个 30% 的缓冲 —— 一个心理学上很大的效应 ——
在这里与零区分不开。

正对照证实了这一点:**植入 30% 的缓冲,读出 77.1%;植入 0%,读出 8.7%** ——
估计量在这个 n 下又吵又偏大。负对照(打乱人)−0.0022 ± 0.0116。

## ⇒ 纠正 `#309c`
**不能说「挡不掉」。只能说:如果它挡掉了,这个设计看不见 —— 而它的视力只到 55%。**

⚠ **不做旋钮扫描。** `#300a` 要求上页面前发明一个能弄坏结论的旋钮,
但这里的结论是「**这个设计没有功效**」—— **功效不足不是一个规格问题,换切法救不回来。**
写下来是因为「跳过一个流程步骤」必须给出理由,而不是省略。

## ⚠ 而 `#309b` 仍然成立,因为它测的是另一个量
`#309b`(两条路都没有被 10 个变量调节,跨格 sd 0.89× / 0.78× 自身 se)**聚合了 19 个格**,
所以它有功效;本轮那**一个**成长环境对比没有。
**「所有调节变量合起来看不出系统性变化」和「这一个调节变量的缓冲量有多大」是两个问题。**

**我不能告诉你,在一个性开放的家里长大能不能让你少一点羞耻。**
我只能告诉你:如果能,那也不到一半 —— 而这台仪器只看得见一半以上。
