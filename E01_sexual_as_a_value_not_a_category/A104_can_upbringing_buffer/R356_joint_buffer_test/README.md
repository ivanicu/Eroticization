# R356 · 四个「本该缓冲」的变量,合起来也没有在缓冲 —— 而这次有功效

`#310c`:`#309b` 有功效而 `#310a` 没有,差别在**聚合**。**那就把缓冲问题也做成聚合量。**

⚠ **跑之前写下的**:联合检验只能说「有没有任何一个在缓冲」,**说不出是哪个**。

## 结果:没有,而且这次能说「没有」
| | |
|---|---:|
| 观测的 R² 下降(去掉 8 个交互项) | **0.0938pp** |
| `perm_finite` 置换零(60 次) | **0.1213 ± 0.0605pp** |
| 位置 | **−0.23× 的 2×展布** |
| 零里 ≥ 观测的比例 | **58.3%** |

**观测值落在置换零的中间偏低 —— 一点缓冲的痕迹也没有。**

## 聚合确实换来了功效,而且逐变量都测了
| 只在这一个变量上植入缓冲 | 联合检验抓到的最小缓冲 |
|---|---:|
| 成长期性开放度 | **10%** |
| 关系风格 | **10%** |
| 年龄 | **10%** |
| 开放性 | **30%** |

对比 `#310a` 的**单系数** MDE:**54.8%**。
⚠ MDE 是单种子的网格估计,分辨率约一个网格步(同一个变量在两次扫描里给 10% 与 20%)——
**保守读法:三个变量 ≤20%,开放性 ≤30%。**

强度扫描单调且 g=0 落回基线(0% → 0.0625pp · 20% → 0.2484pp · 50% → 0.4830pp),过 guard 13。

## 按 `#300a` 发明的旋钮:换聚合方式

## ⚠ 一条关于守卫用法的记录
`negative_control` 这个守卫在这里 FAIL,因为「零大于效应」——
**但当结论本身就是一个零时,这个守卫的形状不适用**。
该读的是**置换分位数**(58.3%),而那正是这一轮报的东西。
**守卫不对,不等于结论不对;而说清楚哪个守卫适用,是我的责任,不是守卫的。**
