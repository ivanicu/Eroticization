## 而「17 行无出处」这个说法本身要改

这个项目用了**至少三种引用记法**:`` `#59` `` · `[RETRACTIONS #16]` · `[#58]` ·
`[MECHANISM REVERSED — #61, #64]`。**`#176` 的正则只认第一种。**

    只认反引号 `#N`      -> 带出处 3 / 17
    认三种记法          -> 带出处 6 / 17
    最宽(任意 `#数字`)  -> 带出处 6 / 17   <- 与三种记法相等,说明界是紧的

**所以 `#176c` 的「17 行无出处」要改成:6 行带着出处(记法不同),11 个 token 真正不带。**

## 本轮修掉的两个错

1. **查找键就是被编辑的那段文本。** `full_line` 用行的**前 60 字符**当键,
   而这一轮我给两行加了 `(`#59`)` —— **插在前 60 字符里,键当场失效**,
   函数静默退回旧前缀(里面没有 `#`),于是"带出处"数纹丝不动地停在 3。
   同 `#171b`(那个家必须先存在)一族:**键不能是会被这次操作改动的那段东西。**
   已加按 token 的退路,数字从 3 → 6。
2. **一个写死在报告里的常量。** "只认反引号 → 0" 是硬编码的;
   我一加反引号出处,那个 0 当场变成假话。
   **一个印在报告里的常量,是一条不会被任何检查抓到的声明。** 已改成实算。
