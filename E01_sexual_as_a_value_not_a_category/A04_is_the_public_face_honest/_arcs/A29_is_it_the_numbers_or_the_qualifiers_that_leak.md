# A29 · 这条线上流失的,是数字还是限定语

`#172` 自己的「结构上做不到」写着:一句被删掉的**限定语**不带数字,那道闸看不见。
而 §2 的 η 规则说 `#167`–`#171` 这一整串的病根就是限定语 ——
*a number reported without the scope over which it holds*。**所以我预期这里会有很多。**

**这个弧要让哪个决定变安全**:下一道规则该去查「限定语被删掉」,还是别的东西。
