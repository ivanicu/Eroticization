# R216 · 有哪些数量离开了这一页

**新规则** `readme_ledger_audit.numbers_that_left(rev)`:抽出参照版本 README 里的所有**数量**,
减去当前版本里的所有数量 —— **差集 = 离开这一页的数。**

**参照提交钉成 SHA**(`88b0993`,即去重提交 `7b1951f` 的父)。
用 `HEAD~1` 会在每次提交后漂一格,那样这个检查就变成在查别的东西了。

## 注册的 kill 开火,而被抓的是我上一轮的修复

    正对照(对去重刚落地那一版 7b1951f 跑):
      README.md  `+0.2523`   离开了这一页
      修前原文:**rho +0.2922 uncontrolled, +0.2523 with all indicators**

声明表行 57 只带 `+0.2922`,**不带 `+0.2523`**。所以上一轮那次「按一个事实一个家去重」,
删掉的是**内容**而不是**重复** —— 「控制全部作答风格指标之后 rho 仍有 +0.2523」这件事,
在整个公开面上一度不存在。

**已修**:`+0.2523` 连同它的 UNVERIFIED 限定(每道题都是情色内容且无反向计分,
一般性同意倾向与一般性情色认可在这个 release 里分不开)一起放回声明表行 57,中英各一处。
规则复跑 → **0 个数量离开这一页**。

## 这条规则的见证(P6 代理账)

一个数可以被**改写**而不是删除(`0.2285 →` 那一串在 `#169b` 的改写里就换了说法)。
所以命中项**必须逐条人工判「被删了,还是换了说法」** —— 规则只在**离开**方向可读,
而且「没有离开」**不等于**去重是对的:也可能删的是内容、留下的才是重复。

## 结构上做不到

只查数量。一句被删掉的**限定语**(scope、instrument、population)不带数字,这条规则看不见。
