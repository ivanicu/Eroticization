# R266 · Δ 方向在残差里占多少

两侧去均值后的残差 `D`(只在观测格、`KEEP` 内),总平方和 **1,108,193**。

| 方向 | 占比 | 超出基线 |
|---|---:|---:|
| **① Δ 方向**(`x` = 稀有度,人载荷自由) | **11.41%** | **+2.99 pp** |
| ② **最佳秩一**(`x` 也自由,带缺失的 ALS) | **15.83%** | +7.40 pp |
| ③ 随机 `x` 基线(20 次) | 8.43% ± 0.58% | — |

## 原始比值虚高,必须扣掉共同基线

    原始 Δ/最佳 = **0.721**
    **净比值 = 2.99 / 7.40 = 0.404**

**随机方向本来就占 8.43%** —— 那是"任意一个题目权重向量"的免费额度。
**扣掉之后:稀有度拿到了最好那个方向超额解释力的 40%,而随机权重拿到 0%。**

**注册的 kill(Δ < 最佳的 1/5)不开火。Δ 不是残差里一个次要方向。**

- **正对照**:种强 Δ → 占比 11.41% → **54.03%** ✅
- **offset**:Δ vs 随机基线 = +2.99 pp,**5.1×** ✅
- `corr(最佳秩一的 x, 稀有度) = +0.2935` —— 最佳方向**只与稀有度中度对齐**,
  所以那里面还有一个**不是稀有度**的成分。

## 结构上做不到

**占比小 ≠ 不重要** —— 一个小而稳的方向可以比一个大而杂的方向更有解释力。
**本轮只量大小,不判重要性。**
