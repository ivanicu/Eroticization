# R231 · 单题信度的下界,与一条敏感性带

**单题做不了分半。** 能给的下界:对任意另一题 `y`,`r_xy ≤ √(r_xx·r_yy) ≤ √r_xx`
→ **`r_xx ≥ max_y r_xy²`**。

## 这个下界弱到没有用

    羞耻与其余 19 题的最强相关  |r| = 0.1444  ->  下界 r_xx >= 0.0209
    正对照:同一方法用在 S 上    下界 0.0247,而 S 的真实分半信度是 0.432(`#100`)
                            -> **只逼近到真值的 6%**

**所以单题信度在本数据里不可估。** 按跑之前注册的规则(下界 < 0.25 → 不可估),
**只报敏感性带,不给校正后的点值。**
