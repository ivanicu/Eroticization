# R260 · 是哪些类别在扛「晚来的那一半」

## 集中度:不集中,而且不比早半更集中

基线:31 个类别均匀时前 3 类占 **9.7%**。

| c | >c 半前 3 类占比 | ≤c 半前 3 类占比 | >c 观测数 |
|---:|---:|---:|---:|
| 10 | 22.4% | 34.7% | 140,661 |
| 14 | 22.0% | 30.1% | 89,929 |
| **18** | **22.9%** | 25.1% | 30,356 |

**`c=18` 半的前 3 类只占 22.9%,而且比 `≤18` 半的 25.1% 还低。**

## 更直接的判据:删掉贡献最多的 3 个类别

| | Δ at c=18 |
|---|---:|
| 全部类别 | −0.3034 |
| **删掉前 3 贡献类** | **−0.2895**(14.0×) |
| 随机删 3 类(20 次) | −0.3013 ± 0.0202 |

**删掉前 3 类与随机删 3 类不可分辨**(差 +0.0119,**0.6×**)——
`offset_control` 的零命名为「随机删 3 个类别,即只因少了 3 个 item 该掉多少」。

**两条 kill 都不开火:晚来的那一半不是几个特定类别扛起来的。**

## ⚠ 我的负对照选错了,它动不了这个统计量

我用「人内打乱起始年龄」当负对照,得到 **23.4%**,与真实的 22.9% 几乎相同。
**但打乱年龄根本改不了"哪些类别被报过"** —— 集中度只由**观测覆盖**决定,与年龄配对无关。
**一个动不了被测统计量的负对照,不是负对照。**
它这次 PASS 只是因为我在断言里写了 `or < 0.35` 那一支。
**有意义的基线是均匀的 9.7% 与早半的 25.1%,不是那个打乱。**

## 结构上做不到

删掉 3 个类别同时也减少了每人的条目数 —— 所以必须与**随机删 3 类**并排比,而不是与全量比。
本轮已这么做。
