# R249 · 那张载荷表本身,可复现吗

## ⚠ 这一轮替代了 `#203` 注册的 NEXT,并说明为什么

`#203c` 要求一个**干净上下文的独立编码者**(我已看过载荷,自己写的编码会顺着它走)。
**本会话的指令是「未经用户要求不调用 Agent」——比常设授权更窄、更即时,所以不调用。**
替代设计达到同一个认识论目的,而且**更硬**:
**在给那张表起名之前,先问它是不是真的。**

## 结果:高度可复现

| | |
|---|---:|
| **真实两半载荷 \|r\|** | **0.9692 ± 0.0067**(10 个劈分种子) |
| 置换零 \|r\| | 0.4154 ± 0.0383 |
| 差 | **+0.5537(14.2×)** |
| 块内中位 \|r\| | 真实 0.9835 · 零 0.3849 |
| 最差 / 最好的块 | 0.849 / 0.997 |

**`#203b` 看到的「动物 · 体液 · 所有权 / 手铐 · 锁链 · 3P」是一个真实稳定的对象,不是噪声。**

⚠ 只能判 **|r|** —— 特征向量符号不定;**而零也享有同样的"取绝对值"便宜**(它的 |r| 是 0.415,
不是 0),所以判据是两者之差,不是真实值本身。

## 正对照失败,而诊断是天花板

注册的正对照是「块内 PC1 解释率越高,复现越好」。实测 `corr = +0.0621` —— **失败**。

诊断:**29/32 块的 |r| ≥ 0.90**,块级 |r| 的 sd 只有 **0.036**,
而那个 sd 本身只有它自身重抽展布的 **1.5×** —— **没有可被预测的变异**。
所以这个控制的失败是**无信息**的,不是反证:判 **UNVERIFIED,不判 REFUTED**。

⚠ 我写的严格判据是「全部块 ≥ 0.85」,而最小值是 **0.849** —— **差 0.001 没过**。
**没有动阈值。**

## 结构上做不到

每半约 3,300 人 · 每块 8–40 个选项 —— 载荷本身噪声大,所以 |r| 是复现度的**下界**。
