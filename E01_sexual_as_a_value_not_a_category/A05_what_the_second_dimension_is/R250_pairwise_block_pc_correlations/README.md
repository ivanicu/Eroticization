## 为什么锚要选"某一块"而不是"和"

对齐到**和**(即全局 `Cres`)会**人为造出**正的两两相关 —— 那是循环。
**锚是第 1 块**,与其余 431 对的关系是无偏的。**99.1% 同号是在这个无偏锚下读出来的。**

## 结构上做不到

两块的共同人群因块而异(1,200–13,000),每对的 n 不同;
本轮报的是**未加权**平均,**不做跨对排名**。
