# A45 · 「内容维度」是一个维度,还是 32 个块内成分的和

`#204b` 只证明了**每一块自己**的载荷可复现,**没有证明 32 块的 PC1 指向同一个人层构念**。
`Cres` 一直是 32 个块 PC 分数的**和**,而"和"只有在它们彼此相关时才是一个维度。
**这一条本该在 `#188` 就做。**
