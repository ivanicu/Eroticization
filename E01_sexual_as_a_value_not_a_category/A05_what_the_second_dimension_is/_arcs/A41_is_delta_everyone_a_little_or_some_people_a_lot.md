# A41 · Δ 是「所有人都有一点点」,还是「一部分人有很多、另一部分相反」

`#128` 的 Δ = **mean_i rho_i** = −0.0328 —— **它是一个人层平均,而从没人看过 rho_i 的分布。**
这两件事在同一个均值下长得一模一样,却是完全不同的心理学陈述。
