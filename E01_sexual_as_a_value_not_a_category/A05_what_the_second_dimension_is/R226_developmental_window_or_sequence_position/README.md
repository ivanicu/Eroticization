# R226 · 「早」是发育窗口,还是序列位置

`#180` 的"早"是**人内相对**的,混着两件心理学含义完全不同的东西:
**绝对年龄早**(青春期前 → 发育窗口)与**在这个人的序列里靠前**(→ 身份地基)。

## 整格(2 种劈分 × {真实, 人内打乱} × 阈值 {10,12,14})

| 劈分 | n | Δ(早−晚) | sd | \|Δ\|/sd | MDE |
|---|---:|---:|---:|---:|---:|
| **相对(人内中位)** | **11,329** | **+0.0276** | 0.0131 | **2.2** | 0.026 |
| 绝对(<10 岁) | 1,089 | +0.0515 | 0.0421 | 1.2 | 0.084 |
| 绝对(<12 岁) | 2,423 | +0.0450 | 0.0289 | 1.6 | 0.058 |
| 绝对(<14 岁) | 3,854 | +0.0124 | 0.0221 | 0.6 | 0.044 |

**四种劈分同号。相对劈分的人内打乱零 = 效应的 18%。**

## 判定:UNVERIFIED —— 本设计分不开

只有相对劈分可分辨(2.2×)。**但绝对劈分的臂只有它的 1/10–1/3 样本**,
而 3 个阈值里 **2 个的点估计更大**(+0.0515 / +0.0450 vs +0.0276)。

> **把"没通过可分辨性"读成"发育窗口不起作用",是把功效不足读成证据缺席(P5 ★)。**

**要在绝对劈分上判到 2×,`<12 岁` 那一格需要把 MDE 从 0.058 压到 0.045 以下 —— 约 1.7 倍样本。**

## 本轮修掉的两个错,都在 print 侧

1. **第一版直接打出结论「序列位置」**,而它自己的可判前提(两臂都要 n>2000)**刚刚失败**。
   Gate 里守住了(UNVERIFIED),`print` 里放行了。
   **一个 verdict 必须受同一个条件式管辖,不能只在 Gate 里守而在 print 里放行。**
2. **"点估计比相对劈分大"是逐行印的通用语**,而对 `<14 岁` 那一行是假的(+0.0124 < +0.0276)。
   已改成逐行实判。`#178` 那一类:**一个印在报告里的通用语,没有任何检查会去查它。**

## 结构上做不到

绝对与相对在数据里高度相关(早熟的人两种劈分几乎一致)。
**即使把样本补足,这两件事在本数据里能不能分开,仍是未知的。**
