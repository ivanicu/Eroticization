# R239 · 勾选数是作答风格,还是真实内容

`#193c` 我把勾选数称作「近乎普适的**作答风格**因子」——
**那是一个关于测量的断言,而我没检验过它。**

`#184` 已证这 20 道**没有反向计分题**,所以常规办法用不了。
替代筛子:**语义天然相反的一对** —— K 同号 = 作答风格,反号 = 真实内容。

## 筛子没通过它自己的正对照

**正对照**:性别镜像对(「想象自己是**女性**地存在」/「…**男性**…」)
在题间相关上必须**强负** —— 否则"语义相反"这个筛子无效。

    实测题间 r = **+0.241**   ← 正的

**在这群人里,这两道根本不是语义相反,而是同向共现。**
筛子失效 → **本轮判不了**,判定 **UNVERIFIED**。

## 数据自己挑出的强反向对(题间 r < −0.15),仅供记录

| 题间 r | r(K,a) | r(K,b) | 同号 | 对 |
|---:|---:|---:|:--:|---|
| −0.271 | +0.1080 | −0.0074 | no | `biomale` \| `written` |
| −0.261 | +0.1080 | +0.0305 | **YES** | `biomale` \| 被支配唤起 |
| −0.226 | +0.0901 | +0.0305 | **YES** | 被支配唤起 \| 被支配唤起 |
| −0.159 | −0.0074 | +0.0901 | no | `written` \| 被支配唤起 |

同号 **2/4**,而**随机配对的同号率是 83%** —— 方向上不像纯作答风格,
**但 n=4 对,且筛子未通过正对照,不足以判。**

## 结论:`#193c` 的措辞要收窄

    可以说:K 与 20 道结局里的 18 道相关。
    不能说:K 是一个作答风格因子。

**在这份 release 上,"作答风格 vs 真实广度"结构上不可判** ——
没有反向计分题,而语义相反的筛子被它自己的正对照否掉了。

## 结构上做不到

语义相反 ≠ 心理学相反。一个人可以既被支配唤起、也被它的反面唤起 ——
这正是正对照失败所展示的东西。
