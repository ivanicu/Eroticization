# A38 · 勾选数自己预测什么

`#192b`:「位置贴羞耻、内容贴媒介」的干净分工**只在给定勾选数之后才出现**。
而**勾选数从来只是一个控制项** —— `#104` 证过位置倾向去掉它后保留 67%,
**但没人问过它自己预测什么。**

**这个弧要让哪个决定变安全**:「位置↔羞耻」要不要按"勾得多的人更容易有一样让自己羞耻的东西"重新分解。
