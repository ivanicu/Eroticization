# R238 · 把勾选数当主变量

## 勾选数几乎预测一切 —— 除了羞耻

全族阈值:K 侧 |r| = 0.0366 · S 侧 |r| = 0.0369

| r(K,·) | r(S,·) | 题 |
|---:|---:|---|
| **+0.1820** ★ | +0.1570 ★ | `inducefetish` |
| +0.1663 ★ | +0.1166 ★ | 异性互动为色情 |
| +0.1448 ★ | +0.0937 ★ | 疗愈 |
| … | … | … |
| **+0.0442**(排名 **18/20**) | **+0.1185** | **羞耻** |

**K 侧越阈值 18/20 · S 侧 16/20。而羞耻是 K 最弱的一格,却是 S 最强的一格。**

## 三项分解(共线 `corr(S,K) = +0.6067`,**不得声称分开了**)

    r(S, 羞耻)  raw +0.1185  ->  给定 K  **+0.1155**    几乎不动
    r(K, 羞耻)  raw +0.0442  ->  给定 S  **−0.0351**    翻负

**注册的 kill(K 自己越阈值且达到 S 的一半以上)不开火**:
`0.0442 < 0.0593`,而且 `|+0.0442 − 0.0366| = 0.0076` 只有自身噪声的 0.5× —— **它连阈值都没真的越过。**

## ⚠ 注册的可判前提失败了,所以面板不能用来说"特异性"

我注册的前提是「多数题在 K 侧为零,否则 K 对什么都出结果」。**实测 18/20 —— 前提失败。**
所以**不能**用这条面板说"K 只预测 X 不预测 Y"。
**能用的是三项分解** —— 那是另一个测量,不依赖这条前提。

同时这也是一个关于 K 的事实:**勾选数是一个近乎普适的作答风格因子**,
所以"它在羞耻上最弱"是**诊断性**的,不只是"弱"。

## 结构上做不到

`corl(S,K) = +0.6067`,两者的"各自贡献"在共线下不可分(`#182b` 的教训)。
本轮报三个数,**不声称把它们分开了**。
