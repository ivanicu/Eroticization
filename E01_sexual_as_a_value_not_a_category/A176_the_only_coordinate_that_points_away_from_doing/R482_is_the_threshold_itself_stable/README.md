# R482 · 阈不是那个限制 —— 设计才是

⚠ **FRONTIER**。`#437` 的 NEXT:z = −2.25 对阈 2.37,差距 5%,而阈是 400 次置换估的。
**阈本身有没有比这个差距更吵?**

## 结果
| 置换次数 | 阈 |
|---:|---:|
| 400 | 2.358 |
| 1,000 | 2.297 |
| 2,000 | 2.343 |
| **4,000** | **2.384** |

**阈的自助 95% 区间 = [2.323, 2.434]** · **2,000 -> 4,000 漂移 = 1.7%**(< 5%)
**观测 |z| = 2.276 -> 低于整个阈区间。**
**对照**:系数与 `#437` 一致(−0.0273)—— 变的只有零。

**判决 = RESOLVED。**
