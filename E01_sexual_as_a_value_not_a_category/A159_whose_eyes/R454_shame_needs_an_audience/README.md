# R454 · 方向偏向「需要观众」,但这个设计答不了

`#384b`:羞耻 -> 少做(−0.083)。**从没问过:这条关系在**从没有过性伴**与**有过**的人身上是不是一样。**
两个世界对**差的符号**给出相反预测 —— 真正的分离器。

## 结果:方向有,强度没有
| | 系数 | se | n |
|---|---:|---:|---:|
| **从没有过性伴** | **−0.0499** | 0.0239 | 1,758 |
| **有过** | **−0.0860** | 0.0144 | 4,850 |
| **差(有过 − 没有过)** | **−0.0361** | \|t\| **1.294** | |

已控 `S` · `c3⁻` · 类别数 · **年龄**(⚠ `corr(从没有过, 年龄)` 大 -> 同轮控,不事后加)。

offset 零(**随机等大小分层** 400 次)= −0.0009 ± 0.0280,95 分位 **0.0533** -> **未越阈(−1.26 sd)**。

## ⚠ 而这个零也不可发布
guard 26:**MDE 0.08** vs 有意义 **0.05** —— 1.6× 偏大。
**⇒ 既不能说「羞耻需要观众」,也不能说「与观众无关」。**
**方向是 A(有过性伴的人身上近两倍),但那只是一个方向。**

## 对照
负对照**越阈率 4.5%** ✅ · offset 零非退化 ✅ · guard 26 **FAIL(如实记)**。

## IMPOSSIBLE
① 「从没有过性伴」与年龄强相关 -> 已同轮控年龄;
② `ACTED` 对没有性伴的人天然更低 -> 分层压窄该层方差 -> **只比符号与越阈,不比大小**;
③ **「需要观众」与「有机会」在这份数据里分不开** —— 明说,不让零承担。

## 一句关于人的话
**羞耻对行动的压制,在有过性伴的人身上看起来强了近一倍(−0.086 vs −0.050)——**
**但这个设计分不清那是「有人看着」还是「有机会做」,也分不清它是不是只是噪声。**
