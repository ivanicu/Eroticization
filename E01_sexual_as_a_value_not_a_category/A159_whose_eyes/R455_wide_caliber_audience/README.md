本轮**只解决「是不是噪声」**(`#410c`:加 n 修不了混淆)。

## ⚠ 而 MDE 网格第一版又太粗
0.05 给 63.3%、0.08 给 96.7%,**80% 点落在两者之间** -> MDE 报成 0.08 > 实测 0.0618 -> 门 FAIL。
加密后 **MDE = 0.055 ≤ 0.0618**,通过。
**这是 `#403b` 的规矩第二次生效**:网格分辨率把 MDE 系统性报**高**,
**而加密网格改的是测量的分辨率,判据(实测 0.0618)一个字没动。**
⚠ 打印的格式把 0.055/0.06 都印成 `+0.06`(小数位不够)—— **数值是对的,显示是错的**,这里说明一下。

## ⚠ 而 `#410c` 的混淆**原样带进结论**
**没有过性伴的人**既没有观众,也没有机会** —— 而 `ACTED` 同时被这两者压低。
**⇒ 本轮证明的是「这个差不是噪声」,**不是**「羞耻需要观众」。**
**加多少 n 都改不了这一条。**
