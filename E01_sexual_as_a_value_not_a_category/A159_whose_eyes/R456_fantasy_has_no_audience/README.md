# R456 · 幻想上的分层差只有行动上的三分之一 —— 但这个设计排除不了「自我评价」

`#411c`:行动上的分层差分不清「观众」与「机会」。**幻想两者都不需要** -> 换结局。

三个世界:**A 自我评价**(幻想同样受它管 -> 差**存在**)· **B 观众** · **C 机会**(幻想都不需要 -> 差**消失**)。
⚠ **B 与 C 预测相同 -> 本轮只排除,不分离** —— 这一条写在跑之前。

## 结果:三格同号,**都未越阈**
| | n | 从没有过 | 有过 | 差 | 阈 | |
|---|---:|---:|---:|---:|---:|:--|
| A 窄 × 全模型 | 6,607 | −0.0307 | −0.0497 | −0.0190 | 0.0576 | 未越阈 |
| B 窄 × 简模型 | 6,607 | −0.0342 | −0.0483 | −0.0142 | 0.0582 | 未越阈 |
| **C 宽 × 简模型** | **12,515** | −0.0254 | −0.0439 | **−0.0185** | 0.0420 | **未越阈** |

**guard 25:6,607 -> 12,515(+89.4%)。** 负对照**越阈率 2.5%**。

## ⚠ 而这个零**不可发布** -> **A 排除不了**
guard 26:**MDE 0.060** vs 有意义 **0.05** —— 1.2× 偏大。
**⇒ 既不能说「自我评价被排除」,也不能说「它成立」。**
⚠ 网格**一开始就加密**了(`#411b` 的教训),所以这次不是网格的问题,**是功率本身不够**。

## ★ 但有一个**直接可比**的对照,而它不需要新数据
| 结局 | n | 分层差 | 阈 | |
|---|---:|---:|---:|:--|
| **行动**(`ACTED`,`#411a`) | 12,516 | **−0.0618** | 0.0421 | **越阈** |
| **幻想**(治疗性,本轮) | 12,515 | **−0.0185** | 0.0420 | 未越阈 |

**同一设计 · 同一分层 · n 差 1 · 阈差 0.0001 —— 而行动上的差是幻想上的 3.3 倍。**
⚠ **但「3.3 倍」本身没有被检验过** —— 那是下一轮的事,不是本轮的结论。

## IMPOSSIBLE
① **B 与 C 本轮不分离**;② `corr(羞耻, 治疗性)` 总体 = **+0.0005**(`#401a`)——
所以分层差若存在,意味着**零掩盖了两个相反的一半**,那是一个更强的主张;
③ 「从没有过性伴」与年龄强相关 -> 已同轮控年龄。

## 一句关于人的话
**羞耻压住的似乎主要是**做**,不是**想** —— 幻想上的分层差只有行动上的三分之一。**
**⚠ 但这个设计还不足以说「自我评价被排除了」。**
