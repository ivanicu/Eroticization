`corr(支配, 臣服) = **−0.2256**`(负相关 -> 「两端都高」本来就罕见)
| 构造 | ① 自己越阈? | ② 吃掉 P1/P2? |

## ⚠ 而更要紧的是:**能用的那个构造,不测那个概念**
`FLEX_avg` 是支配与臣服的**平均** —— 它高,意味着**这个人对权力动力整体反应强**,
**不意味着他在两端都灵活**。`min` 才是灵活性,而 `min` **什么也没有**。
> **一个假设的「支持」若只来自不测它的那个构造,那不是支持。**
