## ⚠ 而它最强的那一格已经被撤回过

`u_i × age = +0.1818` 是整张表最大的一格 —— **而 `#210` 已把 `rho_i × age` 判为截断假象**。

## 结构上做不到

本轮判的是它们**指向的外部结局**重不重叠,**不是它们本身正交不正交**。
