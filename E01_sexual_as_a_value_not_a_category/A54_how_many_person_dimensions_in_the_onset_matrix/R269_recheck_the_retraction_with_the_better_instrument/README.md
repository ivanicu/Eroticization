## 结论:`#210` 的撤回**被复现**,但它的"反号"措辞是仪器特有的

**两把刀都同意:这个关系在去掉截断后塌掉了。**
`u_i` 从 +0.1818 → **+0.0220**(与零不可分辨,1.2×),偏移 **7.4×**;
`rho_i` 从 +0.1532 → −0.0741。

**它们不同意的是"反不反号"**:`rho_i` 反号,`u_i` 只是归零。
**所以 `#210` 那句「反号」应当改成「塌到与零不可分辨」** —— 反号是 `rho_i` 特有的。

## ⚠ 可判前提二失败:在受限臂上 `u_i` 反而不如 `rho_i` 灵敏

我注册的前提是「`u_i` 在两档上都比 `rho_i` 灵敏」。
**全样本成立**(0.1818 > 0.1532);**受限臂不成立**(0.0220 < 0.0741)。
**所以"更灵敏的刀给出不同答案"这个框架在这一档上不适用** ——
注册的 kill(不反号 → 重开 `#210`)**按字面开火了,但它的前提没站住,判定不可读。**

**能读的是那个不依赖"谁更灵敏"的事实:两把刀都显示关系塌掉。**
