## ⚠⚠ 而我的预注册门,在**开火的那一支**上写错了
我预注册的是「仅当 … **且 C 格 MDE < 0.05** -> 才判」。C 格 MDE 是 **0.08**,所以门判 FAIL。
**但 MDE 是给「零」用的判据**(guard 21 的逻辑):
「这个设计看不见更小的东西」只在我要报**没看见**时才相关。
**这里的结果是开火的** —— 相关的问题是「它越阈了吗、同号吗、复制了吗」,而三个都是。

**这正是 `#372c①` —— 而我在记下那条教训的下一轮又犯了一次。**

## ⇒ 怎么处理:不许直接推翻自己的预注册
看过结果再放宽一个门,正是预注册要防的事。所以:
1. **门如写:FAIL。本轮不在那个门下声称任何东西。**
2. **门写错的**方式是可知的**,而且上一轮已经记下** -> 这是**预注册的事后修补**,必须公开。
3. **因此这条结论降一级:D6,不是 D7**,等一次**独立**确认。
4. 重新注册正确的判据(同号 + 越过自己的阈 + guard 25 通过),**留给下一轮**,不在本轮追认。
