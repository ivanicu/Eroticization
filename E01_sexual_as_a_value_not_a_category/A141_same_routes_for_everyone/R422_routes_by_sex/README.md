## ✅ 能说的:`c3⁻` 那条路对两性是同一条
差 **−0.0026**,|t| **0.10** —— 而这个设计对 0.12 的差**百分之百**检出。
**⇒ `#296` 的性别非不变性,不在 `c3⁻ -> 羞耻` 这条路上。** 这是对 `#296` 的一次**收窄**,不是推翻。

## ⛔ 不能说的:「三条路对两性都一样」
**MDE = 0.12,而有意义的差是 0.05** -> guard 21 判**不可发布**。
`EARLY` 的两倍之差(−0.098 vs −0.045)**看得见但过不了族内阈**(2.14 vs 2.31)——
**既不能报,也不能否。**
