# R407 · 那个下降不是一般性的纳入效应 —— 它几乎只发生在羞耻上

`#360b`:`S ↔ 羞耻` 沿覆盖阈从 +0.1715 掉到 −0.0023,约 43% 归给选择。
`#361`:「固定人群变块数」走不通。**换一条更直接的路:问它是不是只发生在羞耻上。**

⚠ guard 22 先过:这条曲线有 **6** 个点。

## ⇒ 注册的 kill 的第二支:羞耻特有
**多数结局**没有**这个下降**(中位 +0.0015,只有 2/29 超过纯选择基线)。
**⇒ 不是一般性的纳入效应。`#360` 的旗不降级 —— 它反而更值得追。**

## ★ 而这里顺带修正了 `#360b` 的一个数
`#360b` 用一个**合成**关系估「纯选择」的下降 = 0.074,并据此说观测的 43% 是选择。
**但本轮显示:真实结局的下降(中位 +0.0015)远**小于**那个合成基线(+0.0435)** ——
**合成基线**高估**了选择造成的下降。**
**⇒ `#360b` 的「43% 是选择」是一个**慷慨**的估计;真实的选择份额更小,
而羞耻那 0.169 里不能归给选择的部分**更多**。**

## 一句关于人的话
「填得越少的人,冷门口味越带羞耻」——**这件事只发生在羞耻上。**
在另外二十八个结局上,填多填少几乎不改变任何东西。
