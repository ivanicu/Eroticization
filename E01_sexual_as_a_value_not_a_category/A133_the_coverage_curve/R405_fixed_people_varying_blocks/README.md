# R405 · 这个设计跑不动 —— 固定住人并不能固定住块

`#360` 的边界:「谁被纳入」与「`S` 被测得多好」分不开。
**本轮的设计是:固定 `cov>=16` 的那 950 人,只改用来算 `S` 的块数。**

## ⛔ 它在第一步就死了
**这 950 人里,被 >95% 的人答过的块只有 1/32。**

> **块的进入是**被父评分把着门**的(`R01`:`P(进入 | 父评分 > 0) = 0.99`)——
> 所以「答了 ≥16 块」的人,答的**不是同一批**块。**
> **固定住人,并没有固定住块。**

k 只能取 1,曲线只有一个点,全距 0.0000 —— **那不是「平」,那是空的。**

## ⚠⚠ 而注册的 kill 和 guard 21 都在这个退化结果上「通过」了
- 注册的 kill:「全距 > MDE?」-> 全距 0.0000 < 0.0908 -> **判「平」**;
- guard 21:三件套齐(分位数 · MDE 0.0908 · 灵敏度)-> **判「这个零可以发布」**。

**两个判据都对着一个只有一个点的曲线开火。**
⚠ 这正是 `#296b` / guard 17 的形状:**一个坏掉的仪器可以让判据通过。**
**本轮的判据里没有一个问「曲线有几个点」。**

## ⇒ 诚实的结论
**UNVERIFIED —— 不是「曲线平」,是这个设计在这份数据上跑不动。**
而它跑不动的原因本身是一条结论:
**`#360` 的那个边界,在这份数据上是**永久**的** ——
没有办法固定人群而改变 `S` 的估计质量,因为块的集合随人而变。
