# R276 · 「对越轨类别宽」挣不挣得到这个名字

`#230c`:成分 3 的**得分明确,名字未挣**。
⚠ **诚实前置**:c3 的载荷我已经看过(`R274` 打印了高低端各 3 块),
所以「载荷与块勾选率负相关」**不是独立检验** —— 它只是把已看见的图样量化一遍
(实测 **−0.4026**,标注为非独立,不作证据)。
`#201` `#202` 两次命名失败的教训:**名字必须先写成一个能被杀死的预测,再去测。**
所以主检验是一个从名字推出来、而我没看过的东西:
**把块按自身平均勾选率切成「普通」/「越轨」两半,羞耻只贴哪一半?**

## 全门通过,而两半的符号是**相反**的

| | 块数 | 平均勾选率 | 分半信度 | **↔ 羞耻** | 解衰减 |
|---|---:|---:|---:|---:|---:|
| 普通半 | 16 | 0.435 | +0.6459 | **−0.0618 ± 0.0128**(n=5,322) | −0.0769 |
| 越轨半 | 16 | 0.308 | +0.7164 | **+0.1007 ± 0.0119**(n=6,113) | +0.1189 |

**差 +0.1625,是合并展布的 9.3×;解衰减后 +0.1958**(⚠ 最强混杂是"越轨半信度更高",
它确实存在 0.646 → 0.716,但**解衰减后的差更大**,所以它不能解释这个结果)。
置换羞耻的零 +0.0023 ± 0.0123(效应的 2%)。
正对照两端都过:只贴越轨半的合成结局 → 差 **+0.5680**;与两半等相关 → 差 **−0.0041**。

## 名字挣到了第一份证据,但它比我原来的读法更强
原读法是"越轨半**更**贴羞耻"。实测是:**普通半的方向是负的。**

> **不是「想要的越多越羞耻」。在普通的事情上敞开,羞耻反而更少;
> 羞耻只跟「在少有人去的地方敞开」绑在一起 —— 同一个「宽度」,两个方向相反的半。**

## 作用域(不要越写)
- 「越轨」在这里被操作化为**块的平均勾选率低**,是一个**粗代理**:
  它不区分「社会禁忌」与「单纯少见」。名字挣到的只是**这个代理下**的第一份证据。
- 两半的 n 不同(5,322 / 6,113),因为各自要求 ≥4 块覆盖。
- 这与 `#179` 的位置分**不是同一件事**:位置分问的是**块内**你挑的选项有多冷门,
  这里问的是**你在哪些块上敞开**。`corr(c3, 位置分) = +0.2036`。

## 一句关于人的话
羞耻不跟「你要得多」走,跟「你要的是哪一类」走。
**在人人都去的地方敞开的人,羞耻更少;而同一份敞开,换到少有人去的地方,就变成羞耻。**
罕见这件事在两个层次上各起一次作用:**在一个领域里你挑多冷门的**(`#179`),
和**你根本在哪些领域里敞开**(这一轮)—— 两者几乎不重叠,却都通向同一种感觉。
