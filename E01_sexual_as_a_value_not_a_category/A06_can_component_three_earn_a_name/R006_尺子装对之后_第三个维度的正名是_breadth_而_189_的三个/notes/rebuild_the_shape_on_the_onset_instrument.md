## ⚠ 全门通过,而我不信那个绿灯 —— 两条门本身有问题
1. **功效那一条结构上不可能失败**:我写的是「取扫描中高于零+2sd 的最小值」,
   而**基线本身就在零之上**,所以那个集合永不为空。已在门里标成 `[空条款]`。
   真正该报的是:种入 2 类人后 k=2 给 0.9046 / 0.8957 / 0.8425 / 0.9856 ——
   **非单调,因为基线已经是 0.9379,种入只能扰动它。**
   在一个基线接近上限的量上,「种得更强 → 数更大」这个假设本身不成立(`#228d` 的同一个病换了方向)。
2. **`negative_control` 的「零 < 一半效应」在零很大时几乎无力**:k=2 以 **49% vs 50%** 险过。
   而 `(观测−零)/零的展布` 把 2.3× 与 33.5× 干净分开。
   **两个判据会不一致,应当同时报。**
