# R303 · c3 的名字,换一把仪器还挣不挣得到

c3 是这个项目最结实却最没被解释的一个:29 个结局打中 **17–21**,信度 **0.5631**,
三重控制后仍然如此,对羞耻 **+0.1286**(比位置分还大),**而它至今没有名字**。
⚠ 那个读法(「对越轨类别宽」)是**从块载荷看出来的**,所以在块上再量一次不是独立检验。
**换一把仪器**:起始仪器的 31 个类别与块选项**完全不相交**。

## 结果:名字挣到了,而且两半的符号是**相反**的
| | c3 与它的相关 | 控制起始仪器总类别数后 |
|---|---:|---:|
| 普通半(流行度高的 15 个类别) | **−0.1086 ± 0.0114** | **−0.2452** |
| 越轨半(流行度低的 16 个类别) | **+0.1815 ± 0.0106** | **+0.2452** |

**越轨 − 普通 = +0.2901,是自身展布的 18.6×;控制类别数后差反而涨到 +0.4905。**
置换 c3 的零 −0.0030 ± 0.0143(效应的 2%)。
正对照两端都过:只贴越轨半 +0.2562 · 与两半等相关 +0.0083。
⚠ 常驻混杂 `corr(c3, 总类别数)` 已先报,而控制它之后**差变大**,所以它不能解释这个结果。

> **c3 = 你把「敞开」这份额度花在哪里。**
> 高 c3 的人:在**少有人去的类别**上宽,在**人人都有的类别**上**窄**。
> 这不是「更宽」,是**同一份宽度的分配方式** —— 两半的符号相反,正是这个意思。

## 一句关于人的话
这个项目最可靠的那个人层维度,现在有名字了:
**不是「你有多开放」,是「你把开放花在哪儿」。**
有些人把它花在大家都去的地方,有些人花在少有人去的地方 ——
而后者,正是更羞耻的那些人(`#230b`:c3 ↔ 羞耻 +0.1286,比位置分还大)。
