# R293 · rate 与 Δ 算自不相交的类别,那条地形还在不在

⚠ **先纠正 `#247` 自己的 NEXT**:它写「把 `rate` 对人内起始年龄 sd 残差化」。
**那是过强的控制** —— `rate` 的分母**就是**跨度,人内 sd 与跨度几乎是同一个量,
扣掉它等于把构念本身扣掉,无论如何都会塌,而那不能区分「假象」与「被我自己删掉」。
**真正的威胁更根本**:`rate` 与 `Δ` **算自同一批起始年龄**,
一个人若回忆噪声大,两个量会同时被扭曲。把 31 个类别劈成两半,**rate 只用 A 半、Δ 只用 B 半**。

## 作用域
跨半切断的是**共享观测**,切不断**共享的人层回忆风格** ——
若一个人在所有类别上都压缩,两半仍会同时被压缩。**这条边仍开着。**

## 一句关于人的话
把一个人的兴趣随机分成两半,用其中一半算「他积累得多快」,用另一半算「他罕见的兴趣排在哪」——
**这条关系仍在,而且保住了一半以上。** 它不是同一批数字算了两次的产物。
