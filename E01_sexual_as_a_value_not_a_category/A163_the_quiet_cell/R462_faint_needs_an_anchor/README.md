# R462 · 「不羞耻也不疗愈」**不是**「什么都淡」—— 而这个零是有功率的

`#417b`:符号一致性测不了「淡」,因为八个量没有共同朝向。
⚠ **而 NEXT 提的「按页面已有结论定向」有两个坑,写在跑之前:**
**① 按羞耻定向是**循环的**** —— 页面上这些量的朝向都是对着羞耻记的,而「都低」那一格**就是按羞耻定义的**;
**② 按我的读法定向,正是 `#417b` 刚批评的错。**

## ⇒ 需要一个**既不是羞耻、也不是我**的锚
`Totalsexacts`(认可的性行为**计数**)—— **方向由「它是一个计数」给出**,
且**不参与四格的定义**(四格只用羞耻与治疗性)-> **不循环**。
**锚先自证**:`corr(Totalsexacts, 勾选类别总数) = **+0.2465**`(两个计数同向)✅

## ⇒ 结论
**那一格在**某些**量上差得很远(`#417a`:`S` 的 |t| = 10.17),但**不是每一样都更少**。**
**「不羞耻也不觉得疗愈」不是一个整体变淡的状态。**
