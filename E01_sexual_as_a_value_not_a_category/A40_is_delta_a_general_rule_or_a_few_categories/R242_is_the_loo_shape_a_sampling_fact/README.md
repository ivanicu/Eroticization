# R242 · 留一形状是采样事实还是心理学事实

`#196d`③ 提出:留一影响可能主要由「多少人答过这个类别」决定,而不是由稀有度决定。

## 这个问题不是一个问题

    corr(log n, 稀有度) = **−1.0000**

**稀有度就定义为 `−log(答过的比例)` = `log N − log n`。** 它们是**同一个变量**。
「是 n 还是稀有度」是**同义反复**,注册的 kill **取不到数**。

后果一路可见:两个对照都失败(把一个变量从与它完全共线的另一个里回归掉是退化的),
真实的偏相关之差的 bootstrap sd 直接是 **`nan`**。**判定 STRUCTURALLY IMPOSSIBLE。**

## 能读的只有一个数

    r(log n, |ΔΔ|) = **+0.4295**

**留一影响随「答过这个类别的人数」上升。** 而由于稀有度按定义是它的负对数,
「Δ 的逐类别影响跟着**常见程度**走」与「跟着**样本量**走」**是同一句话**。

> **`#196c` 那个"既不集中也不均匀"的谜团,不是被解开的,是被解散的:
> 我拿来分类别的那把尺,和我想解释它的那个变量,是同一根东西。**

**漏掉 189 个**,其中就有 `cov`(`#166c` 咬过我,我当时改了列名却从没把它加进名单)。
