# R459 · 两把刀切出两组**几乎不重叠**的量

`#402a` 比的是**「都高」vs「只羞耻」** —— 两格都在**羞耻高**那一侧,差别只来自**疗愈**那一维。
**本轮是另一刀:「都高」vs「只疗愈」**(815 vs 1,046)—— 两格都在**疗愈高**那一侧,差别只来自**羞耻**那一维。

## ⇒ 结构:两个维度有**各自的**签名,加上两个**共享**的
- **共享**:`S`(口味冷门)· `EARLY`(来得早)—— 两把刀都切得到;
- **只标记疗愈**:**五题(常规的东西对他也管用)** + 轮廓清晰度;
- **只标记羞耻**:**`c3⁻`(口味的内容)** + `D`(块间对比)。

**⇒ 「口味的内容」标记的是**羞耻**那一维;「普通的也管用」标记的是**疗愈**那一维。**
**它们不是同一件事的两种说法。**

## 一句关于人的话
**在觉得疗愈的人里,把羞耻的人标出来的是**他口味的内容**和**它来得早**;**
**在羞耻的人里,把觉得疗愈的人标出来的是**普通的东西对他也管用**。**
**两把刀切出两组不同的量 —— 羞耻与疗愈不是同一件事的两面。**
