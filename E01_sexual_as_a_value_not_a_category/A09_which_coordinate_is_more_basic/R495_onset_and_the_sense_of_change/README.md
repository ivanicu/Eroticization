## ① 本页两条最强的弧,从未被接上

**那么:早来的东西是不是更像是定死的?**

## ⚠ ③ 而正对照第一版写反了 —— 第五次门测错断言

**两版都留在记录里**:写错的那版 **FAIL**,它本意要测的那句 **PASS**。
