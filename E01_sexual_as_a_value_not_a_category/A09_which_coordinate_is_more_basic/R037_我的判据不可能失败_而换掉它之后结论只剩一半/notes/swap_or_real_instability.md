# R491 · 换标签这个解释被它自己的符号否掉了

⚠ **FRONTIER**(两枝都改页面)。`#446` 的 NEXT:「坐标塌掉」是结构不稳,还是成分互换?

## ⚠ ① 我提的机制被**符号**否掉
互换的预测:**间隙小 -> 互换 -> 逐向量相关低**。
实测:**间隙 与 逐向量相关 = −0.3716** -> **间隙越大,向量恢复得越差** —— **符号相反。**

## ② 换成对换标签**不变**的仪器:主角
| | |
|---|---:|
| **对照**:全样本子空间对自己 | 最大主角 **< 1e-6°**(仪器认得出同一件事) |
| **对照**:随机二维子空间的零 | 最大主角 5 分位 **76.5°** · 中位 85.5°(仪器说得出「不」) |
| **较小的主角** 中位 / 最大 | **12.4° / 21.6°** |
| 较大的主角 中位 / 最差 | 23.6° / **82.2°** |
| 较大主角 **< 45°** 的半样本 | **18 / 20** |
| 较大主角 **≥ 随机零 5 分位** 的 | **1 / 20** |

## ★★ ③ 结论:不是换标签,而脆的是**一对里的第二个方向**
**较小的主角在二十个半样本里从未超过 22°** -> **一个方向每次都长得出来**;
**较大的主角在 1/20 里达到随机水平** -> **另一个方向大约每二十次彻底失败一次**。
**⇒ 这一对在两个方向上并不同样结实,而压在它上面的结论继承这个不对称。**

## 一句关于人的话(方法轮,所以是关于我的)
**「这个坐标不稳」和「这一对里有一个方向不稳」是两句话,**
**而逐向量相关分不出它们 —— 分得出的那个仪器,对换标签不变。**

## IMPOSSIBLE
① 20 次劈半不独立;② 只看了第 2/3 这一对;
③ **本轮没有说哪个方向是稳的那个** —— 主角不带方向标签,这是它不变性的代价。
