# R504 · 把答题行为拿去和它自己对分

⚠ **FRONTIER**。`#459` 的 NEXT:领域数仍是答题行为 —— **那就让答题行为自己对分。**

## ① 设计:两个量由**同样的两个数**构造
**进得广** = `ncat`(踏进过多少个彼此分开的领域)
**进得深** = `PICKS / ncat`(每个进过的领域里勾了多少项)
**两者都由答题行为产生** -> **「这个人答得多」会同时出现在两者上。**

## ② 前置(`#459` NEXT 的自订规矩)
- **分母分布**:`ncat` min **5** · 中位 **13** · max **31** -> **由构造为正且远离零**,比值可采信;
- **共线性先报**:corr(广, 深) = **+0.4110** -> **不共线**,「都不越」不会是互相吃掉。

## ★★ ③ 结果:只有「广」推
| 量 | b 羞耻 | b 能不能改 |
|---|---:|---:|
| **进得广 `ncat`** | +0.0134 | **−0.0360 ✅** |
| 进得深 `PICKS/ncat` | −0.0232 | +0.0042 |

族内阈 **0.03041**。**对照**:加入「深」之后 `ncat` 的系数**没动**(−0.0360 vs `#459b` 的 −0.0353)。

**⇒ 答题行为作为共同解释被排除了** —— 它同时决定两者,而只有一个在说话。

## 一句关于人的话
**跟着「觉得自己能改」走的,不是一个人答了多少,**
**而是他到底踏进过多少块彼此分开的地界;每一块填得多满,什么也不说。**

## IMPOSSIBLE
① 「广」仍然经由问卷测得 -> 排除的是**一般性答题倾向**,不是全部测量效应;
② 横断面;③ 只测了这一个结局对。
