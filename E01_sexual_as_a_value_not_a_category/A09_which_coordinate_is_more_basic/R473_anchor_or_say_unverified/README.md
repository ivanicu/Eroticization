## ★★ ② 两个锚是坏的,坏法不同,而且都不报错
| 锚 | 症状 | 机制 |
|---|---|---|
| `TotalMentalIllness` | `to_numeric` 后 **0 个非空** | 名字叫 Total,**实际是只有 `'Any'` 一个取值的字符串** |
| `sexcount` | `r = nan` | 分档字符串,`to_numeric(errors='coerce')` **只留下取值为 `'0'` 的 4,524 人** -> 全为 0 -> 零方差 |

而修分档时**又踩了第三个**:
**`v.dtype == object` 在 pandas 3 里是 False** —— 字符串列的 dtype 是 `str`,
所以整条分档分支没进,再次退回 `to_numeric`。**判内容,不要判 dtype。**

⚠ **两次我都差点从这些 `nan` 里读出「不可标定」** —— 那正是 P5 的 ★:
**一个从没返回过非零的仪器给出的零,不是测量,是沉默被当成了无罪。**
