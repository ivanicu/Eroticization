# R308 · 把「最像的那一个」回归掉,残差还剩什么

## 结果:「最像外向」是纯粹的剖面层巧合
| | 分数层相关 | |
|---|---:|---|
| `corr(c3⊥D, extroversion)` | **−0.1010** | 而**剖面层是 +0.7091** —— **符号都相反** |
| `corr(c3⊥D, openness)` | **−0.0414** | 几乎是零 |

| 臂 | 29 个结局越阈 | 区间 |
|---|---:|---:|

正对照完美:把 extroversion 从**它自己的带噪声复制**里回归掉,残差越阈 **0.0 ± 0.0**。

> **两个分数层相关 −0.10 的量,结局剖面可以相关 +0.71。**
> **而把其中一个整个扣掉,另一个几乎不损失(15.7 → 14.3)。**
