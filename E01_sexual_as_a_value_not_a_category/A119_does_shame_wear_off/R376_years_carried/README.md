# R376 · 这个设计里问不了「带了多少年」—— 它问出来的是起始年龄

⚠⚠ **横断面 -> 只能说关联,不能说「磨掉」。** 写在设计里,不是写在讨论里。

## 数字
| | ↔ 羞耻 |
|---|---:|
| 带了多少年(原样) | −0.0045 |
| **控制当前年龄** | **+0.0857** |
| **+ 控制 `S`** | **+0.0621** |
| + 再控制起始均值 | −0.0008 ⚠ 过控制(三者共线) |
| 参照:当前年龄 | −0.0670 |
| **参照:起始年龄均值** | **−0.1024** |

n = 6,676;「带了多少年」中位 12.6 年;MDE 0.0342;负对照(打乱人)−0.0017 ± 0.0127。

## ★★ 而那个 +0.0621 是一个恒等式
**带了多少年 = 当前年龄 − 起始均值**,所以
`partial(年数, 羞耻 | 年龄)` **在代数上就等于** `−partial(起始均值, 羞耻 | 年龄)`。

**实测:+0.0857 vs +0.0857,差 5.55e-17;加控 `S` 后 +0.0621 vs +0.0621,差 5.55e-17。**

> **⇒ 这个设计里问不了「时长」。给定年龄,时长携带的**恰好**是起始年龄的信息,一点不多。**
> 那个「控制年龄后带得越久越羞耻」的说法,**是「起始越早越羞耻」的另一种写法。**

## ⇒ 能说的与不能说的
- **不能说**:羞耻会不会随时间磨掉。**这份数据结构上答不了**(时长 = 年龄 − 起始,三者线性相关)。
- **能说**(而且它本来就在直接可测的量里):**起始年龄越早,羞耻越多** ——
  `corr(起始均值, 羞耻)` = **−0.1024**。
- ⚠ 正对照(种入一个真的随年数下降 0.10 的结局)只读出 −0.0504(1.5×MDE,**没到我注册的 2×**)
  —— **所以即使时长效应可分离,这个设计的功效也只到这里。**

## 一句关于人的话
**一个性兴趣来得越早,它带的羞耻越多。**
而「带得久不久」这件事 —— 在这份数据里问不出来,因为一个人带了多久,
恰好就是他多大减去它什么时候来的。
