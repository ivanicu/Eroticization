# R03 · 三个量,一台机器

`#160` 的 NEXT 问:`#160c` 的 0.105 和 `#63` 的上界是不是同一件事。
而账本里已经有第三个可比的数 —— **`Entry 8`**:「时间表贴合度是一种个人特质」被杀掉,
**跨类别分半 Spearman-Brown = 0.214,"mostly measurement noise"**。

三个量放进**同一台机器**(同一批人、同一种劈分、同一个 k、同一个 SB):

| | 问的是 |
|---|---|
| **S** | 你**喜欢**多罕见的东西 |
| **a** | 共享时间表**贴合你**的程度(成对顺序准确率) |
| **z** | 你的罕见兴趣比时间表**早多少** |

## 结果

| 每半单位数 k | **S** | **a** | **z** |
|---:|---:|---:|---:|
| 4 | 0.5663 | 0.1182 | 0.1124 |
| 5 | 0.6072 | 0.1458 | 0.0759 |
| 6 | 0.6330 | 0.1960 | 0.1065 |
| 7 | **0.6817** | 0.1935 | 0.1610 |
| **均值** | **0.6221** | **0.1634** | **0.1140** |

- **a 与 z 分不开**:差 +0.0494,**1.3× 展布**。
- **a 与 S 差 +0.4587,12.2×** —— 可分辨。
- 三个种植全部开火(S 0.57→0.99 · z 0.11→0.66 · a 0.12→0.55);三个置换零都在 ±0.06 内。
- **`Entry 8` 报的 0.214,在这台机器上是 0.194–0.196**(k=6,7)—— 那条早期撤回的数立得住。

## 一句话

> **关于「何时」,两个完全不同的问法给出同一个小数字。**
> 「共享时间表贴合你多少」= 0.16;「你偏离它多远」= 0.11 —— 分不开。
> 而「你喜欢多罕见的东西」= 0.62,**高一个数量级**。
>
> **一个人的性偏好里,「什么」是他自己的;
> 「何时」—— 无论你问贴合还是问偏离 —— 几乎都不是。**
