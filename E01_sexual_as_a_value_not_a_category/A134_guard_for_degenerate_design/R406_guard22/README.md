# R406 · guard 22:一条只有一个点的曲线,会让下游每一个判据都通过

⚠ **Closure(工具),如实标注。**

`#361b`:`R405` 的设计退化成一个点,而**注册的 kill(「全距 > MDE?」)与 guard 21(三件套齐)
都在那个点上通过了** —— 两个判据都对着一个点开火,而没有一个问「曲线有几个点」。

## 守卫做什么
任何以**曲线 / 扫描 / 剂量-反应 / 规格曲线**作证据的判据**之前**调用:
传入 x(扫描的自变量)与可选的 y;
**不同 x 的个数 < 3 -> FAIL(设计退化)**,不让下游判据开火。

## 六个用例,6/6
| 用例 | 预期 | 结果 |
|---|---|---|
| `#404` 的六点覆盖曲线 | PASS | PASS |
| `#390` 的三点节点扫描 | PASS | PASS |
| **`#405` 的一点曲线** | **FAIL** | **FAIL** |
| x 全相同(4 点但 1 个 x) | FAIL | FAIL |
| 非数 / x-y 长度不一致 | FAIL ×2 | FAIL ×2 |

守卫库现有 **26** 个可调用的判据。

## ⚠ 边界
**它检的是「有没有曲线」,不检曲线「对不对」** —— 一条有六个点但每个点都算错的曲线,它照样放行。

## 一句关于人的话
没有 —— **但从此以后,一条曲线要先证明自己是一条曲线,才轮到它的全距被读。**
