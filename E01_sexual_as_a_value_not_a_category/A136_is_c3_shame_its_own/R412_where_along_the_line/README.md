## ★ 本轮真正的产出是两件基础设施
**① guard 24 —— 分量必须先被定向,才轮到它的标签(`#368a`)。**
第一版直接照着 `np.linalg.eigh` 的输出写标签:「PC1 高 = 更年轻/性经验更少/…」。
**实测平均羞耻从 Q1 的 1.179 掉到 Q5 的 0.266 —— 正好反过来。**
**特征向量的符号是任意的**,而所有从分量读出的**量**都符号不变(R² · 共同性 · 保留率 · |cos|),
**所以门永远看不见它;它只在散文里现形。** 本项目第四次(R210:73 · `#306b` · `#361` · 本轮)。
⚠ 第一版 guard 24 用绝对阈 0.02,**纯噪声 1000 次里有 ~33% 通过** —— 阈值必须相对于自己的采样地板,
改成 `3 se`;重攻后 **0/1000**,且随 n 缩放(弱真信号 r≈0.05 只在 n=5000 才锚得住)。

**② 地板重建 —— 一个永远不会开火的判据。**
第一版 offset 地板是**段内对半**。它的**正对照失败了,而它是对的**:
效应集中在一段时,那一段的半样本噪声把地板自己撑到 **0.5567**,吞掉了真实的 **0.4861**。
**一个偏保守的地板对「未越阈」是更强的结论,对「越阈」却是一个永远不会失败的检验。**
改成**把人在五段之间随机重排(段大小不变)** —— 五段真值按构造相同,而每段仍是全样本量。
正对照随即通过(0.4210 vs 0.1000)。
