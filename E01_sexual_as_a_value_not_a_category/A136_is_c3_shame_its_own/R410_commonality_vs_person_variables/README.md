# R410 · `c3⁻` 那份羞耻不是独有的 —— 而咬掉它的五个量说的是同一种人

`#365` 的 NEXT 期待的是「若全部 ≈ 0 -> `c3⁻` 的那份羞耻是**独有**的」。
**注册的 kill 反向开火(OVERTURNED,不是 UNVERIFIED):20 个里 13 个单独越阈。**

⚠ 先分清:`#309b` 证明的是这些变量**不调节**羞耻。
**「不调节」与「不共线」是两件事** —— 一个变量可以完全不改变斜率,却把整条关系吃掉。

## 主结果(n=6,606,`c3⁻` 单独对羞耻 R² = 1.671pp)
| | 值 |
|---|---|
| 全 panel 联合共享 | **+0.674pp**(整行置换零 +0.007±0.017,95 分位 +0.032)|
| `c3⁻` 的唯一成分 | **0.996pp** -> **保留 59.6%** |
| 单个最大的一口 | **性伴数 18.9%** · 外向性 14.9% · 年龄 8.8% |
| 单独越阈 | **13 / 20** |

**⇒ 40% 被普通人层量吃掉,60% 没有。**

## 五口咬的方向**完全一致**
| 量 | ↔`c3⁻` | ↔羞耻 | 吃掉 |
|---|---:|---:|---:|
| 性伴数 | −0.1494 | −0.0943 | 18.9% |
| 外向性 | −0.0911 | −0.1142 | 14.9% |
| 年龄 | −0.0939 | −0.0670 | 8.8% |
| 神经质 | +0.0600 | +0.0940 | 8.3% |
| 无力感 | +0.0561 | +0.0880 | 7.3% |

**更年轻 · 性经验更少 · 更不外向 · 更焦虑 · 更觉得没有主动权** —— 五个都指向同一个人。

## 对照
正对照(V = `c3⁻` + 同幅噪声)共享 +0.7383pp、保留 **54.8%**;负对照(纯噪声)+0.0006pp、保留 **100.0%**。
⚠ **刻度而非检验(k 不同)**:一个**真是 `c3⁻` 加噪声**的变量保留 54.8%,20 个普通量合起来 59.6%。

## ⚠ 本轮同时修了一个基础设施缺陷 —— guard 23
`Gate` 只有**两个**出口。一个**对照健全、阈值反向开火**的 kill 被印成 `UNVERIFIED`。
那是 P6 的镜像错误:把 UNVERIFIED 折进 OVERTURNED 制造**假赦免**,
把 OVERTURNED 折进 UNVERIFIED 制造**假怀疑** —— **怀疑会被重试,反驳会被放弃。**
而本项目的盆地规则是「同一问题连续两轮 UNVERIFIED 就换方向」——
**这个误标直接污染盆地检测器本身。**
`asserted(..., kind='control')` 声明对照;9 个攻击向量,含两个旧调用的逐字节回归。

## 局限
`c3⁻` 是在全体人身上估的(`#347`:坐标本身会过拟合)。它同时进入分子与分母,保留率大体稳健,但绝对 pp 是上界。
`心理疾病(Any)` 与 `童年逆境(Any)` 的 NaN 被读成 0 —— 把「没有」与「没作答」并成一档,已在代码里标注。
共同性是记账项,不定因果方向。「没有一个量吃掉它」若成立也只等于「**这个问卷里**没有」。

而剩下的 60%,这二十个量合起来也认不出来。**
