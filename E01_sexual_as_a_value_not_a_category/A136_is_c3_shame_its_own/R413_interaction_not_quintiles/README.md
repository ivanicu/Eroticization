# R413 · 换估计量,不换问题 —— 那 92% 真的是摊在整条线上

`#368d`:分段设计的 MDE 是 **+0.20**,有意义的集中是 +0.05,差 4× -> 「均匀」报不了。
**但 0.20 是那个估计量的极限,不是数据的极限。**
五段各 1,322 人,全距是**五个噪声量的极差** —— 所有统计量里最不稳的一个。

## ① 先算 MDE,再看系数(`#312a`)
沿 PC1 线性种植,每级 40 次:
`+0.010` 15% · `+0.020` 42.5% · **`+0.030` 80%** · `+0.040` 97.5% · `+0.050` 100%。
**线性 MDE = 0.030**(分段设计 0.20 —— **低了一个量级**)· 有意义 0.05 -> **可以看系数**。

## ② 实测
| | |
|---|---|
| 交互 `c3⁻ × PC1` | **−0.00042** · se 0.01201 · 95% CI [−0.024, +0.023] |
| offset 零 | **+0.00005 ± 0.01183** · \|值\| 95 分位 0.02243 |
| 距零 | **−0.04 sd** · **未越阈** |

⚠ **零的种类**:`offset_control`,而且这个零不该是零 —— `corr(c3⁻, PC1) = +0.1632`,
乘积项与两个主效应共线,会**借到**主效应的一部分。
零 = **只置换 PC1**(保住 `c3⁻ ↔ 羞耻`,只打断 PC1 的配对)。

## ③ ⚠ scope:交互是**线性**形状,所以 MDE 有两个
正对照只是**擦线过**(+0.02295 vs 阈 0.02243),而它种的是**阶跃**。
| 形状 | MDE(80% 检出) |
|---|---:|
| 线性沿 PC1 | **0.030** |
| 阶跃(只有最高五分位) | **0.150** |

`#368e` 的分段界挡住 ≥ **0.20** 的阶跃 -> **0.150 与 0.20 之间没有缝。**
**⇒ 两种形状都被覆盖,零是完整的。**
