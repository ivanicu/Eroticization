# R411 · 那 40% 是**一个**维度,不是二十个 —— 但「同一种人」这句话里有一半是我读出来的

`#366c` 我写的是「最大的五口方向完全一致 —— 它们是同一种人」。
**那是一个一维性主张,而我从来没测过它。** 本轮测。

## ① 一维性是真的,但很薄
对齐后(每个量都指向更高的 `c3⁻`)相关矩阵的 **10/10 非对角全为正**,中位 **+0.0920**。
特征值 1.446 · 1.135 · 0.901 · 0.774 · 0.744 -> **PC1 份额 28.92%**。

⚠ **零的种类(`offset_control`,而且必须点名)**:这个零绝不该是零,有**两**个原因 ——
(i) 五个变量的 PC1 天然 > 1/5;(ii) **更要命的是我按 `c3⁻` 对齐了符号**,
让每个 `corr(V_i,c3⁻)>0` 会在 V 之间**诱导** ≈ `r_i·r_j` 的相关下限。
所以零 = 合成五个量,各自与 `c3⁻` 的相关等于实测 |r|(0.149 · 0.089 · 0.094 · 0.060 · 0.057),其余独立,
**走同一条对齐流程** -> **20.88% ± 0.23%**,95 分位 21.32%。

**实测 28.92%,越阈,+35.2 sd。一维性是真的。**
⚠ **但它很薄**:一个**真单因子**(载荷 0.7)给 **59.55%**。28.9% 离那儿很远。

## ② ⚠ 而「五个同号」几乎不含信息
「同号」= `corr(V,c3⁻)·corr(V,羞耻) > 0`。20 个变量里 **16 个同号(80%)**。
**随机 5 元组全同号的频率 = 4368/15504 = 28.2%。**
**⇒ 我那句「五个都指向同一个人」里,「同号」那一半是修辞,不是测量。**

## ③ ★ 但 PC1 一个维度,做掉二十个变量 92% 的活
| | 拿走 `c3⁻` 那份羞耻的 |
|---|---:|
| 全 20 个 panel(`#366a`) | 40.4% |
| **选出五个量的 PC1** | **37.1%** |
| 占比 | **92%** |

## ④ ⚠ 最强混淆:这五个是**在同一份数据上按同一个判据挑出来的**
所以 37.1% 必须对着**随机 5 元组的 PC1** 比,不能对着 0。
**随机 5 元组拿走 8.3% ± 7.7%**(95 分位 22.8%,300 次里最大 32.2%)。
**选出的 37.1% 高出 +3.8 sd,超过 300 次抽取的全部。**

## 对照
正对照(真单因子)59.55% · 负对照(五个独立噪声)20.45%(贴着零 20.88%)· offset 零非退化。
**五个门全过。**

## 一句关于人的话
**`c3⁻` 那份被普通人层量吃掉的羞耻,是**一个**东西,不是二十个:
一条「更年轻 · 性经验更少 · 更不外向 · 更焦虑 · 更觉得没有主动权」的薄薄的共同线,
一个维度就做掉了二十个变量 92% 的活。
⚠ 而「他们是同一种人」这句话里,「方向一致」那一半在 20 个变量里 28% 的时候会自己发生 —— 那一半我要收回。**
