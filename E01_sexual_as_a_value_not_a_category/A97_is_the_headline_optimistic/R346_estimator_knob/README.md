# R346 · 1.4% 是样本内的 —— 换到没见过的人身上是 1.09%

`#300a`:网格只能覆盖已知的旋钮,所以这一轮**发明一个**能弄坏头条数字的旋钮。

## 四个估计量,同一批数据
| 估计量 | 29 个结局的联合 R² 中位 | 相对已发表 |
|---|---:|---:|
| ① 样本内 OLS(**已发表的 1.4%**) | **1.390%** | — |
| ② 调整 R²(解析改正) | 1.239% | −0.151pp |
| ③ **5 折人层交叉验证** | **1.087%** | **−0.303pp** |
| ④ 岭 + 交叉验证 | 1.056% | −0.334pp |

**这是目前 `CALIBER.md` 里最大的一个旋钮 —— 此前单个最大是 0.18pp。**
n 中位 4,717,解析预期的乐观偏倚 p/n ≈ **0.127pp**,而实测缩水 **0.303pp,是它的 2.4 倍** ——
因为**六个坐标本身也是在这批人身上估出来的**,不是外来的固定预测量。
⚠ **2/29 个结局的 CV R² 为负** —— 对那两个结局,六个坐标在没见过的人身上比用均值还差。

| 总体 R² 真值 | 样本内 | 调整 | **CV** |

**CV 在这里量得准,而且偏在安全的一侧。**

## ⚠ 这条**不**解释 `CALIBER.md` 那 0.85pp
`#314` 的 2.23% 比 1.37% **高** 0.85pp,而本轮的修正方向是**向下**。
**它没有关掉那个缺口,它在旁边开了一个新的。**

## ⚠ 这个 1.087% 本身还是上界
本轮的 CV **固定了六个坐标**(在全体人身上估的),只对回归系数做折叠。
**真正的嵌套 CV 要在每折内部重估坐标**,那只会更低。所以 **1.087% 是样本外表现的上界**。

## 一句关于人的话
页面上那个 1.4%,是在**同一批人**身上算出来的。
**换到没见过的人身上,它是 1.09%** —— 六个坐标能带走的东西,比页面上写的少五分之一。
