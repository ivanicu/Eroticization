# R316 · 拆开 1.38% → 2.23%,并决定公开页的口径

`#269d` 说两处同时变了(S 的构造 + R² 的估计式),而我把它们归成了一件事。拆开:

## 2×2:估计式**根本不重要**,而 S 把数推**低**了
| | 最小二乘 | 相关矩阵 |
|---|---:|---:|
| 旧 S(不随块变化) | **1.37%** | **1.37%** |
| 新 S(`#267c` 修好的) | **1.21%** | **1.21%** |

**估计式的主效应 = +0.00pp** —— 两者**逐位相同**,因为**它们本来就是同一个量**
(最小二乘 R² 与 `r' Rxx⁻¹ r` 在标准化之后是同一个式子)。
**S 的主效应 = −0.17pp** —— 新 S 让数**变低**,不是变高。

## ⚠ 于是 `#314` 的 2.23% 在这一轮**复现不出来**
`#264a` 的 1.38% 复现到 **1.37%**(旧 S + 最小二乘)。
`#314` 的 2.23% 对应的格子(新 S + 相关矩阵)在这里是 **1.21%**。
**两个注册的原因都解释不了那 0.85pp。**

> **`#314` 的 2.23% 记为「未复现」** —— 它来自那一轮里我没有隔离出来的其它构造差别
> (覆盖阈值、清晰度的最小块数等)。
> **一个数在两轮之间变了,而两个我能想到的原因都不是它 —— 那说明还有第三个我没记下来的选择。**

## 决定
**公开页的 1.4% 保持不变**,并注明口径:**旧 S + 最小二乘**(`#264a`),本轮复现 1.37%。
替代口径(新 S)给 1.21% —— **两者都在 1.2–1.4% 区间内,结论不变。**

## 一句关于人的话(方法轮)
我以为两个口径差 0.85 个百分点,拆开之后发现**其中一个原因根本不存在**(估计式不影响),
另一个的方向是**反的**(−0.17pp)。**而那 0.85pp 至今没有归属。**
