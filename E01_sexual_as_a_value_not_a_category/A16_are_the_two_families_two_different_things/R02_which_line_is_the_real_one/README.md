# R02 · 哪条线是对的?

`#137g`:早/晚这条线在外部锚上是六个同样连贯的分割里**最弱**的。所以问题从"我挑的这条线
对不对"变成"**哪条线是对的**"。6 个特征向量分割 × 11 个非性变量的整格,多重性由
**最大统计量零**(把非性变量在人之间打乱,重算整格,取 |最大差|,200 次)一次性控制。

⚠ **标度**:去掉性别后的差在 0.033–0.088 之间。小。可报的是**方向与排序**。

## 判定

**这张性版图真正被心理学锚住的主分界线,不是"先来后到",而是"物件 vs 叙事"。**
`#135`/`#136` 的早/晚两族在**组织度**与**到达方式**上是真的,但它们不是版图的**主轴**。
