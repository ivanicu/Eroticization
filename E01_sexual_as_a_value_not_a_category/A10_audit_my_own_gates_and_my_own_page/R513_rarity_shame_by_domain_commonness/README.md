## ② 设计:用来分组的东西,不是被测量的那个东西
稀有度在**块内**算(一个人在该块勾到的选项的平均意外度);
分组按**块的人群勾选率**(该块的选项到底有多常被勾)。**两者不同源。**
两组分数进**同一个模型** -> 组间比较是**人内**的。
**对照**:两组稀有度分与合并 `S` 的相关 **+0.737 / +0.922** -> 它们确实在量稀有度。

## ★★ ③ 结果

**常见领域 +0.0422 · 罕见领域 +0.0956 · 差 +0.0534**,自助 **[+0.0192, +0.0901]**(不含零)。

## ⚠ ④ 一条有利于结论的噪声方向,也要说
越罕见的块,每人能平均的勾选项越少 -> 稀有度分越吵 -> **会压低**它的斜率。
**所以这里发现的方向是保守的那一侧。**
