# R525 · 让那条推断成立的东西,正是让它无法被检验的东西

⚠ **FRONTIER**。`#480` 的 NEXT:**锚集**从没被审过 —— 把所有方向已确立的量都放进去,重跑。

## ① 候选集先数(`#474a` 的判据)
**4 个**(openness · conscientiousness · neuroticism · agreeableness)-> **小到可以整批手读。**

## ⚠ ② 前置把锚集又缩了一次,而这一步在看任何数之前
四个候选与 `extroversion` **同一条计分流水线**(`#429d`:n、范围、步长全同)->
**共享的编码约定会复现所期待的符号,无论真相如何** -> **`extroversion` 对它们不是合法的锚。**
合法锚集 = 流水线之外的五个(三个计数 · `pornhabit` · `bondageaverage`)。

## ⚠ ③ 符号先验在**任何相关被计算之前**写下(这是 `#480c` 的修补)
| 特质 | 事先写下的先验 |
|---|---|
| openness | 弱正(开放性涵盖兴趣广度)—— 可辩护但弱 |
| conscientiousness | **无可辩护先验** |
| neuroticism | **无可辩护先验** |
| agreeableness | **无可辩护先验** |

**⇒ 即使四个全部越杠,也最多只有一个能读出方向。**

**对照**:`powerlessness` 在加宽后的锚集里**复现 0.174 并过杠**(`#480b`);正对照 0.196 / 0.247 全过。

## ★★ ⑤ 于是那条循环可以被点名
**让「隔一层继承」成立的东西 —— 同一条计分流水线 ——**
**恰恰就是让它在内部无法被检验的东西。**
⇒ 那条继承**不是拿来替代测量的捷径**,而是这份释放版留下的**唯一**一条路。
