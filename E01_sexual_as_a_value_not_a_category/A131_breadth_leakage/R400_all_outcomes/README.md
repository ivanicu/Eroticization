# R400 · 六个坐标解释的东西里,中位 18% 与「你报了多少」共线

`#355b` 只在 `animated` 上看到这一点。**这一轮量它有多普遍。**

⚠ 统计量是标准的**共同性**(commonality = 只A + 只B − 合并),**它可以为负**(抑制)。

## 对照(两个都是我第一版设计错、由它们自己抓出来的)
- **正对照**(只由类别数驱动):共同性 **3.619pp** ✓
  ⚠ 第一版的门槛「共同性 > 只类别数 R² 的 50%」问的是一个**不由它决定**的比例 ——
  种入越强,独有增量越大,占比越小。**我设计错了。**
- **负对照**(与 `ncat` **无关**的纯噪声结局,20 次):**+0.0027 ± 0.0245pp** ✓
  ⚠ 第一版把结局建在**与六坐标正交的 `ncat` 残差**上 -> **必然**产生抑制(−4.46pp)——
  **那检的是我的构造,不是统计量。**

## `#300a` 的旋钮:换一个广度代理
用**块覆盖数**代替起始类别数:共同性中位 **0.263pp** · 为正 **25/29** ·
`corr` **+0.4120** · **两个代理的共同性向量相关 +0.8920**。
**⇒ 这是「广度」的性质,不是那一个变量的。**

## 一句关于人的话
六个坐标解释一个结局时,**中位有五分之一其实与「这个人在问卷里报了多少东西」共线**;
而结局越好解释,这个比例越高。

⚠ **边界**:共同性是**分解的记账项**,不是因果量 —— 它只说「这部分共线」,
不说是坐标带着广度还是广度带着坐标。
