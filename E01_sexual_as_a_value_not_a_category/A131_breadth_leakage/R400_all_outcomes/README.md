# R400 · 六个坐标带着「报告广度」,而且遍及 29 个结局

`#355b`:类别数单独能解释 `animated` 的 2.648%,独有增量只有 1.137pp ——
剩下约 1.51pp **已经藏在六个坐标里**。**那其余 27 个结局呢?**

统计量 = **共同性**(commonality = 只类别数 R² + 六坐标 R² − 合并 R²),即被两边共享的那部分。

## 分布(29 个结局,窄口径)
| | |
|---|---:|
| 中位 | **0.345pp** |
| 均值 | 0.458pp |

**`corr(共同性, 六坐标联合 R²)` = +0.6091 —— 解释力越大的结局,共享得越多。**

## ⚠ 两个对照第一版都是我设计错的
- **正对照**:我注册的是「共同性必须占只类别数 R² 的 50% 以上」——
  **那个比例不由统计量决定**(种入越强,独有增量越大,共同性占比越小)。
  正确的问法是**共同性明显为正**:实测 **3.619pp**(只类别数 R² 13.126%)。
- **负对照**:我把结局建在**与六坐标正交的 ncat 残差**上 —— **那必然产生抑制**(共同性为负,−4.46pp),
  检的是我的构造不是统计量。改成**与 `ncat` 无关的纯噪声结局**:**+0.0027 ± 0.0245pp**,正好为零。

**⇒ 改正后全部门通过。而这是本会话第六次门槛/对照设错,六次都是对照自己发现的。**

而且越是能被解释的结局,这个比例越高。
