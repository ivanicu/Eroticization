## ⇒ 本轮真正新的只有一件事:**定位**
`#356a` 说「六个坐标里有一份广度共线」。**本轮说它在哪:在 `S`,不在 `c1/c2/c3`。**
而 `S` 的广度负载本身**已被 `#164` 处理过并带着零** —— **定位不改变那条结论,它只是让下一次追问知道该去哪。**

## ⚠ 而我的构造推理错在哪
我以为「除以勾选数」就消掉了广度。**没有** ——
除法消掉的是**计数**,消不掉**组成**:勾得多时,均值向该块的平均稀有度回归;
勾得少时它可以很极端。**`S` 的**方差**依赖勾选数,而不只是它的均值。**
