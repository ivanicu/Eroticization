# R377 · 起始越早,羞耻越多 —— 每一项检查都过了

`#331b` 的 −0.1024 是**顺带**报的,而 `#324b` 的教训是顺带的数最容易被高估。**给它一个设计。**

## ① 逐类别:普遍,不是几个类别扛的
31 个类别里 **28 个为负**,中位 **−0.0712**,范围 [−0.1226, +0.0202]。

## ② 控制之后保留 79%
| | ↔ 羞耻 |
|---|---:|
| 原样 | **−0.1024** |
| 控制类别数 | −0.0938 |
| **+ 控制 `S`** | **−0.0810**(保留 79%,2×MDE = 0.0683) |

## ③ 去衰减 + 区间
类别分半信度 **0.9242**(`corr(半A, 半B)` = +0.8591)—— 这条量得很稳。
**去衰减 −0.1065,自助 95% 区间 [−0.1339, −0.0822]。**

## ⚠⚠ 删失敏感性
起始年龄分档到 **26yo+**,删失率 **3.4%**。
**只用「一个 26yo+ 也没有」的人(n=5,566,占 83%):−0.0684** —— 同号、同量级。
