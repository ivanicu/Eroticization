## ⚠ 而我在这一轮重犯了自己写下的那个错
负对照第一版直接 `permutation(FORM)` —— **把 NaN 也搬了位置**,缺失模式被打乱,SVD 直接不收敛。
**`#264b` 就是我亲手写下的这条教训**:「置换必须只在有限值之内进行,缺失模式保持原样」。
⚠ 另外正对照第一版用的是**已在模型里的位置分 S** —— 设计矩阵精确奇异,**连跑都跑不起来**。
**一个正对照如果用的是模型里已有的量,它不是弱,是无效。**
