# R319 · 一个最朴素的「你离常模有多远」,打不打得赢这六个坐标

这个项目有六个坐标、14 个守卫、一张口径清单,而它对羞耻的联合解释是 2.77%。
**从没有人问过一个更朴素的对手。**

`atypicality` = 一个人**所有**块上所选选项的**平均稀有度** ——
不残差化、不特征分解、不劈半、不留一。**最朴素的那一个。**

## 结果:装置赢了,而且赢得干净
| | 对羞耻 |
|---|---:|
| `atypicality` 单独相关 | **+0.1148** |
| `atypicality` 单独 R² | **1.32%** |
| 六坐标联合 R² | **2.79%**(`#264a` 报 2.77%,复现) |
| 两者合起来 | 2.88% |
| **`atypicality` 在六坐标之上的增量** | **+0.09 ± 0.10pp** —— **与零不可分辨** |
| **六坐标在 `atypicality` 之上的增量** | **+1.56 ± 0.38pp** —— **4.1×** |

⚠ 必须先报的:`corr(atypicality, 位置分 S)` 见运行输出第 2 行 —— **S 就是它的留一残差化版本**,
所以结论只用**增量 R²**,不用单独 R²。

> **六个坐标把这个朴素对手**完全吸收**了,并在它之上再加 1.56 个百分点;
> 而朴素对手在六个坐标之上加不出任何东西。**

## 一句关于人的话
「你喜欢的东西有多冷门」这一个数,就能解释羞耻的 1.3%。
**这个项目花了 81 个弧建起来的六个坐标,把它整个吃掉,然后再多解释 1.6%。**
这是这套装置第一次被一个真正朴素的对手检验 —— 而它过了。
