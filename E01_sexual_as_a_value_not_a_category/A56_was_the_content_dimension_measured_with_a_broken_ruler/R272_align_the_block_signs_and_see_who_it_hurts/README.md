# R272 · 把块的主成分符号对齐,然后当场判它伤到了谁

`#226b` 测到 `R210:73` 把 32 个块的主成分人分**直接相加**而从没对齐符号,
17 个块的载荷为正、15 个为负。这一轮修尺子,并在同一轮内判它伤到了谁。

## 修法
共识法**留一**对齐:人分 = Σ_b s_b·z_ib;s_b = sign(corr(z_·b, **其余块**的人分)),迭代至不再翻。
⚠ 留一是必须的 —— 若共识分包含块 i 自己,块 i 与它必然正相关,符号永远不翻,
那就是一个不可能失败的检查。**实测翻了 15/32 个块。**

⇒ 整块 `UNVERIFIED`。**但作用域要说清**:
