## `#118` 就是一个刀尖,而且它宣布的"加强"没有发生

| | 位移 | 自助展布 | 强度 |
|---|---:|---:|---:|
| n≥400(原) | +0.03392 | 0.01097 | **3.0928** |
| n≥250(加倍后) | +0.03181 | 0.01043 | **3.0484** |

- **写死的门槛是 `r250 >= 3`,实测 3.0484 —— 高出 1.6%。**
- **加倍样本后强度从 3.0928 走到 3.0484,略微下降。** 而源码打印的是
  「**加强成功,按新强度引用**」—— 那句话是假的,什么也没加强。
- **而"3.0 还是 3.1"本身在噪声里**:20 个不同的自助重抽种子给出 **3.023–3.163(sd 0.035)**。
  **一个设在 3 的门槛,落在这个噪声带里。**

**`#118` 的效应本身没问题**(+0.0339,3.1× > 可分辨门槛 2×,46/68 为正,种植对照单调)。
被改的是**那句关于"加强"的话**。
