# R01 · 「去衰减 ≤ 0.362 所以是三条轴」—— 这个 0.4 是刀尖吗?

## 先纠正我自己的路标

`#140` 的 NEXT 写着「0.362 与 0.349 几乎相等」。**那是两个不同的量:**

- `0.349` = 族内 PCA 成分 vs **随机载荷**全类别坐标的**留出 |相关|**
- `0.362` = `A02` 手工命名量表之间的 `r_obs / sqrt(alpha_a · alpha_b)`

**数字接近是巧合,不是等价。** 但底下的担忧合法,只是要用 `A02` 自己的量来问。

## `A02/R034` 的实际数字

`POWER` alpha = **0.686**(3 题)· `GAZE` alpha = **0.163**(2 题)· `coord4` 分半 = **0.337**
判定写死在源码里:`mx < 0.4 → "still three axes"`。

| 对 | 原始 \|r\| [2.5, 97.5] | 去衰减 \|r\| [2.5, 97.5] |
|---|---|---|
| P-G | 0.080 [0.053, 0.106] | 0.239 [0.157, 0.328] |
| P-C | 0.112 [0.086, 0.140] | 0.233 [0.179, 0.292] |
| G-C | 0.085 [0.057, 0.117] | **0.362 [0.243, 0.528]** |

正对照(`POWER` 的 3 题劈成 2+1,题目已定向)= **0.872**。负对照(合成独立数据)= **0.012**。

## 判定:KNIFE —— 但被切的是**报告的数字**,不是结论

**max 去衰减 \|r\| 的自助区间 = [0.259, 0.528],跨过 `A02` 写死的 0.4 的比例 = 30.2%。**
也就是说:**三次重抽里有一次,同一个脚本会打印 "collapses — the axes may be one construct
measured badly"。**

不确定性**全部**来自 `GAZE` 的 2 题 alpha = 0.163(自助 [0.114, 0.207]),
它给出的去衰减因子是 **4.27×**。

**而原始相关又小又紧:三对全部 ≤ 0.112,95% 上界全部 < 0.15。**

> **`A02` 的结论站得住,但它引用错了自己的证据。** 稳的是原始相关(≤0.112),
> 不稳的是去衰减最大值(0.362,CI 宽 0.27)。README 已改成引用前者。

## 一条可迁移的方法学结论

> **去衰减是为保守而做的,但它把一个稳的量换成了一个不稳的量。**
> 在信度低的地方,校正因子自身的方差比被校正的量还大 —— 而**报出来的永远是校正后的那个,
> 因为它看起来更严谨**。任何用短量表做的去衰减相关都有这个问题。

## 我在这一轮里也踩了一次

第一版给量表的题目**随机翻符号**,两个对照当场都塌了(正对照只到 0.567,负对照返回 `None`)。
原因是同一个:**没定向的 alpha 不是信度。** `A02` 用的是有意的符号(`worship` 取 −1),
而我把它换成随机,alpha 就变成了噪声。定向后正对照 0.872、负对照 0.012。
