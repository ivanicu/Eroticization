# R273 · breadth 是回答风格,还是一个真的人格维度

`#227b` 把第三个人层维度正名为 **breadth**。`#193c` 曾撤掉"默认赞同因子",
而 breadth 现在从内容维度那条路走了回来。`#26` 说这份数据分不开"默认赞同"与
"真的被更多东西唤起" —— **但那是对单一 Likert 量表说的,对 32 个块的结构从没被问过。**

## 第一段(设计不合身,记录下来是因为它的失败方式值钱)
块层载荷谱:每块与**留一** breadth 的跨人相关。全样本 +0.5145 ± 0.0757,
扣掉 `(选项数, 平均勾选率)` 后残差展布 0.0724 —— **块规模只解释 8.6%**。
残差谱跨人分半复现 **+0.8917 ± 0.0320**,置换零 +0.0407 ± 0.0931。

**但这把尺子量的不是人。** 载荷是**块的属性**;任何与人无关的块性质(不止规模)
在两个人群半样本里都会完美复现 —— 未扣块规模时复现 +0.8889,扣掉后 +0.8917,
**几乎不动**,这正是它分不开两个世界的证据。

⚠ 而它的正对照也没点着:种入"只在一半块上更宽"的人,分开度只有 **+0.0088**。
强度扫描 0.05→+0.0076 · 0.15→+0.1792 · 0.30→+0.4064 · 0.60→+0.5968 ——
**我又一次硬编码了种入强度**(`#211a` 已经教过一次),而 0.05 比可观测量级低一个数量级。

## 第二段(合身的设计:把测量放回人身上)
**块内选项劈半**。同一个块的两半选项是对**同一个人×块格子**的两次独立测量;
块的属性对两半相同、被块中心化扣掉,剩下的只有"**这个人在这个块上是不是格外宽**"。
剖面 `r_ib = p_ib − 留一breadth_i`,再块中心化。

| | |
|---|---:|
| 人×块残差剖面的两半复现 | **+0.4290 ± 0.0141**(77,872 格) |
| 置换零(劈开**之后**两半各自独立打乱) | **+0.0043 ± 0.0012**(效应的 1%) |
| 种入人×块特异宽度,g → 复现 | 0.02→0.4393 · 0.05→0.4477 · 0.10→0.4789 · 0.20→0.6056 · 0.40→0.8188 |

⚠ **零第一次是坏的,而它坏的方式值得记**:我在**劈选项之前**打乱人,
两半拿到同一次置换,人×块这个格子原封不动 —— **零 +0.5835 比效应 +0.4290 还高**。
零比效应高,是零坏了,不是效应没了。

## 判决
★ 注册的 kill **点着了**,负对照干净(1%),强度扫描全程单调。
⚠ **但正对照的注册条款没过**(0.4789 vs 要求的 0.4893),我没有事后改它。
它没过的原因本身是一条教训:**基线不是零,是 +0.429 —— 因为现象就在那儿。**
一个要"涨 0.05"的正对照,是在跟真信号抢地方;
**正对照的增量必须对着实测基线定价,不是对着零定价。**
⇒ 整块 `UNVERIFIED`,结论按 **D6** 报,不按已定论报。

## 作用域(不要越写)
这一轮证明的是:**breadth 不只是一个单一的全局回答风格 —— 它有可靠的领域结构。**
它**没有**证明全局水平里不含回答风格。**全局高度**与**剖面形状**是两件事,这一轮测的是后者。

## 一句关于人的话
"对什么都说是"的人,其实**不是对什么都说是** ——
他在某些事情上格外宽、在另一些上并不,而**这个形状在同一批题目的两半上复现到 +0.43**。
所谓"默认赞同",至少有一半是**一个人真的被哪一类东西打开**。
