## ★ 而成分 3 给了这个项目一个它没有预料到的对手
`#179` 起,这个项目的主 claim 是**位置分 ↔ 羞耻 = +0.1185**。
同一道羞耻题,**成分 3 给 +0.1286 —— 更大**,而 `corr(c3, 位置分) 只有 +0.2036`。

> **通向羞耻的路不止一条,而且这条新的、几乎独立的路,比这个项目建立在上面的那条还要略强一点。**

成分 3 的块载荷(`R274`):高端 nonconsent scenarios · urine · transformations · abnormal body states;
低端 sensations · sex acts。读法是 **"对越轨类别宽,而不是对普通性行为宽"** —— 但这是**载荷的读法,`D5`**:
特征向量的旋转不可识别(`#229` 已记),所以**这个得分是明确的,它的名字不是**。

## 作用域
- 三个成分共享同一批人、同一批块、同一条管道,所以剖面本来就不会独立 ——
  判据是 **offset(同一件事该有多像)**,不是零。**先问「这个零应该是零吗」:不应该。**
- c1 与 c3 的剖面相关 **+0.789**,所以"三条不同的剖面"要收窄成
  **"至少两条明显不同的剖面"**(c2 与 c1 只有 −0.061)。
- 全部在 `n = 6,717`(块覆盖 ≥8)上,不是全样本。
