# R217 · 那道闸,用 git 历史回测它会拦下多少

`tools/readme_gate.py` 把四条规则接成单一入口:
`named_defects`(#170)· `numbers_that_left`(#171)· `uncited_numbers`(#145)· `internal_consistency`(#144)。

**判的是增量,不是绝对值。** 当前绝对命中 2 个,**两个都是已确认的假阳性** ——
`+0.023` 同串两指(`#170b`)、`3.14` 是 python 版本号。绝对值判会拦下每一个提交,
拦截率 100% 而信息量 0。

## 结果

**正对照通过**:`7b1951f`(`#170a` 的去重提交,`#171` 已确证它删掉了 `+0.2523`)**被拦下**。

**拦截率 5/30 = 16.7%**,而注册阈值 20% **落在噪声带内**(0.5× 自身噪声)→ **阈值判定 UNVERIFIED**。
不是"闸不需要",是"这个 n 上答不了"。

## 被拦的 5 个,逐条分诊

| 提交 | Δ点名 | Δ离开 | 离开的数 | 判 |

**一个拦截不是一个缺陷。** 5 个里 1 个是真缺陷、2 个是被正确撤回的量级、其余待判 ——
这正是它的 `P6` 代理账说的:**它的 FAIL 是"去看一眼",不是"你错了"。**

## 本轮修掉的两个自己的错

1. **静默截断**:第一版任一文件缺失就 `return None` —— 老提交里还没有 `README_zh.md`,
   于是 20 个样本**静默变成 9 个**,脚本一声没吭。缺文件按**空文件**处理(那正是当时的事实),
   并显式 `check_coverage`。现在 30/30。
2. **归一化 bug**:英文写 `10.4×`、中文写 `10.4 倍`,字符串不同 ——
   于是**每一次翻译都被判成删除**(`63e03b7` 一次假报 7 个)。差集之前归一化,降到 2 个。

## 结构上做不到

规则只看**数字**。一句被删掉的**限定语**(scope · instrument · population)不带数字,这道闸看不见。
