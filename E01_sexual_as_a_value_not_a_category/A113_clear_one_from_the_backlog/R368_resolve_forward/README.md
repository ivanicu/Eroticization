# R368 · 那份 29 条的清单是个过计数,而自动判「已解决」的方法不可用

按 `#322` 写好的规则挑第一条 -> **`#24`**。
**而 `#24` 就是 POWER–SUBSTANCE,`#321` 上一轮刚给了它区间 [+0.5608, +0.6591]。**

> **清单把「这一条自己有没有区间」当成了「这一条有没有被解决」。**
> **一个 UNVERIFIED 可以被后来的某一轮解决,而证据写在那一轮里,不在它自己里。**

**然而正对照失败:`#24` 的前向解决者被判为空。**
因为 **`#321` 引的是 `#143`/`R043`,不是 `#24`** —— 同一条声明在不同轮次里换了编号。

> **引用图不是解决图。一条声明可以在另一个编号下被解决。**

**⇒ 那个 19/29 不成立,10 条的欠账数**也**不成立。** 两个都按 UNVERIFIED 记。
