# R402 · 那张共享时间表,现在有了它自己的证据 —— 以及一个上限

`#120` 被 `#130` `#333c` `#336` 等十几轮引用,**而它自己的证据只有一组均值。**

## ① 分辨率:那 31 个均值是分得开的
**全距 3.37 年 · 自助 95% 区间平均宽 0.34 年 · 465 对里只有 87 对重叠(19%)。**
**⇒ 注册的 kill ①(「区间大量重叠」)没有开火 —— 排序是被分辨出来的,不是噪声。**

## ② 它**不是**冷门度造成的
`corr(类别起始均值, 类别稀有度)` = **+0.0640**(31 点)——
换三套年龄编码后是 **+0.0314 / +0.0640 / +0.0908**。**这条排序与「多少人有」无关。**
⚠ 这一条**不依赖**「内容类 / 关系类」那个二分 —— **本轮完全没有使用它**
(它是谁分的没有来源,所以不用)。

## ③ 「共享」这个词站得住,但有一个上限
| 比较 | Spearman ρ |
|---|---:|
| **正对照**(合成已知顺序) | **+0.9992** |
| 随机劈半(**参照臂 = 天花板**) | **+0.9661** |
| 年龄档两两 | +0.9028 · +0.8746 · +0.9343 |
| **男 vs 女** | **+0.8052** |
| **负对照**(打乱每个人的类别标签) | **−0.1685** |

**⇒ 顺序在各组间高度复现(0.80–0.93),对着 0.97 的天花板与 −0.17 的地板。**
**但男女之间的 0.805 明显低于随机劈半的 0.966 —— 时间表是共享的,但不是同一张。**

⚠ **负对照的构造要说清**:打乱**人**不破坏类别顺序(每一列还是那一列)——
**正确的负对照是打乱每个人内部的类别标签**,它给出 −0.1685。

## 一句关于人的话
性兴趣到来的**先后顺序**,在男人和女人之间、在不同年龄的人之间,是**同一张表** ——
它不是「冷门的东西来得晚」,而且这三十一个时间点是真的分得开的。
**但男女之间那张表也不是完全同一张:0.81,而同一群人随机劈两半是 0.97。**
