# R382 · 在格层复现了那个次可加 —— 而格层的时间表已经被中心化掉了

`#336b`:人层扣不掉时间表(代数上是减一个常数)。**到人×类别那一层做。**

⚠⚠ 跑之前写下的陷阱:**147,387 行来自 13,517 人**,一个人贡献多行而羞耻只有一个值 ——
**解析标准误会把 n 虚增 11 倍。本轮只用「打乱人」的置换零。**

## 格层结果
| | 系数 | 置换零(打乱人,400 次) | |
|---|---:|---:|---:|
| `dev`(比该类别的人群中位**更早**) | **+0.08185** | −0.00003 ± 0.00713 | **5.74×** |
| `rar`(该类别的稀有度) | **+0.06824** | −0.00028 ± 0.00370 | **9.26×** |
| **`dev × rar`** | **−0.00936** | +0.00000 ± 0.00345 | **1.36×**(置换 p = **0.010**) |

正对照(格层种入 `dev × rar`,再聚合回人层):
g=0 → −0.00074(0.11×)· g=0.02 → +0.00858(1.24×)· **g=0.05 → +0.02363(3.43×)**。

## ⇒ 重叠那一段**不是**人群时间表
`dev` 是**逐类别中心化**后的量 —— **人群时间表在它里面已经被减掉了。**
**而次可加在这一层仍然出现(负号,置换 p = 0.010)。**

> **⇒ 「在**冷门**的东西上**比别人更早**」这两件事,在格这一层就已经重叠了。**
> **它不是「早来的兴趣本来就更冷门」这个人群事实的影子。**

⚠ **量级要如实**:1.36× 的 2×展布(≈2.7 sd),置换 p = 0.010 —— **真,但不大**。
主效应(5.74× / 9.26×)比它清楚得多。

## 一句关于人的话
**在同一类兴趣里比别人来得更早**,和**这类兴趣本身有多冷门**,各自都带来羞耻;
而两样都占的格里,**加起来比两份之和略少** ——
这在把「哪类东西什么时候来」这张人群时间表减掉之后,依然成立。
