# R381 · 这个设计在人层扣不掉人群时间表

`#335` 的 NEXT:用「相对于人群时间表来得多早」(`EARLY_rel`)替换绝对起始,
看 `S × EARLY` 的次可加会不会塌。

## ⛔ 先报的那个控制当场失败了
| | |
|---|---:|
| `corr(EARLY_rel, EARLY_abs)` | **+0.9983** |
| `corr(EARLY_rel, S)` | **+0.2154** |
| `corr(EARLY_abs, S)` | +0.1952 |

**两个变量几乎是同一个,而 `EARLY_rel` 与 `S` 的相关反而**更大**。这一步什么也没扣掉。**

## 原因是代数的,不是数据的
`EARLY_rel_i = mean_{j∈J_i}(中位_j − 起始_ij) = mean_{j∈J_i}(中位_j) − MO_i`

**人群时间表只经由 `mean_{j∈J_i}(中位_j)` 进来 —— 而那一项只随「他答了哪些类别」变,
不随时间表本身变。** 大家答的类别集又高度重叠,所以那一项几乎是常数。

> **在人层做「逐类别中心化再平均」,等于减掉一个近似常数。**
> **要扣掉人群时间表,必须在**人×类别**这一层做,不能先平均再扣。**

## 交互本身(为完整起见)
| | 系数 | \|t\| | 全族 p | 过阈 |
|---|---:|---:|---:|:--:|
| `S × EARLY_abs` | −0.0395 | 3.357 | 0.004 | 是 |
| `S × EARLY_rel` | −0.0425 | **3.624** | **0.002** | 是 |

正对照(种入 `S × EARLY_rel` = 0.15):|t| **12.21**,过阈 —— **判据本身有分辨力,
是被检验的那个变量没被改动。**
