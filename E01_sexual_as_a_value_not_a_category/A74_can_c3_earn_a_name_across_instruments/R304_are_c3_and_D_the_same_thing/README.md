# R304 · c3 与跨块对比 D 是不是同一件事

`#296` 的总表把它们列成两行,而两者都在说「越轨 vs 普通」。

## 结果:大体是同一件事,但残差可分辨
| | 越阈(29 个结局) | 最强的几个 |
|---|---:|---|
| c3 | **18** | `animated` +0.200 · `I am aroused by be…` −0.155 · **羞耻 +0.129** · `written` +0.112 |
| D | **11** | `I am aroused by be…` −0.116 · **羞耻 +0.088** · `neuroticism` +0.055 · `written` +0.054 |

**剖面相关 +0.7826**,offset(同一件事的两次带噪声读数)**0.9142 ± 0.0171** ——
**是上限的 86%,低于它 7.7 个展布,但绝对差只有 0.13。**
正对照两端都过:已知不同 0.1324 · 同一变量两次带噪声复制 0.9957。
`corr(c3, D) = +0.1589`(⚠ 分数层相关低,而**剖面层相关高** —— 两者说的是同一批结局)。

**注册的 kill 两个分支都没干净地点着**:
它要求「贴上限 → 合并」或「低于上限 0.15 以上 → 两行」,实测差 **0.1316**,恰好在线下。
⇒ `UNVERIFIED`,按 **D6**:**大体同一,残差可分辨但小。**

## ⚠ 一个必须说的口径差
本轮的信度是**半块信度**(c3 0.2105 · D 0.2378),因为 `rel()` 只用一半的块;
它们与总表上的 **0.5631 / 0.6785**(全仪器)**不是同一个口径**,不能并排读。
本轮内部一致(offset 用的就是这两个半块信度),但**不要把 0.2105 写进总表**。

## 一句关于人的话
「你把开放花在哪儿」这件事,用两种方式量出来 ——
一种看你在哪些块上宽(D),一种看块之间怎么协同变化(c3)——
**它们说的几乎是同一批话,但 c3 说得更多(18 vs 11)。**
