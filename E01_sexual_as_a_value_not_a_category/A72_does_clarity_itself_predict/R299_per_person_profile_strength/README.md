# R299 · 「一个人的剖面有多清晰」本身预测什么

`#296` 的总表里「宽度剖面」那一行的 ↔羞耻 与 越阈两格是 `UNCOMPUTED`,
因为剖面是一个**人×块矩阵**,不是标量。诚实的问法不是硬造标量,而是问**清晰度**本身。

`strength_i` = 这个人的残差剖面在**两半选项**上的一致性(`#228a` 的量,逐人而非合并)。

## 结果:可测,但几乎什么都不预测
| | |
|---|---|
| 分半信度(块劈半,4 次) | **+0.3093**(+0.382 · +0.287 · +0.287 · +0.281)—— 过 0.2 的可测门槛 |
| 29 个结局越阈 | **4.1 ± 1.8,读作 0–8** —— **区间含零** |
| ↔ 羞耻 | **+0.0148 ± 0.0116(1.3×)** —— 不可分辨 |
| 最强的几格 | `highenergy` −0.063 · `I've acted upon or…` +0.062 · `If my partner is ar…` +0.047 |

## ⚠ 但这是一个**没有功效证明**的零
正对照(种一个人×块特异结构,守卫 13 判方向)给出 10.2 → 11.8 → 10.6 → **7.0** —— **非单调**,
守卫 13 拒绝认证灵敏度。**种入再一次干扰了被测量本身**:
`strength_i` 是一个**一致性**度量,而种入一个跨块结构会同时改变它的分子与分母。

> **所以这一格不能写「0(已测)」,只能写「不可分辨,且功效未证明」。**
> 一个没有功效证明的零,和一个 `UNCOMPUTED`,只差一点点 ——
> 但它比 `UNCOMPUTED` 多了一件事:**它告诉你下一个人该从哪里接着做。**

## 表上那两格的更新
从 `UNCOMPUTED` 改为 **`+0.0148 ± 0.0116(1.3×)` / `0–8(含零)`,并标注「功效未证明」**。

**但在这 29 个结局上,它几乎什么也没说** ——
清晰或模糊,和你羞不羞耻、你是什么样的人,看不出关系。
(⚠ 而这句话的把握有限:我没能证明这个设计看得见多大的效应。)
