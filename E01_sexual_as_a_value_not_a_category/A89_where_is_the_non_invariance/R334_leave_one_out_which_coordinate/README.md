# R334 · 哪一个坐标带来了非不变性(留一)

`#288a`:非不变性是**整套结构**的,**但没说是哪一个坐标带来的**。
`#285b` 逐坐标比剖面那一格因展布 0.4247 不可用,而 `#286b` 证明**联合层是稳的**——**所以用留一**。

## 结果:去掉位置分 S,非不变性完全消失
| 去掉哪一个 | 保留集 22 道上的差 |
|---|---:|
| (基线,不去掉) | **−0.1144** |
| **位置分 S** | **+0.0118** ← **差消失** |
| 跨块对比 D | −0.061 |
| c2 | −0.085 |
| 剖面清晰度 | −0.096 |
| c1 | −0.115 |
| **c3** | **−0.298** ← **去掉它反而更糟** |

**正对照完美**:把位置分 S 换成一个**按性别驱动的合成量**,留一**正确指认出 S**
(换掉后去掉 S → +0.0336,其余各项仍在 −0.13 到 −0.45)。
⚠ **而真实数据里去掉 S 给的是 +0.0118 —— 与「S 就是那个性别驱动量」的情形几乎一样。**

> **非不变性的来源是**位置分 S** —— 而 `c3` 是最稳的那一个(去掉它差扩大到 −0.298,
> 说明它一直在把两组拉近)。**

## 这与 `#164`/`#209` 不矛盾,而且必须一起读
`#164`「位置分不是性别的影子」· `#209`「去性别后信度不变」—— **两条都还站着**。
**它们问的是「S 是不是性别」,答案是不是。**
**本轮问的是「S 在两组里是不是同一个东西」,答案是不是。**

> **S 不是性别,但 S 在两个人群里意味着不同的东西。**
> 这两句话同时为真,而它们此前从没被放在一起。
