# R458 · 类别层有一堵**结构性的墙**:31 个类别就是整个仪器

⚠ 先按 `#396b` 查了一条腿:`corr(类别中位起始, 稀有度) = +0.3406` **已在 `#370b` 估过** —— 不是新信息。
真正没被问过的是**残差**:「这个类别比它的稀有度所预测的**更早**还是**更晚**到」有没有意义。

## 结果:未越阈,而零也不可发布
| | |
|---|---|
| `corr(off, 平均羞耻)` | **+0.0740** |
| offset 零(**在人层打乱羞耻,重算每个类别的平均羞耻**) | +0.0125 ± **0.1463** · 95 分位 **0.2924** |
| | **+0.42 sd,未越阈** |

⚠ **零的种类**:`offset_control` —— 「中位起始」与「平均羞耻」**都在重叠的人群上聚合**,
所以零由「**人层打乱羞耻后重算类别均值**」构造,**精确保住类别之间的人群重叠结构**。

## ⇒ 而这不是功率不足,是**一堵墙**
**`n_eff` = 31 个类别 —— 而 31 就是这个仪器的全部。**
offset 零的 sd 就有 **0.1463**,阈 **0.2924**,MDE **0.45**。
**⇒ 这份数据上,任何低于 ~0.45 的类别层相关都是看不见的,而且没有办法再加类别。**
**这与 `#381d`(`S` 的两性差)是同一种墙:不是没做,是做不到。**

## ⚠ 而极端值会骗人 —— 这一轮正好演示了
「延后到」的两个类别平均羞耻 **0.591 / 0.756**,「提前到」的两个是 **0.370 / 0.467** ——
**看起来像一条清楚的正相关,而实际相关只有 +0.074。**
> **⇒ 31 个点里的头尾各两个,不是那条关系的代表,是那条关系的噪声。**
> 而它们**恰好同号**,所以读起来会更像证据。**这正是「看排序头尾」最危险的地方。**
