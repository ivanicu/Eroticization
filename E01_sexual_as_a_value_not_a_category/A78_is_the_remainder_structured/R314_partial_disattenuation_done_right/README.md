## 而它没有定义这件事,本身就是答案
解衰减假设**测量误差是随机且独立的**(我在 `IMPOSSIBLE` 里登记过)。
把相关除以 √(信度×信度) 之后**超过 1**,只能是两种情况之一:
① 信度被低估了;② **这六个量共享测量误差** —— 而这正是登记过的那个假设失效。

> **② 几乎必然为真:六个量全部由**同一次选项劈半**构造出来 ——
> 它们不是六个独立的测量,是同一次抽签的六个投影。**
> **所以「把这六个量测准」这个建议,本身就建立在一个错的模型上。**
