# R311 · 六个坐标之后,剩下的 98.6% 是噪声还是结构

`#264a`:六个人层量联合解释中位 1.4%。**但它没说剩下的是噪声还是结构** ——
而这直接决定这个项目该不该继续找第七个维度。

## 结果:残差谱**低于** offset —— 没有第七个维度
| | 观测 | offset(把六个坐标换成六个随机量) | 超出 |
|---|---:|---:|---:|
| λ1 | **2.0693** | 2.1132 ± 0.0006 | **−0.0439** |
| λ2 | 1.7271 | 1.7945 ± 0.0006 | −0.0674 |
| λ3 | 1.4821 | 1.5185 ± 0.0005 | −0.0364 |

| λ5 | 1.2421 | 1.2261 ± 0.0002 | +0.0160 |
| λ6 | 1.1492 | 1.1686 ± 0.0004 | −0.0193 |

**前 6 个的总超出 = +0.0220**,而 λ1 是 **−0.0439**(即观测**低于** offset,69.6 个展布)。

> **扣掉这六个坐标之后,29 个结局的残差之间剩下的共同结构,
> 比扣掉六个**随机量**之后还少。**
> **这六个坐标已经吃掉了这份数据里可被线性人层结构解释的部分 —— 1.4% 就是这个仪器的天花板。**

## ⚠ 而这个零的功效是**有限**的,必须说清
正对照(种入一个已知第七维)g = 0 / 0.05 / 0.15 / **0.40** → λ1 超出
−0.0439 / −0.0468 / −0.0594 / **+0.9954**。
守卫 13 **拒绝认证**:小 g 处非单调(弱种入在结局间交替符号,部分抵消)。
**所以这是「对一个足够强的第七维有功效」的零,不是「对任何第七维有功效」的零。**
可测到的最小值介于 g=0.15 与 0.40 之间。
