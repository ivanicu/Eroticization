# R01 · 成年后加进来的东西,是旁边那一块还是别处?

## 三条证据线,一条干净、一条脏、一条只是复述

对 29–32 岁、17 岁前后都有条目的人(1,462 人;早 8.6 个 / 晚 4.7 个),
把「晚获得」与「早获得」的类别对比。零是**人内置换早/晚标签** —— 精确保留这个人的类别集
与晚的个数,只摧毁"哪些是晚的"。

| 证据线 | 晚 − 早 | 人内置换零 | 倍数 | 判定 |
|---|---:|---:|---:|---|
| **与早期集合的连通性** | −0.0047 | +0.0076 | **6.7×** | **干净** |
| **去掉稀有度后的连通性** | **−0.0042** | +0.0076 | **6.5×** | **干净,保留 89%** |
| 评分 | −0.1815 | −0.0136 | 6.3× | ⚠ **UNVERIFIED**,`#114` 贡献 248% |
| 稀有度 | +0.2284 | +0.0016 | 20.3× | **复述** `#130a`,不是新证据 |

**判定:EXPAND。** 晚获得的类别与这个人早期那些**更不相连**,不是更相连。

- `#114` 的回忆偏差在两条连通性线上都**符号相反**(+0.0022 / +0.0013),校正只会放大效应。
- 稀有度不是它:在**配对层**把 `rar_a + rar_b`、`rar_a · rar_b`、`|rar_a − rar_b|` 回归掉
  (稀有度解释了配对相似度的一部分方差),连通性差保留 **89%**。
- 评分那条如预注册所料是脏的:`#114` 说人把最爱的记得更早,这条通路**单独**就能造出
  「晚来的评分低」,而且它给出的伪影是效应的 248%。**不读。**

## 标度,写清楚

连通性的基线是 +0.1398,效应 −0.0047 —— 晚获得的类别比"人内随机挑同样多个"**低约 3.4%**。
**小,但测得很准**(6.5–6.7× 自身自助展布)。不要把它说成大效应。

## 被跳过的 35%,本身是一句话

29–32 岁档共 2,259 人,进入分析 1,462 人。跳过的 797 人里:

- **17 岁后一个新兴趣都没有:753 人 = 该档的 33.3%**
- 早期条目不足 3 个:44 人 = 1.9%

**三分之一的人,版图在 17 岁就关上了。** 剩下三分之二的人,它是向**外**开的。

## 残余缺口(本轮测不了)

自报的获得年龄被 `#114`/`#119` 证明是被扭曲的。`#114` 的通道(越爱越早)符号相反已排除,
但还有一条**反向回忆**通路没被排除:*「这个东西跟我其余的不搭,所以它一定是后来才有的」* ——
即连通性低**导致**被报成晚,而不是晚**导致**连通性低。横断面自报数据分不开。
