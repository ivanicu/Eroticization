# R02 · 「不搭,所以一定是后来才有的」—— 这条通路活着吗?

`#133` 自己写下的残余缺口:连通性低可能**导致**被报成晚,而不是晚导致连通性低。
这条通路是**回忆过程**的性质,所以它应随回忆衰减而加深 —— 而 `#119` 已独立测到
「记忆畸变随年龄加深,十五年里几乎翻倍」。年龄梯度就是它的印记。

## 反向回忆:预测的印记不存在

| 年龄档 | n | 连通性差(固定切点) | 倍数 | `#114` 斜率(正对照) |
|---|---:|---:|---:|---:|
| 14-17 | 418 | **−0.0088** | 5.8× | −0.1391 |
| 18-20 | 525 | −0.0072 | 6.1× | −0.1581 |
| 21-24 | 1,231 | −0.0045 | 5.3× | −0.1815 |
| 25-28 | 1,434 | −0.0057 | 7.7× | −0.1772 |
| 29-32 | 1,632 | −0.0069 | 10.9× | **−0.2920** |

**效应在全部五档上都可分辨、同号,而年龄趋势是 +0.000133/岁 —— 最年轻的一档效应最大。**
同时年龄仪器在 `#114` 的斜率上从 −0.1391 走到 −0.2920(与 `#119` 独立测得的 3.5× 同向),
**所以它不是没有检出力**。反向回忆的预测印记 ABSENT。

## 但 `#133a` 的**量级**要降级

| 切点 | n | 晚的个数 | 连通性差 | 倍数 |
|---:|---:|---:|---:|---:|
| 13.5 | 1,729 | 8.4 | **−0.0165** | 29.2× |
| 15.5 | 1,817 | 6.7 | −0.0110 | 17.1× |
| 17.5 / 19.5 / 21.5 | 1,632 | 5.2 | −0.0069 | ~10.5× |
| **人内中位数分割** | 1,841 | ~6.5 | **−0.0006** | **1.0×** |

- **方向在每一个绝对年龄切点上都一致**(全部为负,10–29×)。
- **量级差 2.4 倍**,所以可报的是方向,不是量级(frontier §2)。
- **人内中位数分割不可分辨(1.0×)** —— 这个现象**不是**"你自己序列里靠后的",
  而是绑在**绝对年龄**上的。中位数分割把绝对年龄打散,效应就消失。

## 三个精度修正

1. **`#133` 的"晚"实际是 19 岁以后,不是 18 岁以后。** 起始年龄的分箱是 17.5 → 22 → 28,
   所以 `V > 17.5`、`V > 19.5`、`V > 21.5` 选出**完全相同**的集合(n 与效应逐位相同)。
2. **我预测的剂量方向又反了**(本会话第二次,见 `#132b`)。写的是"切点越晚效应越强",
   实测是切点越**早**效应越大。
3. **我第一版把置换基线当"零"来断言,那是问错了问题。** 它是两个随机半边之间的平均连通度,
   天然为正(+0.0047…+0.0075),零假设**不预测它为零** —— 所以它是 `offset_control` 的偏移量,
   不是 `negative_control` 的零。
