# R04 · 「一整套」是字面意义的吗?

`#135d` 证明的是人的晚期集合**富集**于关系族,**没有**证明它们在**同一时间**到达。
这一轮直接测时间上的靠拢。

## 两个必须先解决的设计问题

1. **族不能用时间定义**,否则是拿同一批数据既选样本又下结论。
   这里用**共现的谱分割**定义族 —— 共现与获得年龄是两个不相交的仪器。
2. **人群时间表本身会让族内靠拢**(关系族的题目平均起始年龄都在 16.8–17.0)。
   所以离散度必须在**题目去均值后的残差**上量。

## 结果

| 族(共现谱分割) | n | 族内离散度 | 人内置换零 | 差 | 倍数 |
|---|---:|---:|---:|---:|---:|
| **A**(21 个:束缚 · 权力动态 · 施虐受虐 · 非自愿 · 性玩具 · 羞辱) | 9,904 | **2.2608** | 2.4954 | **−0.2347** | **17.7×** |
| **B**(10 个:身体部位 · 温柔 · 外观 · 衣物 · vore · 异常身体) | 8,921 | 2.4511 | 2.2488 | **+0.2023** | 12.1× |

> **关系性的那一族是一起到的;具体的那一族是一个一个到的。**

族 A 比同样多个随机挑的**靠拢 9.4%**;族 B 比随机**分散 9.0%**。
⚠ 起始年龄的分箱是 **2.0 年**,这是离散度的地板;比这更紧的打包本设计看不见。

## 「只是平均更晚」这个混淆,在代数上不可能

**sd 对平移不变**,所以"这一族只是整体来得更晚"**不可能**影响这个统计量。
数值验证:把整族平移 5 年,离散度 **2.2607600611 → 2.2607600611**,差 0.00e+00。
这与救了 `#116` 与 `#128b` 的是同一种结构免疫。

## 我在这一轮里写坏了两次对照

- **第一版**:「族内置换时间」——**sd 对置换不变**,所以它逐位给出同一个数(2.2608 vs 2.2608)。
  一个在构造上不可能失败的检查(`#96a`)。
- **第二版**:改成从这个人**其余类别**取捐赠残差 —— 撞上 `same_scale`,因为捐赠池
  (非族 A)不是零的池(全部类别),给出一个无法解释的中间值 2.3160。
- **正确的答案不是一个对照,是上面那条代数事实。**
  **当一个混淆对你的统计量在代数上不可能时,该做的是陈述并数值验证那个不变性 ——
  而不是造一个对照,因为你造的任何对照都会在别的地方与零不同。**
