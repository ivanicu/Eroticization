# R03 · 有边界吗?—— 没有边界,但有两族

`#134d` 把「晚获得的更不相连」定位在**绝对年龄**上。`#134e` 发现切点扫描被分箱卡死。
这一轮绕开切点:对每个 (人, 类别) 求它与这个人**其余类别**的平均去稀有度连通度,
按获得年龄分箱画一条曲线。

## 曲线单调上升,穿零,没有拐点

| 获得年龄分箱 | n | 连通度 − 人内置换零 |
|---:|---:|---:|
| 2.0 | 457 | −0.00959 |
| 7.5 | 2,971 | −0.01125 |
| 11.5 | 14,812 | −0.00696 |
| 13.5 | 26,256 | −0.00261 |
| **15.5** | 28,471 | **+0.00128** ← 穿零 |
| 17.5 | 20,577 | +0.00470 |
| 22.0 | 20,749 | **+0.00579** |
| 28.0 | 4,260 | +0.00525 |

**拐点检验 UNVERIFIED**(增益 0.703,置换零的 95 分位 0.754,1.6×)—— 两个对照都过:
种植的真拐点被检出(0.805),种植的**纯直线不触发**(0.385)。**所以曲线是连续单调的,
没有边界。** `#132`/`#133` 里"版图在 17 岁关上"的措辞,对**连通度**不成立
(对**类别数**仍成立 —— 那是 `#132d` 的另一个量)。

## 而它与 `#133a` 的表面矛盾,揭示了一个块结构

`#133a` 说晚→早的连通度**更低**;这条曲线说晚的类别连通度**更高**。两者同时为真,
当且仅当**晚获得的类别彼此抱团**。直接测:

| 块 | 真实 | 人内置换零 | 差 | 倍数 |
|---|---:|---:|---:|---:|
| 早 × 早 | −0.00531 | +0.00740 | **−0.01272** | 27.9× |
| **晚 × 晚** | +0.02743 | +0.00640 | **+0.02103** | **23.1×** |
| 晚 × 早 | +0.00263 | +0.00747 | −0.00484 | 15.2× |

## 那一族是什么

| 最常晚到(19+) | 比例 | 最常早到 | 比例 |
|---|---:|---|---:|
| 怀孕 | 32.1% | 外观 | 8.6% |
| 感官 | 31.0% | 开始看色情 | 10.0% |
| 精神改变 | 28.1% | 衣物 | 10.9% |
| 施虐受虐 | 26.6% | 身体部位 | 11.1% |
| 束缚 | 26.3% | 神话生物 | 15.7% |
| 权力动态 | 26.0% | 乱伦 | 15.8% |

**题目层:最晚到的 8 个彼此 +0.06735,最早到的 8 个彼此 −0.00751,两组之间 −0.01902。**

> **早来的东西是散的,晚来的东西是一整套。**
> 早期获得的是具体的、彼此不相干的 —— 外观、衣物、身体部位。
> 晚期获得的是关系性的、彼此高度成套的 —— 权力动态、束缚、施虐受虐、精神改变、感官。

这与 `#75` 的时间表(外观 14.0 → 精神改变 17.0)是同一件事的两个侧面,
而**新的部分是"成套"**:`#75` 只说了先后,没说晚的那批彼此高度连通而早的那批不。

## 本轮做不到的

「关系族**作为一个包**到达」需要一个更强的检验:**在一个人内部,关系族的条目是不是
比同样大小的随机子集在时间上更靠拢?** 本轮只证明了人的晚期集合**富集**于这一族,
没有证明它们在**同一时间**到达。
