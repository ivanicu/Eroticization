# R209 · 「偏爱冷门」是不是性别的影子?

`#163a` 立住的是一个**位置**倾向。但它有一个没被问过的对手:`#101`/`#154` 说它
**唯一挂得住的外部锚是性别**(+0.093)—— **而性别本身也是一个"跨话题都成立"的位置变量**。
男性若在**每个**块上都挑更冷门的,就会产生一个完美可迁移的位置倾向,
而它不是"这个人的口味",是"这个人的性别"。

做法:把性别从**每一个块层分数**里回归掉,重跑 `#163` 的整台机器。

## 结果

| | 去性别前 | **去性别后** | 保留 |
|---|---:|---:|---:|
| **内容最不相似分半** | +0.5059 | **+0.5166** | **102%** |
| 随机分半 | +0.5894 | +0.5914 | 100% |
| **纯性别驱动的位置种植** | +0.9439 | **−0.0009** | **−0%** |
| 纯**个人**位置种植(去性别后) | — | **+0.9858** | — |

性别在块层分数里只解释掉**中位 1.32%** 的方差(最大 10.80%)。

## 两个对照必须一起看

- **纯性别驱动的位置种植塌到 −0%** → **残差化确实有效**,它能杀死一个由性别造出来的位置倾向。
- **纯个人位置种植存活到 +0.9858** → **残差化没有误伤**,它不会把真的个人倾向一起削掉。

**两个都开火,所以真实数据的 102% 是可读的。**

## 判定:INDEPENDENT

> **「偏爱冷门」是这个人自己的口味,不是他的性别。**
> 把性别从每一个话题块里回归掉,这个倾向**一点没少**(102%,4.9× 自身展布);
> 而一个纯由性别驱动的同型倾向,在同样的处理下**塌到 0**。

`#100` 的 0.46 不动。**这是本项目最老的那条现存声明的最后一个未做的对照,它过了。**

## 范围

性别在本 release 是二值自报,且与其它未测的位置变量(社会经验、暴露史)混在一起。
**"不是性别的影子"不等于"不是任何人口学变量的影子"** —— 只是性别是唯一一个
`#101`/`#154` 量到过外部锚的,所以它是唯一一个有具体理由怀疑的。
