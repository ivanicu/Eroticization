# R208 · 稳的是"偏爱冷门",还是"喜欢某一类东西"?

`#100` 的 S 是"勾选项的平均冷门程度",它同时含两件事:你**挑了哪些**(内容)与
你**挑得多冷门**(位置)。分离器很直接:**把块按内容相似度分到最不像的两端。**

- 若稳的是**位置**,它应当能传过去(冷门偏好与话题无关)。
- 若稳的是**内容**,它传不过去(你喜欢的那一族不在另一端)。

## 结果

| | 随机分半 | **内容最不相似分半** | 保留 |
|---|---:|---:|---:|
| **真实** | **+0.5973** | **+0.5059** | **85%** |
| 纯**位置**种植 | +0.9859 | +0.9855 | **100%** |
| 纯**内容**种植 | +0.9268 | **−0.0212** | **−2%** |

跨人置换零 **+0.026**(效应的 5%)。不相似分半上的信度 **31.6× 自身展布**。

**两个种植完美分开**(100% vs −2%),所以这个设计**能**分辨位置与内容 ——
而真实数据保留 **85%**,落在位置那一侧。

## 判定:POSITION,`#100` 的名字是对的

> **「偏爱冷门」是一个真的、可迁移的口味位置,不是"喜欢某一类恰好冷门的东西"。**
> 把话题换到最不像的另一端,这个倾向仍然带得过去。

⚠ 但 15% 确实掉了(**5.7× 自身展布**),所以**存在一个小的内容成分** —— 只是压倒性的部分是位置。

## 我在这一轮里写坏了两个东西,都是自己的对照抓的

1. **置换零是一次改标签,不是一次破坏。** 第一版写 `x = Bc[随机另一个人]` —— 把整个人换成
   **另一个人的整条向量**,两半仍来自同一个人,**置换什么也没破坏**。零给到 **+0.38 = 效应的 71%**。
   正确的零:**每个块独立跨人置换**,这样一个人的两半来自不同的人。改后零 **+0.017**。
2. **种植建在真实信号之上,所以内容种植塌不下去**(81%)。改成建在**零背景**上。
   而"不相似分半"也必须**显式跨族**(h1 全部取自对比轴下半族、h2 全部取自上半族)——
   第一版取"这个人自己块里 pc1 最低/最高的 k 个",块少的人两端会落在同一族里。

## 范围(预注册过)

"内容相似度"由共现给出,而共现本身与冷门程度相关(`#159b` 量到 −0.89),
所以最不相似的两半在稀有度构成上也不同。**这条由两个种植对照兜底**:
若那个相关是主要驱动,纯内容种植不会塌到 −2%。
