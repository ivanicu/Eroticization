## ★★ ③ 而活下来的是一句更准也更有用的话
**在 KILL 里:更宽 5/6。** 两条「更严」的是**一个对照**与**一个方向判据**。
**而两个方向的危险不一样:**
- **KILL 偏宽 -> 发布一个假的东西;**
- **对照偏严 -> 把一台好仪器判成坏的**(`#451b` 差一点就是)。

**⇒ 不是「我总是放宽」,是「我在 KILL 上放宽、在对照上收紧」——**
**而这两种错各自朝着它那类门最坏的方向。**
