## ★★ 而这是**第二次**(`#386` 的 NEXT 是第一次)—— 两次之后它是一个**类**

> **「加一个控制 M,看 X 的系数往哪走」,当 `X→M` 与 `M→Y|X` **都已经估过**时,
> 那个移动**由代数强制**,不可能是别的值 —— 它携带**零**比特的新信息。
> 它只在其中**一条腿没有被估过**时,才是一个检验。**

⇒ 而我连着两次把它写进 NEXT,原因是**它读起来像一个中介分析** ——
**而中介分析的信息量来自它的**假设**(无混淆),不来自那个算术。**
把假设拿掉,只剩算术,就只剩恒等式。

## 本轮不做 offset 零
**因为本轮不主张任何关于世界的东西**,只主张一个**算术关系**。
(`#312a` 的镜像:一个不主张世界的轮次,不需要世界的零。)

## IMPOSSIBLE
恒等式只在**标准化 OLS + 同一控制集 + 同一掩码**下精确;三者任一不同会有残差 —— 本轮三者都同。
