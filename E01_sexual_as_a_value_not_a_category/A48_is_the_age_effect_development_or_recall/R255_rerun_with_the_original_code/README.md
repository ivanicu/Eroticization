本轮载入 `R173` 的 `betas`/`demean_conv`(与 `#207` **同一条管道**),
**唯一改动是把 `V` 换成 `where(V ≤ 14, V, nan)`。**

**可判前提通过**:未截断时精确复现 `#206b`/`#207c` 的 **+0.153**。
**反号**,偏移 **11.0×** 自身展布(`offset_control` 的零命名为
「同一条管道在全部起始年龄上的值 —— 若截断无关,受限臂该落在那儿」)。

## 结论:`#206b`/`#207c` 那条观察是截断假象

**「年纪越大的人,他自己罕见的兴趣相对来得越晚」——** 撤回。
在**没有截断差异**的那一段(所有年龄段都能观测到的 14 岁前),这个关系**反号**。

## 什么**没有**受影响

`#199` 的「第三个维度」**不依赖这条关系** —— `#207a` 已证控制年龄后
rho_i 的 20 道面板只从 7/20 掉到 6/20。**倒下的是 `#206b`/`#207c` 自己那句观察,不是 `#199`。**

## 结构上做不到

截断后剩下的 **2,806 人(28%)不是随机子集** —— 他们是「14 岁前就获得 ≥8 个类别」的人,
**本身更早熟**。所以受限臂的 −0.0741 测的是**这群人**,
**它足以证伪全样本那条声明,但不足以支撑一条新的反向声明。**
