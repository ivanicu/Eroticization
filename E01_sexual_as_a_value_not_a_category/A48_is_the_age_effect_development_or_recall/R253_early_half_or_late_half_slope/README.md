# R253 · 早半斜率 vs 晚半斜率,哪一半与年龄绑得更紧

    DEVELOPMENT  只有**晚期一半**与 age 相关 -> 年长者确实在更晚才获得罕见兴趣
    RECALL       **两半同等**相关 -> 整条曲线被重排,`#207c` 降级成测量假象

## 判定:UNVERIFIED —— 本设计答不了

| | 早半 | 晚半 | 差(晚−早) |
|---|---:|---:|---:|
| **真实** | +0.0534 | +0.1113 | **+0.0580 ± 0.0141(4.1×)** |
| **负对照**(人内打乱) | +0.0706 | +0.1162 | **+0.0456 ← 真实差的 79%** |
| 正对照(只往晚半种 age 信号) | +0.0534 | +0.5174 | +0.4640 ✅ |

**负对照失败**:打乱起始年龄(保留曲目与年龄分布,只毁掉配对)后,
「晚半比早半更贴年龄」**几乎原样重现**。所以那个 +0.058 里**大部分不是配对带来的**。

**两半的人层信度都是 0.0000**(超额方差为零)——
每半只有中位 **6** 个类别,斜率在人层上是**纯噪声**。
**「哪一半与年龄绑得更紧」在本设计里比的是两个噪声量。**

## 三个自己的错

1. **无条件去衰减**:`rel ≈ 0` 时打印出 **+53.4** 与 **+111.3**。
   **信度为零时不存在"去衰减值"** —— 那是除以零。已加条件。
2. **print 侧无条件打出 `=> DEVELOPMENT`**,而负对照刚刚失败。
   **verdict 必须受同一个条件式管辖** —— `#181a` 的同一个 bug,**第二次**。已加条件。
3. **「两半信度可比」这条可判前提 PASS 了 —— 因为两个都是 0.000,差为 0。**
   **两台坏掉的仪器,在"可比性"这个检查下是可比的。**
   正确的写法是「两者都 ≥ 某个下限 **且** 可比」。

## 结构上做不到

两半各只有中位 6 个类别 —— **每半的斜率噪声都吞掉了全部人际方差**。
要分开发育与回忆窗口,需要**每人更多的起始年龄条目**,不是更多的人。
