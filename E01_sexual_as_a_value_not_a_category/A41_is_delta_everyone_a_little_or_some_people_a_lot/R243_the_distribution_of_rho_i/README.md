# R243 · rho_i 的分布

**参照是置换零,不是 0。** 题内跨人置换保留缺失模式与每题值分布,只毁掉配对 ——
所以它带着**完全相同的人内测量噪声**。这个零回答的是「只有噪声时该有多宽」。

| 臂 | mean | sd | ΔBIC(1−2) |
|---|---:|---:|---:|
| **真实** | **−0.0328** | **0.3573** | 297.2 |
| 置换零(5 个种子) | ≈ 0 | **0.3111** | 10.9–49.0 |
| 【正对照】双峰种植 | −0.0031 | 0.5270 | 2252.2 |
| 【正对照】单峰宽种植 | −0.0161 | 0.4885 | **792.1** |

## 宽度:确证

    超额 sd = √(var_real − var_null) = **0.1757**   (49.3× 自身 bootstrap 展布)
    展布 / |均值| = **5.4×**
    正态近似下 rho_i < 0 的人占 **57.4%**(11.8× 离 50%)-> 约 **43% 的人方向相反**

**Δ 不是"每个人都有的一点点"。它是一个很宽的分布上的一个很小的均值。**

## 模态:判不了,已撤下

**正对照二失败**:**单峰宽**种植也给出 ΔBIC = **792.1**,不到双峰的 1/3 以下。
在 n ≈ 10,000 上,2 成分混合几乎总是赢 1 成分(真实分布都有一点非正态)。
**ΔBIC 不是这里的双峰检验** —— 按条件式规则,**本轮不报模态判定**。

⚠ 所以那个 **57%** 带着一个**本轮无法检验的假设**(正态)。**宽度本身不带这个假设。**

## 本轮修掉的两个自己的错

1. **列名 `mean` 撞 pandas 方法** —— `#197a` 收紧后的 `check_columns` 在这一轮又抓到一个。
2. **误用 `same_scale`**:我拿它去断言"展布与均值同在 rho 尺度上",
   而它比的是两个量的**可比量级**(挡"拿 k=17 的数比 k=9 的数"那类错)。
   5.4× 恰恰是本轮的结论,所以那个断言等于在断言结论不成立。**守卫没错,用法错了。**

## 结构上做不到

`rho_i` 每人只由 8–31 个类别估出,**个体噪声很大** ——
所以 0.176 是人际差异的**下界**,而任何窄于噪声的双峰都看不见。
