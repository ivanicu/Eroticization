# R282 · 减法式正对照:人层信号的剂量-反应曲线

`#236c①`:本项目的正对照几乎全是**加法式**(种入结构看数变大),
而在**基线贴顶**的量上结构上无效(`#281` k=2 基线 0.9379、上限 1.0,种入后非单调)。
这一轮把**减法式**落成方法:随机把 λ 比例的人替换成置换噪声,扫 λ,**两端都断言**。

⚠ **先撤回我自己在 `#236` NEXT 里写下的一个推断**:我写了「小 λ 急降 -> 结构集中在少数人」。
**这不成立** —— 随机替换 λ 比例的人,平均而言同等比例地打掉集中型与分布型的贡献,
**这个操作分不开那两个世界**。它能给的是另一样东西,而那正是真正欠的:**一条真的功效曲线**。

## 两端都对上,而两条曲线的形状完全不同
| λ(被换成噪声的人) | 块:剖面复现 | 占基线 | 起始:k=2 子空间 | 占(基线−地板) |
|---:|---:|---:|---:|---:|
| 0.00 | 0.4504 ± 0.0089 | 1.00 | 0.9576 ± 0.0134 | 1.00 |
| 0.25 | 0.3487 ± 0.0125 | 0.77 | 0.9697 ± 0.0038 | 1.02 |
| 0.50 | 0.2579 ± 0.0028 | 0.57 | 0.9271 ± 0.0059 | 0.94 |
| 0.75 | 0.1445 ± 0.0037 | 0.32 | 0.8960 ± 0.0073 | 0.88 |
| 0.90 | 0.0613 ± 0.0022 | 0.14 | 0.6347 ± 0.0898 | 0.37 |
| 1.00 | 0.0053 ± 0.0026 | 0.01 | 0.4408 ± 0.0256 | 0.00 |

两端断言都过:λ=0 落在基线(`#228a` 0.4290 / `#236a` 0.9379),
λ=1 落在置换零(+0.0043 / 0.4587)。曲线单调不增。

**块的曲线几乎正比于 (1−λ)**(1.00 / 0.77 / 0.57 / 0.32 / 0.14 / 0.01 vs 1 / .75 / .50 / .25 / .10 / 0)。
**起始的曲线到 λ=0.75 几乎不动**,之后才塌。

> **★ 所以那两个数字不能直接比。**
> 起始仪器的 k=2 = 0.9379 **不是**比块的剖面复现 0.4290「强一倍」——
> 它是一个**四分之三的人换成噪声也还剩 88% 的量**。
> **一个贴着天花板的统计量与一个线性响应的统计量,数值上不可比。**

## ⚠ 我注册的「检测极限」定义是无信息的
我注册的是「掉到 λ=1 端 +2sd 以内的最小 λ」,两条都给 **1.0** —— 因为曲线只在 λ=1 精确落到地板。
诚实的替代(**看过曲线之后算的描述统计,不是注册阈值**):
**λ₅₀**(掉到基线与地板之间一半处)—— 块 **≈0.57** · 起始 **≈0.83**。

## 一句关于人的话(这一轮也是方法轮,如实说)
把四分之三的人换成随机噪声,「一个人被打开的形状」在粗的那把尺子上**几乎看不出区别** ——
因为那把尺子问的是「人群里有几个方向」,而不是「这个人是谁」。
**要看见一个具体的人,需要的是另一种精度,而它每丢一个人就丢掉相应的一份。**
