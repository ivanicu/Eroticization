# R03 — is acquisition the same system as valuation

## DECISION: should acquisition timing be modelled by the same coordinates as preference?

**Closed.** SAFE: no. Onset structure is real and 64%-of-variance independent of preference, but it is organised by a population-shared maturational schedule, not by coordinate membership (COORD t=-0.46 vs TEMPO t=+4.59). Model them as two systems.
