# A36 · 两个维度在人层正交,在结局层耦不耦合

`#188` 立起「两个正交维度,各自的外部相关物不同」——
但**正交性只在构造上成立**(`corr(S, Cres) = 0` 是回归的定义,`#129`)。
没被检验的是:**两条外部相关向量,是不是也彼此独立。**

**这个弧要让哪个决定变安全**:`#188` 那句「两个正交维度」该不该原样留在前页。
