# R234 · 两条相关向量,以及一个我自己造出来的耦合

`a_j = r(S, y_j | 勾选数)`,`b_j = r(Cres, y_j | 勾选数)`,j 跑遍 20 道 Likert。

## 第一版结论(错的),以及它通过的四道闸

    corr(a, b) 跨 20 道结局 = −0.4062
    负对照(打乱配对,2000 次)   −0.0026 ± 0.2297   -> 零是效应的 1%
    混杂对照(随机正交对,60 次) −0.0151 ± 0.2234   -> 结局协方差原封不动
    人层 bootstrap(120 次)     −0.3934 ± 0.0830   -> 4.9×
    留一(20 道)               −0.4808 .. −0.2476  -> 全部同号

**四道闸全绿。结论会是「两个维度在人层正交,在结局层反向耦合」。**

## 而它是残差化造的

    b_j = [c_j − ρ_CS·a_j] / √(1−ρ_CS²)      c_j = r(C, y_j),ρ_CS = corr(C,S)

**只要 `ρ_CS ≠ 0`,残差化就在构造上给 b 灌进一个对 a 的负依赖。**

| | |
|---|---:|
| `corr(C, S)` 人层 | **+0.4323** |
| 残差化灌进的斜率 `−ρ_CS/√(1−ρ_CS²)` | **−0.4795** |
| 观测 `corr(a, b)` | **−0.4062** |
| **`corr(a, c_raw)`(未残差化 —— 判据)** | **+0.0511(0.5×)** |

**观测值几乎就是被灌进去的那个斜率;而未残差化的版本与零不可分。
结局层不耦合。判定 ARTIFACT。**

## 为什么我的混杂对照没抓到

我**专门为这个混杂**设计了「两个随机正交的人层向量过同一条管道」——
它保住了结局协方差,却**保不住 `ρ_CS`**:那一对本来就 `ρ = 0`,**没有可灌的东西**。

> **一个负对照必须匹配被判对象的**可观测量级** —— 这里是 `ρ_CS = 0.43`,不是 0。**
> 与 `#165b`(正对照的强度必须匹配被判对象)同一条,这次落在**负**对照上。

## 结构上做不到

n = 20 个结局。**任何 |corr| < 0.44 在 n=20 上都不显著**,所以本设计只能判**大的**耦合;
`+0.0511` 只能说"与零不可分",不能说"确实为零"。
