# R460 · 第三把刀是空的;而真正的交互检验说:两维是**相加**的

`#415` 的 NEXT 提了**第三把刀**(只羞耻 vs 只疗愈),并写着「若 `S`/`EARLY` 在这一刀上接近零,
说明它们标记的是「都高」这一格(**交互**)」。⚠ **跑之前先算代数 —— 两处都错。**

## ① 第三把刀的点估计是**恒等式**
三把刀都是同三个格均值的差:`刀3 ≡ 刀2 − 刀1`,**精确成立,不需要任何可加性假设**。
**实测最大偏差 = 2.78e−17。**
**⇒ 点估计携带零比特新信息**(`#396b` 的同一类,`#387b` 的做法**第四次**生效)。

## ② 而那个读法本身也是错的
`刀3 ≈ 0` 只等于 `刀1 ≈ 刀2` —— **那意味着这个量沿两个维度移动得一样多,即**可加且对称**,恰恰不是交互。**
**真正的交互 = 四格均值**不可加**,而它需要**第四格(都低)** —— 本项目从没用过它。**

## ⇒ 于是本轮做了真正的检验:四格
四格(坐标掩码后):都高 **815** · 只羞耻 **1,193** · 只疗愈 **1,046** · **都低 2,566**(← 从没用过的那一格)

交互 `(都高 − 只羞耻) − (只疗愈 − 都低)`,族内 max-|t| 阈 **2.726**(**四格标签随机重排**,各格大小照旧):
| 量 | 交互 d | \|t\| |
|---|---:|---:|
| **`EARLY`** | −0.1300 | **2.152**(最大)|
| `D` | +0.0695 | 1.156 |
| `c3⁻` | −0.0424 | 0.702 |
| 五题 | +0.0311 | 0.517 |

**最大的也没越阈。而 MDE = 0.20 sd ≤ 有意义的 0.20 sd(擦线)-> 这个零可发布。**

## ⇒ 两维是**相加**的
**没有哪个量专门标记「两样都强」的那一格。**
**⇒ 这收窄了 `#402a` 的读法**:那 1,790 人的「形状」**就是两条线各自形状的和**,不是额外的东西。
与 `#405`(「两边都有」不是一个构念)**一致**。
