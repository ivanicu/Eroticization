## ⚠⚠ 而 `#276` 的 NEXT ③ 问错了问题,守卫 14 当场抓住
`corr(form_i, c3⊥D) = **−0.0000**`(实测 −5.68e−17)。
**这不是发现,是恒等式**:`form_i` 是六坐标回归之后的**残差**,
**按构造与六坐标的任何线性组合正交**,而 `c3⊥D` 正是其中之一。
守卫 14:**3 个扰动下逐位相同 → 「这个数不可能是别的值」。**
