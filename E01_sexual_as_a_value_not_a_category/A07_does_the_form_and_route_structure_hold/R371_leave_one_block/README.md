# R371 · `S` 与 `c3` 都不是某一块 —— 而我的门槛设错了

`#325d`:合成分与 X 的相关可以几乎全部来自一个指标。`form` 只有 2 个指标一眼看穿,
**`S`/`c3` 是 32 块的合成,看不穿,而它们是页面的主干。**

## 留一块重算(32 次,`c3` 每次对齐符号)

## ⚠ 我的 30% 门槛设错了,而正对照当场说了
- **正对照**(合成一个**只由块 #5 驱动**的量):识别对了块 **#5**,
  但最大块只占 **29.0%** —— **低于我注册的 30%,所以正对照 FAIL。**
- **原因**:留一在 32 块的和上做,**剩下 31 块永远在贡献噪声**,
  所以这个统计量**在纯单块驱动下的上限就是 ~29%**。
  **我拿一个绝对门槛去比一个上限只有 29% 的量。**
- **负对照**(均摊的量):**7.8%**(解析均摊期望 3.1% —— 噪声把它抬上来了)。

**按上限校准读**(这是唯一正确的读法):
| | 占「单块上限 29.0%」的比例 |
|---|---:|
| 均摊地板 | 27% |
| **`S`** | **30%** |
| **`c3`** | **40%** |
| 单块 | 100% |

## ⇒ 两条
1. **`S` 基本就是均摊的**(30% vs 地板 27%)—— 它确实是 32 块共有的东西。
2. **`c3` 略集中**(40%)但远不是一块 —— 最大的块 #13 只解释了它的一小部分。
   **页面上「位置」与「广度型」这两个名字站得住。**

⚠ **不改判据,写清怎么读** —— 与 `#305d`(置零 <5% 写错)、`#315b`(两半同时 ≥0.90 无分辨力)
是同一条:**一个预注册的门槛,必须先对着它自己的正对照校准。**
