# R373 · 那条界线不是「少人选」

`#327c`:两件不相交的仪器给出同一条界线,而四次命名都失败。
**也许我一直在找内容学的名字,而它其实是结构性的?**

## 三个与内容无关的块属性,解释了 45%
| | 系数 | 偏相关 |
|---|---:|---:|
| 块内平均流行度 | −0.0764 | **−0.4498** |
| 块内选项数 | −0.0790 | **−0.4857** |
| 流行度离散度 | −0.0518 | −0.3406 |

**R² = 0.4522**,人层自助 **[0.2697, 0.5458]**;随机载荷基线 **0.1060 ± 0.0780**(解析 3/32 = 0.094)。
**⇒ 4.3 倍于随机,但**没到**我注册的 0.5 门槛 —— 不能说「这条界线是结构性的」。**

正对照(只由流行度驱动的合成载荷)R² **0.9011**;负对照见上。

## ★ 而同义反复那一步给出了这一轮真正的结果
跑之前写下的警告:**流行度与「越轨」在概念上高度重合** —— 越轨的东西本来就少人选。
**所以真正的问题是:除了「少人选」之外还剩什么。**

**只扣掉流行度之后,残差载荷与原载荷相关 +0.9223** —— 流行度只解释了 **15%** 的载荷方差。
**而两端还是同一批块:**

| 残差载荷 | 块 |
|---:|---|
| **+0.256** | 尿液 |
| **+0.254** | 非自愿场景 |
| **+0.251** | 变形 |
| **+0.218** | **精神改变**(扣掉流行度后进入前四) |
| −0.239 | 性行为 |
| **−0.289** | 感觉 |

> **⇒ 那条界线不是「少人选」。**
> **把「多少人选」整个扣掉,尿液 · 非自愿 · 变形 · 精神改变 仍然在一端,
> 性行为 · 感觉 仍然在另一端。**

把「多少人选」完全扣掉之后,**尿液、非自愿、变形、精神改变**还是站在一边,
**性行为、身体的感觉**还是站在另一边。
