# R317 · 口径清单:哪些小选择真的会改变一个已发表的数

## 结果:5 个候选旋钮,4 个真的会动,1 个(阴性对照)不动
| 旋钮 | 实测 | 最大变动 |
|---|---:|---:|
| ① 块覆盖阈值 `cov>=` 8/6/10 | 1.37% · 1.38% · 1.54% | **0.17pp** |
| ② 清晰度最小块数 `need` 8/6/10 | 1.37% · 1.37% · 1.55% | **0.18pp** |
| ③ S 是否随块变化 | 1.37% · 1.21% | **0.17pp** |
| ④ 选项劈分种子 | 1.37% · 1.35% · 1.35% | 0.02pp |
| ⑤ 阈值重抽样次数(**阴性对照**) | 1.37% × 3,**逐位相同** | **0.00pp** |

守卫 14 逐项验证,**⑤ 被正确识别为「这个数不可能是别的值」并从清单里删掉**。

## ⚠ 而清单**不完整** —— 这一点比清单本身重要
三个主旋钮**同时**取另一端:**1.52%**,只比基线高 **+0.15pp**(它们部分相消)。
**`#314` 那 +0.85pp 依然无归属:单个最大 0.18pp,三个叠加 0.15pp。**
