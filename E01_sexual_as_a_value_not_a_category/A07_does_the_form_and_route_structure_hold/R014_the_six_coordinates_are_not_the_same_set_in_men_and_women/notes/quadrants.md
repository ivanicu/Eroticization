# R353 · 羞耻的两条路,在同一个人身上是**相加**

⚠ **符号约定先写下来**(`#306b`):`c3` 与羞耻的相关是负的,所以全程用 **`c3⁻ = −c3`**,
让两条路都指向「更多羞耻」。**这是约定,不是发现。**

## 四象限(中位切),n=6,717
| | 低 `c3⁻` | 高 `c3⁻` |
|---|---:|---:|
| **低 `S`** | **0.3829** | 0.7178 |
| **高 `S`** | 0.6995 | **1.0772** |

**加性预测 1.0344,观测 1.0772,交互 +0.0427 ± 0.0891 —— 落在自身 se 里。**
两条都高的人,羞耻是两条都低的人的 **2.81 倍**,而那恰好就是把两个单独效应加起来。

## 这是一个有功效的零
| | |
|---|---:|
| 连续交互系数 | **−0.0150** |
| `perm_finite` 置换零 | +0.0051 ± 0.0135 |
| 比值 | **0.7× 的 2×展布** |
| **正对照:植入交互 0.15** | **抓到 +0.1502** |
| 正对照:纯加性合成结局 | +0.0144 ± 0.0503(落回零) |

**仪器能把 0.15 的交互认到小数点后三位,而它在真数据上读到 −0.015。**

## 规格曲线:符号乱走,而那正是真零的签名
中位 **+0.0427±0.0891** · 三分位 **+0.0583±0.1380** · 四分位 **−0.0777±0.1885** ·
极端五分位 **−0.0978±0.2416** —— **四格全部小于自身 se**,符号在中间翻。
⚠ 我预注册的「符号一致」这条 FAIL 了 —— **但一个真零本来就该符号乱走**,
所以这里读的是「全部小于 se」,不是「符号一致」。**不改判据,写清楚该怎么读。**
