# R369 · `form` 是不是「反事实性」 —— PLAUSIBLE,不是 CONFIRMED

`#316` 排除了媒介与答题风格。**剩下的候选:它是不是「情欲化一个不是你的东西」?**

⚠ 这份问卷**没有**独立的「虚构 vs 真人」题(唯二的媒介题就构成 `form`)。
**但有一组我从没用过的**:四道「想象**成为**另一性别」的题
(**存在为** / **独自自慰为** × 生理女 / 生理男)。

**规则跑前钉死(确定性,无研究者自由度)**:
**反事实半** = 与本人 `biomale` **相反**的那两道 · **同构半** = 一致的那两道。

## 结果
| | ↔ 反事实半 | ↔ 同构半 | **差** |
|---|---:|---:|---:|
| 原样 | **+0.0420** | −0.0112 | **+0.0532** |
| 扣 `biomale` + 答题风格 | −0.1214 | −0.1633 | **+0.0418** |

**2×MDE = 0.0516**(n=11,785)。
**原样的差刚过门槛(+0.0532),而扣掉控制后的差没过(+0.0418)。**

- **正对照**(只由反事实半驱动的合成量):↔反事实 **+0.7049** · ↔同构 **+0.1453**,
  扣控制后差 **+0.6955** —— 判据完全有能力抓到这个成分。
- **负对照**(打乱人):**−0.0029 ± 0.0090**。
- 两半彼此只弱相关(`corr(CF, CG)` = **+0.2167**),所以它们确实是可分的两半。

## ⇒ PLAUSIBLE,不是 CONFIRMED
**方向在两个口径下一致(都是正的),但只有未加控制的那个过了预注册门槛。**
**不写进页面。**

## ⚠ 顺带测到的一件事,值得单独记
**`corr(form, biomale)` = −0.2075** —— **女性在「动画 + 文字」这条维度上明显更高。**
这是 `form` 与性别的关联里最大的一个,而这个项目此前没有点名过它。
**它也正是为什么「扣掉性别」的那一版更保守 —— 反事实/同构的差里可能有一部分是性别。**

## 一句关于人的话
「动画和文字」那条维度**可能**带着一点「情欲化一个不是你的身体」——
方向对,量刚够,而扣掉性别之后就不够了。**这句话现在只能说到这里。**
