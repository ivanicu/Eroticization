# R335 · `#179` 那个 +0.1185 拆开是多少

`#289b`:位置分 ↔ 羞耻 **+0.1185** 是在合并样本上算的,而 `#289a` 说 **S 的预测在两组间不同**。
**所以那个数是两个不同数字的平均,而这个项目从没报过它们各是多少。**

## 结果:拆开了,而差**不可分辨** —— 且这次有功效
| | `corr(位置分 S, 羞耻)` | n |
|---|---:|---:|
| 合并样本 | **+0.1185**(`#179`,复现) | — |
| `biomale = 0` | **+0.1297 ± 0.0188** | — |
| `biomale = 1` | **+0.1081 ± 0.0186** | — |
| **差** | **−0.0216** | |
| **offset**(随机劈同样大小两组之间的差) | **0 ± 0.0273** | |

**观测差是 offset 的 0.8× —— 不可分辨。**
负对照(只在有限值内置换羞耻)+0.0002 ± 0.0238(效应的 1%)。

> **`#179` 那条最老的主张按组拆开之后没有变:羞耻**不是** S 的非不变性所在。**

## ⚠ 而正对照第一版设计错了,修好之后才有功效
第一版用 `0.3×SEX + 噪声` 当作「已知按性别不同的结局」,给出 **−0.0020** —— 判不出任何差别。
**因为一个由性别驱动的**结局**只造成均值差,不造成**相关的组间差**。**
要让 `corr(S, 结局)` 在两组间不同,结局必须依赖 **`SEX × S` 的交互**。
改成交互项驱动后:**+0.3300**(远超 2×offset 0.0546)。

> **`#285c` 的同一条:正对照的失败,几乎总是因为我给它的那个东西不具备被检验的性质。**
> **而这一次它差点让我报出一个没有功效的零。**
