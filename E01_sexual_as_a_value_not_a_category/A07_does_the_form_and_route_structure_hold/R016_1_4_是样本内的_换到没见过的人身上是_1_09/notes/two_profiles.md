# R354 · 注册的问题答不了,而它答出了一个更结实的

**注册的问题**:两条路带来的是不是同一种羞耻?
**答案**:这个设计答不了 —— 但它在失败的过程中量出了一件更结实的事。

## ⛔ 调节剖面这把尺子没有功效,而正对照当场说了
| | |
|---|---:|
| ② 调节剖面相关 | +0.1655 |
| 打乱人的零 | −0.1457 ± **0.4015** |
| **正对照:同一潜变量驱动** | **−0.1324**(本该高) |
| 正对照:对调节反应相反 | −0.9884(只有这个极端情形抓得到) |

**一把连「同一潜变量驱动」都认不出来的尺子,它的读数什么也不说明。**(P5★)

## ★ 而它失败的原因本身是一条结论:两条路都**没有被调节**
| | 19 个条件格的均值 | 跨格 sd | 各格自身 se 中位 | |
|---|---:|---:|---:|---:|
| `RS`(位置侧) | **+0.0989** | 0.0151 | 0.0170 | **0.89×** |
| `RC`(广度型侧) | **+0.1038** | 0.0133 | 0.0170 | **0.78×** |

**跨格变化小于各格自身的抽样误差 —— 两条路的羞耻效应在每一个子群里都是同一个大小。**
年龄 · 开放性 · 尽责性 · 外向性 · 神经质 · 宜人性 · 无力感 · 性别 · 关系风格 · **成长期性开放度**。

**没有变化,就没有剖面可以比** —— 这就是 ② 为什么没有功效。

按 `#300a` 发明的旋钮(切分规则):中位 **0.79× / 0.58×** · 三分位 **0.95× / 0.61×** ·
极端四分位 **0.86× / 0.68×** —— 三种切法下都成立。

## 最该被引用的那一格
**成长期「性压抑」的人 +0.1091 / +0.1081,「性开放」的人 +0.0789 / +0.0972。**
差 0.030,而各格 se 是 0.017 —— **在这个分辨率下读不出来。**
**一个性开放的成长环境,并没有把这条路上的羞耻挡掉。**

⚠ 最大的单格反差是神经质(RS:低 +0.0745 / 高 +0.1353),
但那是 **19 格里的 1 格、没有做多重性校正** —— **不作为发现读。**

## ① 结局剖面(注册的第一个检验)
两个正交残差的 28 结局剖面相关 **−0.1592**。
guard 15:**剖面低是「不是同一个东西」的有效证据**(这个方向不受限制)——
所以这是一条**弱的**、指向「两种不同感受」的证据,不是命名。

## 一句关于人的话
**这份羞耻在每一种人身上都一样大。**
不管你多大、多外向、多尽责,是不是一夫一妻,
**也不管你是在一个性压抑还是性开放的家里长大的** —— 都是同一个 0.10。
