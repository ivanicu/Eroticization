# R350 · 重现度 vs 样本量 —— 外推不发布,而门槛是一个没被列出来的旋钮

`#304c`:0.796 是 n≈3,350 的重现度,不是发布版(n=6,717)的。**本轮想把这个低估补上。**

## 两条门槛规则,两条互相矛盾的曲线
`Cmat` 里有一个 `mm.sum() > 200` 的块对准入门槛。做 n 的曲线时,它有两种读法:

| n(每组) | 固定门槛 200 | | | 比例门槛 3.0%·n | | |
|---:|---:|---:|---:|---:|---:|---:|
| | 置零 | `c1` | `c3` | 置零 | `c1` | `c3` |
| 800 | **85.7%** | 0.882 | 0.436 | 10.1% | 0.528 | 0.303 |
| 1600 | 55.6% | 0.943 | 0.527 | 9.8% | 0.531 | 0.717 |
| 3350 | 22.9% | **0.964** | 0.822 | 9.7% | **0.680** | 0.847 |

- **固定门槛**:n 小的时候把矩阵掏空(85.7% 的格子被置零)——**三个 n 量的不是同一个估计量。**
- **比例门槛**:置零比例拉平了(10.1 / 9.8 / 9.7),**可比性达到了** ——
  但 n=800 时门槛只有 24 个人,相关本身是噪声,曲线变得不单调。
- **同一个 n=3,350 上,两条规则给 `c1` 0.964 vs 0.680。**

> **⇒ 那个准入门槛比样本量更能撬动这个量。**
> 它从来没进过 `CALIBER.md`。

## ⛔ 自检没过,所以外推不发布
Spearman–Brown 自检(用 800 预测 1600、用 1600 预测 3350):
最大误差 **0.278**(固定门槛)/ **0.252**(比例门槛),门槛是 0.05。
**两条规则下的外推值都不发布**(它们分别会给 c3 的 0.9028 与 0.9172 ——
写在这里只是为了说明**我确实算出来了并且选择不发布它**)。

正对照(两半都用全样本 C)**1.0000**,与 n 无关;负对照(随机正交基)**0.1394**,不随 n 变。

## 结论
**`#304` 的 0.796 保持原样,并且它的范围注也保持原样:**
它是**在发布口径的门槛下、n≈3,350** 测到的。
「半样本低估了发布版的稳定性」这句话**仍然成立,但无法定量** ——
因为这个估计量的准入规则本身依赖 n,而两种把它固定下来的方式给出互相矛盾的答案。

⚠ 我预注册的「置零 < 5%」这条门槛控制,比例规则下是 ~10%,**没过**。
真正该要求的是**跨 n 恒定**(达到了:10.1/9.8/9.7),而我写下的是一个绝对水平。
**不改判据** —— 记下来是因为一个写错的门槛会在下一次悄悄放行。
