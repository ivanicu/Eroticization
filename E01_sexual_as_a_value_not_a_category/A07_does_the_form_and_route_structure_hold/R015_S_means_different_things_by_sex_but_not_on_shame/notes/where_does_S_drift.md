# R336 · S 的非不变性到底落在哪一格

`#289a`:去掉位置分 S,非不变性完全消失 ⇒ **S 是来源**。
`#290a`:羞耻那一格没有可分辨差别 ⇒ **来源在别处**。保留集 22 道里还有 21 格没查。

## 结果:**只有一格**,而它是「被支配地位唤起」
| | |
|---|---:|
| 全族阈值(最大统计量,80 次随机劈) | **0.0766 ± 0.0061** |
| **越阈的格数** | **1 / 22**(读作 1–1) |

| 格 | 组 0 | 组 1 | 差 |

正对照:交互项驱动的假结局放进保留集 → 差 **+0.3106**,**被抓到 ✅**(`#290b` 修好的那个版本)。
负对照:置换 S → 越阈格数 **0.1 ± 0.3**。

> **非不变性是**局部的**:S 在两组间意味着不同的东西,而那个不同**只落在支配/臣服这一根轴上**。**
> **而两格构成一面镜子**:组 1 里「偏爱冷门」**朝臣服偏**(支配 −0.065 · 臣服 +0.075),
> 组 0 里它**在这根轴上几乎中立**(+0.018 / +0.022)。
> ⚠ **但只有支配那一臂越阈** —— 镜子是**提示**,不是结论。

## 一句关于人的话
「偏爱冷门的东西」这件事,在两组人身上意味着**几乎同一件事** —— 除了一处:
**在其中一组里,它朝「被支配」偏;在另一组里,它在支配这根轴上什么也不说。**
22 道题里只有这一道分开了它们。
