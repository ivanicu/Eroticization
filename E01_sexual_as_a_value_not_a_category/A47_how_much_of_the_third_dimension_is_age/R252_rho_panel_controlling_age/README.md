## 段内对照 —— 方向性检查,不是计数

| 年龄段 | n | 越(未控)阈值 |
|---|---:|---:|
| 14–17 | 1,834 | 9/20 |
| 18–20 | 1,556 | 12/20 |
| 21–24 | 2,094 | 5/20 |
| 25–28 | 2,201 | 10/20 |
| 29–32 | 2,259 | 6/20 |

**五个段内都有信号,而段内没有年龄变异。**
⚠ **但这几个数不可与 7/20 直接比**:阈值是在**全样本**(n=6,639)上校准的,
而每段只有约三分之一的人 —— **n 小则 |r| 的抽样噪声大,固定阈值会被更多地越过**。
所以 12/20 不是"更强",只是"更噪"。**这一栏只能当方向性检查:每个段里都有东西。**

## 结构上做不到

年龄只有 5 段(14–17 … 29–32),**段内仍有 3–4 年的残余变异** ——
"控制年龄"是不完全的,段内对照是对它的**补充**,不是替代。
