# R291 · Δ 是哪一个钟的函数

`#245a`:Δ 对 `A8`(第 8 个起始年龄)单调,零点 ≈17.5。但 `A8` 只是一个钟。

## 共线性先报(否则「谁存活」由噪声决定)
`corr(A8, A_close) = +0.648`;其余两两 |r| ≤ 0.48。**VIF 全部 ≤ 2.1** —— 联合回归可读。
正对照两端都精确命中:种入只依赖 `A8` 的效应 → 回归给 A8 **+0.918**、其余 ≈0.00;
种入只依赖 `A_close` 的 → 给 A_close **+0.918**、其余 ≈0.00。

## 结果:没有哪一个钟单独决定它 —— 五个全部存活,符号各异
| 钟 | 单独 | **同时** | |
|---|---:|---:|---:|
| `A_close` 版图关闭年龄 | +0.3423 | **+0.2151 ± 0.0133** | **16.2×** |
| `rate` 积累速率 | −0.3283 | **−0.1864 ± 0.0104** | **18.0×** |
| `A_first` 首个兴趣年龄 | −0.0691 | **−0.1430 ± 0.0131** | 10.9× |
| `A8` 第 8 个 | +0.2482 | **+0.1356 ± 0.0146** | 9.3× |
| **当前年龄** | +0.1532 | **+0.0226 ± 0.0096** | **2.3×** |

置换零(A8 的联合 beta)+0.0049 ± 0.0123(效应的 4%)。

> **Δ 不是任何一个钟的函数,是整条积累时间线的**形状**的函数:
> 关得越晚 → 越正 · 积累越快 → 越负 · 起步越晚 → 越负 · 第 8 个越晚 → 越正。**

## ★ 而当前年龄几乎不贡献(2.3×),这排除了最简单的那个解释
`#210` 之后,这条线上一直悬着「这些是不是当前年龄造成的观测窗口差异」。
**在同一个模型里,当前年龄是五个量里最弱的一个。**
