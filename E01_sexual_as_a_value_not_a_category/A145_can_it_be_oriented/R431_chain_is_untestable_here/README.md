## ⚠⚠ 跑之前先做代数,而代数说这句话**两处都错**
**① 符号错。** 间接路径 = (羞耻→ACTED) × (ACTED→BELIEF) = **(−0.0762)×(−0.0423) = +0.00322**,**正的**。
总 = 直接 + 间接 -> 控制 `ACTED` 是**减掉**它 -> 系数应当从 +0.0135 **降到 ≈ +0.0102**,**变小,不是变正**。

**② 而更根本的是:它是一个恒等式。**
| | |
|---|---|
| 实测 Δ | **−0.003221** |
| 代数 −a×b | **−0.003221** |
| **差** | **0.000000** |

`Δ = −a×b` 是标准化 OLS 的**省略变量公式** —— **它不可能是别的值。**
而 `a` 与 `b` 我**已经知道**(`#384b` 与 `#386a`)。
**⇒ 「Δ 越过零」说的不是世界,是回归的算术在工作。这个分离器是**空的**,不是**没功率的**。**
**本轮没有一个比特的新信息 —— 而这正是 `AGENTS.md §9` 的「算术陷阱」。**
