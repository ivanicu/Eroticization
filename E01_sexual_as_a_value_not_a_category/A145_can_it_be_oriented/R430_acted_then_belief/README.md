# R430 · 让一个人觉得「这改不掉」的,是他**做过什么**,不是他**有多羞耻**

`#385` 拿掉了「起始时间造出来的」。剩下的对手是 `#384f④` 的反向:**「做过了所以不那么羞耻」**。

这份数据能对它说一句话的地方只有一个,**而且它不需要羞耻这个变量本身**
(所以 `#384f①` 的自报污染不直接进入主量):
- **若「做过 -> 羞耻降低」成立**,机制是**试过了、发现它还在** -> 做得多的人应更倾向认为**改不掉**。
  预测:`ACTED → BELIEF` **负**。
- **若只有「羞耻 -> 少做」**,`ACTED ↔ BELIEF` 没有这个方向上的理由。预测:**≈ 0 或正**。

⚠ 而 `#384a` 已证明**羞耻本身与 `BELIEF` 无关**(+0.0135,零可发布)——
**所以这里的零会是有内容的:不是「什么都测不到」,而是「那条机制该留的痕迹没留下」。**

## 结果:**痕迹在**
| | 值 | |
|---|---:|:--|
| `ACTED → BELIEF`(等距) | **−0.0387** (se 0.0122) | **−2.97 sd,越阈**(阈 0.0246) |
| 秩变换版 | **−0.0399** | 同号(IMPOSSIBLE ②) |
| 对照:`羞耻 → BELIEF`(`#384a`) | **+0.0135** | 未越阈,零可发布 |

**⇒ 做得越多的人,越认为这东西停不下来。而羞耻本身完全不预测这个判断。**

## ⚠ 强度不宽裕
guard 26 的 MDE 扫描:−0.03 检出 76.7% · **−0.05 检出 100%** -> **MDE = 0.05**,
**恰好等于**争议幅度 0.05(门以 `≤` 通过,擦线)。
**而实测 0.039 低于 MDE** —— 与 `#370c` 同样处理:**方向可报,强度不宽裕**;
同样大小的效应约四分之一的重复会漏掉。

## 对照
guard 26(MDE 扫描 0.05 ≤ 0.05)· 负对照(掩码内打乱 `ACTED`)−0.0148 ≤ 0.0246 ·
offset 零非退化(−0.00096 ± 0.0127)· 秩变换同号。

## IMPOSSIBLE
① 两题仍是自报,只是**羞耻不再是自变量**;② 等距是我加的 -> 秩变换同号才报;
③ **仍不是因果**:`ACTED` 与 `BELIEF` 同时测量,谁在前本设计定不了 ——
本轮只说「**那条机制预测的痕迹在不在**」。

## 一句关于人的话
**让一个人觉得「这改不掉」的,是他做过什么,不是他有多羞耻。**
**羞耻让他少做;而做过的人,更清楚这东西不会走。**
