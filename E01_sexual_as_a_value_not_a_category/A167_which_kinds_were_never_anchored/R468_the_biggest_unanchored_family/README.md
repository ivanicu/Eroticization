## ★★ ③ 而真正的结果不是「方向一致」,是**一个都没有反的**
`r` 的分布:**min +0.0276 · 中位 +0.1524 · max +0.3717** —— **134 个检验里 0 个为负。**
在「与卷入无关」的零下,应当约有**一半**为负。

**⇒ 这份问卷里的 67 种唤起,没有任何一种是「专精」的:**
**没有一种口味,它越强,一个人的性生活越窄。**
最强的三个是 anal `+0.372` · masterslave `+0.270` · mindbreak `+0.267`;
最弱的是 receivepain `+0.028` —— **弱到接近无关,但仍然不是负的。**

## 一句关于人的话
**「口味越重越专精」在这里是假的。** 更强的唤起,伴随的从来不是更窄的性生活 ——
range 从**几乎无关**到 **+0.37**,**而从不为负**。

## IMPOSSIBLE
① 「宽」由两个**计数**定义 -> 这是「与卷入同向」,不是「与幸福/满意同向」;
② 67 列彼此高度相关 -> **「0/134 为负」的强度受这个依赖限制**,
   不为它编一个 p 值(显著性已按 Bonferroni 单独处理);
③ 横断面 -> 「越强越宽」不含时间方向;
④ `OTHER`(83 列)本轮未标定。
