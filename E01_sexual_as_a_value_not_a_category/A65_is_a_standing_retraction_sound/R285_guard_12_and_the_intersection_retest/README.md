# R285 · 第 12 个守卫,和一条现存撤回的回溯重审

`#239a` 是本项目第一个记录在案的**假否定**机制。前 11 个守卫全在防假肯定,
而假否定成本更高:**被撤回的主张没人重审。**

## ① 回溯重审 `#210` —— 它站得住,而且现在有了分解
`#210` 用 `V → where(V ≤ 14)` 撤回了 `#206b`/`#207c`,而那个控制把样本从 9,944 掉到 2,806。
`#210c` 已经注意到这批人「本身更早熟,不是随机子集」并克制地只用它证伪 ——
**但它没有算过第三格:未截断的量,在同一批 2,806 人上。**

| 臂 | r(rho_i, age) | n |
|---|---:|---:|
| A 全样本未截断 | **+0.1532 ± 0.0094** | 9,944(`#210` 报 +0.1532,精确复现) |
| B 截断 ≤14 | **−0.0741 ± 0.0199** | 2,806(`#210` 报 −0.0741,精确复现) |
| **C 未截断,只在 B 的人上** | **+0.0830 ± 0.0174** | **2,806 ← 从没被算过** |

**C 仍然明显为正(4.8×)。**
> **截断造成的部分 C−B = +0.1571(6.0× 展布,69%);
> 样本选择造成的部分 A−C = +0.0702(31%)。**
> **`#210` 的撤回成立** —— 在同一批人上,把截断拿掉,符号就回到正。

这是这个项目第一次**量化**一个控制里「机制」与「样本」各占多少。
