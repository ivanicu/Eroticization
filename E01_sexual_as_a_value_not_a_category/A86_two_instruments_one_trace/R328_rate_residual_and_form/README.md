# R328 · 两把不相交的仪器,一个痕迹

`#282b`:`rate⊥rho` 剩下的最强格是 `animated` +0.044,而 **`form_i` 正是由 `animated`/`written` 构成的**。
两者来自**不相交的仪器**(起始年龄 vs 块选项)——
⚠ 与 `#277b` 不同:那一次是恒等式,**这一次两个量共享零道题,所以是一个真问题**。

## 结果:不是同一个东西
| | |
|---|---:|
| **分数层** `corr(rate⊥rho, form_i)` | **+0.0409 ± 0.0146(2.8×,n=4,546)** |
| **剖面层**相似 | **+0.1212** |

正对照两端都过(`form_i` vs 它自己的带噪声复制 **+0.7728**;vs `age` **−0.0167**);
负对照(只在有限值内置换)−0.0018 ± 0.0142(效应的 4%)。
守卫 15:**剖面低 → 「不是同一个东西」这个方向不受限制**,放行。

> **分数层有一份**可分辨但极小**的共有(+0.041,2.8×),而剖面层几乎不重叠(+0.12)。**
> **`animated` 是两条路各自经过的一道门,不是它们共有的一个人层量。**
