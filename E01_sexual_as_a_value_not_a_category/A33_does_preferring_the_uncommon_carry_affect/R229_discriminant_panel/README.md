# R229 · 判别效度:把同一条管道跑遍 20 道 Likert

`#183` 的 NEXT 注册的是:找 2–3 个**非性的负性自我评价**题跑同一条管道。

> ⚠ **这个检验做不了。** 本 release 的 −3..+3 Likert 只有 **20 道**,逐条读过:
> **没有一道是非性的负性自我评价。** 判 **STRUCTURALLY IMPOSSIBLE**,不拿代理冒充。
> 「性的羞耻 vs 一般性自我否定」这个分岔,**在这份 release 上永远判不了**。

**替代设计(明说是替代)**:同一条管道跑遍全部 20 道,用**最大统计量零**给全族阈值。

## 两条线被分开了 —— 一条站住,一条要降级

### `#179` 的块层位置分 S(n=6,717):**站住,而且是第一名**

| 排名 | r | 比 | 题 |
|---:|---:|---:|---|
| **1** | **+0.1155** | **9.5** ★ | **羞耻** |
| 2 | +0.1020 | 8.1 ★ | animated |
| 3 | +0.1002 | 8.2 ★ | 性成熟未成年 |

**全族 95% 阈值 |r| = 0.0393。羞耻越过它 6.3× 自身噪声,排名 1/20。**
⚠ 但 **10/20 题越过阈值** —— 所以正确的说法是「羞耻是**最大**的那一个」,
**不是「只有羞耻」**。S 与很多东西相关。

### `#180`/`#182`/`#183` 的起始年龄截距(n=10,567):**没越过**

| 排名 | r | 比 | 题 |
|---:|---:|---:|---|
| 1 | −0.0287 | 2.9 | **`highenergy`(非性的一般特质)** |
| **2** | **+0.0278** | 3.0 | **羞耻** |
| 3 | +0.0268 | 2.7 | animated |

**全族 95% 阈值 |r| = 0.0307 —— 20 道题里没有一道越过它,包括羞耻。**
而排在羞耻前面的是 **`highenergy`,一个非性的一般特质**。

> **注册的检验做不了,但它想问的那件事被另一条路答了一半:
> 一个非性的一般特质,与截距的关联和羞耻一样大。**

## 本轮修掉的两个错

1. **列名 `item` 撞 pandas 的 `.item()`** —— 与 `#156` 的 `G.shift`、`#166c` 的 `T.cov`
   **同一类,第四次**;而 `check_columns` 就是为它写的,我**第三次**没调用。现已调用。
2. **打乱的是整条数组(含 NaN)** —— 打乱后 NaN 落进分析样本,相关变 nan,
   于是 20 道题里 **17 道被静默丢掉**,面板只剩 3 道,而"羞耻排名 1/3"看起来很强。
   **打乱必须在分析样本内做。** 已加 `check_coverage`,现在 20/20。

## 结构上做不到

非性的负性自我评价题**不存在于本数据**。所以「性的羞耻」这个词,
在这份 release 上**只能靠 `highenergy` 这类一般特质做半个对照**,不能被正面检验。
