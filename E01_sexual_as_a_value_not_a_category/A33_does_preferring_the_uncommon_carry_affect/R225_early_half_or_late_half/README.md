# R225 · 羞耻贴的是早来的那一半,还是晚来的那一半

**整轮完全在起始年龄那一侧内部做**,绕开了 `#159` 的零 item 重叠问题:
30 个类别各有人群稀有度,每人各有获得年龄 → 人内按年龄中位数劈半,两半在**类别**上不相交。

## 结果

| | r(半, 羞耻) | 信度 SB | 去衰减 |
|---|---:|---:|---:|
| **早半** | **+0.1272** | 0.223 | **+0.2695** |
| 晚半 | +0.0999 | 0.344 | +0.1704 |
| **配对差(早−晚)** | **+0.0282 ± 0.0122(2.3×)** | | +0.0990 |

n = 11,329。**羞耻贴早半更紧。** 而早半的信度**更低**(0.223 vs 0.344),
所以它的相关被衰减得**更厉害** —— 去衰减后差距**变大**,不是变小。**这个方向不是仪器造的。**

⚠ **人内打乱获得年龄**(保留曲目与年龄分布,毁掉配对)给出差 **−0.0125 —— 效应的 44%**。
过了 50% 的门,但**margin 很薄**。诚实的标签是 **PLAUSIBLE,不是 CONFIRMED**。
