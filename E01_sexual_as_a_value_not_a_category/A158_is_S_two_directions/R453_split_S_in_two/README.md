# R453 · 拆开 `S` 没有让它更像一个方向 —— 越轨那一半反而更散

`#408` 之后换的问法:也许问题不在「哪些结局反号」,而在 **`S` 本身不是一个方向**。
⚠ 块的分法来自 `#327` 的**载荷自助**(越轨块 / 普通块)—— **数据给的,不是我挑的**。

## 结果:世界 B
| | 符号一致性 |
|---|---:|
| `S_TRG`(**越轨块**) | **0.6207** |
| `S_ORD`(普通块) | **0.7586** |
| **合起来的 `S`**(`#406a`) | **0.7241** |
| offset 零(**随机把块分成同样大小的两组**,取两半中较小者) | **0.6513 ± 0.0350** · 95 分位 **0.6897** |
| 实测较小者 | **0.6207 -> −0.87 sd,落在零里** |

⚠ **零的种类**:`offset_control` —— **任意**把块分成两组,两半各自都可能比合起来更一致
(每半的题更少、更同质)。

**⇒ 拆开**没有**让 `S` 更像一个方向。越轨那一半比合起来的 `S` 还散。**

## ⚠ 而这是一个**有功率**的零
guard 26(**显式声明离散主量 + 扫描**,`#407c` 的接口):
扫描 35% / 90% / 100% / 100% -> **未饱和**;**MDE = 40% ≤ 有意义 50%** -> **通过**。
负对照**越阈率 8.0%**。**⇒ 这个零可以发布。**

## ⇒ 关闭的决定
**页面上 `#406d` 那句「每一句关于 `S` 的话都要带结局限定」**站得住** ——
而现在它多了一条:**不是因为 `S` 混了两个方向**(那个解释已被有功率地排除)。

## ⚠ 按 frontier §3:换方向
「那 8 个反号有什么共同点」这个问题现在**两轮没答上来**(`#452` 无功率的零 · 本轮排除了一个解释)。
**不追第三轮。**

## IMPOSSIBLE
① 两半的块数比 `S` 少 -> 系数更不稳,**而随机零用同样的块数,已吸收这一点**;
② `TRG`/`ORD` 在**同一份数据**上定(`#327`)-> **不同仪器**,不是独立样本;
③ 「不是两个方向」不等于「是一个干净的方向」。

## 一句关于人的话
**「口味有多冷门」不会因为拆成「在冷门的东西上」和「在普通的东西上」就变得更像一个方向。**
**而越轨那一半,反而是更散的那一半。**
