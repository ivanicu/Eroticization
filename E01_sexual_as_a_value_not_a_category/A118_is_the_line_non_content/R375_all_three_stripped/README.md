## ⇒ 「`c3` 是一个内容维度」这句话有了它能有的最强证据
把三个与内容无关的块属性**全部**减掉之后:
① 羞耻**保住**(区间与参照重叠)· ② 跨到**另一件题目不相交的仪器**上,分离**更锐**。
**那三个结构属性是在给跨仪器的分离添噪声,不是在扛它。**
