# R02 · `corr(ρ,S)` 掉的那一半,是心理学还是仪器?

`#5` 的覆盖度定律说:本 release 上任何未按块数匹配的分组比较,有一大半在测问卷覆盖度。
所以在 `128c` 进 README 之前,必须**在设计上**把这条通路关掉 —— 卡钳 1:1 匹配,不靠回归假设线性。

## 结果

| 协变量集 | 匹配后 `corr(ρ,S)` | 保留 | 块数残差 | 配对数 |
|---|---:|---:|---:|---:|
| 未匹配 | −0.0459(4.2×) | | | |
| 类别数 | −0.0389 | 85% | 0.003 sd | 4,463 |
| 类别数+年龄 | **−0.0417(3.1×)** | **91%** | 0.006 sd | 4,401 |
| 类别数+年龄+勾选数 | −0.0461 | 100% | 0.002 sd | 4,153 |

置换零 **−0.0072**(效应的 17%)· 种植正对照 **+0.5878**。三个规格一致。

**判定:psych。特质链接不是覆盖度,`128c` 可以留在 README 上。**

## 这一轮真正的产出是它抓到的东西

第一次跑时这张表读作「匹配后只剩 13–16%,`128c` 撤回」,而且顺带报出
`corr(类别数, S) = −0.8297`,看上去是一条关于整个 release 的重大警告。

**两个都是同一个 bug。** `S` 的残差化写成了 `z(S − polyval(fit_on_z, z(PK)))` 而不是
`z(S) − polyval(...)` —— 把一个 z 尺度的预测值从**原始尺度**的变量里减掉。原始 S 的 sd
远小于预测值的 sd,所以返回的几乎就是 **−z(勾选数)** 本身。整整两轮的 `corr(·, S)` 测的
是负的勾选数,不是稀有亲和特质。

破绽只有一条,而且是免费的:**残差与它所回归掉的协变量的相关在构造上恒等于 0。**
`corr(所谓残差, PK) = −0.9654`。已落地为 `lib/gates.py::check_residualized`。
