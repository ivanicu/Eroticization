# R01 · 版图是向外辐射的吗?

## 问的是什么

对每个人,把**类别固定效应**(=人群共享的发育时间表)和**这个人整体的早熟程度**都精确扣掉,
剩下的残差里,这个人自己那些**别人很少有**的兴趣,排在他自己那些**大家都有**的兴趣的
前面还是后面?

`ρ_i` = 这个人的起始年龄残差与类别稀有度的**人内相关**(尺度无关)。
`S_i` = 稀有亲和特质,来自**多选题选项**,与起始年龄题目零重叠(`check_disjoint_items` 断言)。

三个世界,在心理学上完全不同:

- **A 共享辐射** — 每个人都从常见走向罕见,速率一样;个体差异只在"走多远"。
- **B 起点分歧** — 高稀有亲和的人一开始就在外围。`ρ < 0`,且 `corr(ρ,S) < 0`。
- **C 行程分歧** — 高稀有亲和的人是走得更久的人。`ρ > 0`,且 `corr(ρ,S) > 0`。

## 设计上唯一重要的一件事

`ρ_i` 是一个**以稀有度为权的对比**,所以常数人效应(整体早熟)贡献恰好 0 —— 与救了 `#116`
的是同一种结构免疫。**但这只有在两个边际被真正扣干净时才成立**,而这正是本轮最贵的一课:

> **一遍「题目去均值 → 人内去均值」在缺失不平衡的面板上不是幂等的。** 人内去均值会把题目
> 均值重新带回来,而残余的题目主效应**恰好沿稀有度排列** —— 它精确地伪造出一个
> "题目属性 × 人"的交互,量级 18× 置换零,**而且符号是反的**。

必须交替投影**迭代到收敛**(本数据 13 次)。

λ 规格曲线在 0 → −0.2947 全程平坦(−0.0327 ~ −0.0329)。

## 判定

**世界 C 死。世界 B 活。** 版图不是从常见的中心长向罕见的边缘 —— 不寻常的东西一开始就在那里。

## 反向工作的混淆(名字写在这里,因为它让结论更强不是更弱)

一个罕见类别之所以罕见,是因为少有人获得它;而**近期才获得**的东西更可能被报成晚 ——
这条通路把罕见推向**更晚**,与观测到的方向相反。

## 这轮做不到的

因果方向。横断面数据分不清"先有稀有亲和所以早"与"早所以形成了稀有亲和"。
起始年龄按 2 年分箱,这是分辨率地板。
