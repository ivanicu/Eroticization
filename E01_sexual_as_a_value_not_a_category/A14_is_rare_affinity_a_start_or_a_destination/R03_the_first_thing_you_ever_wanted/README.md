# R03 · 一个人最早想要的那些东西

`#128b` 和 `#129e` 都建立在**双向去均值后的连续残差**上,而 `#128` 的第四十四个错正是去均值
本身把符号弄反过一次。这一轮问同一个假说的**离散版本**,它的零是这个人**自己的曲目库**:

> 在一个人自己的曲目库里,他最早报告的那些兴趣,是不是比从他自己库里随机抽的更罕见?

这个提法对**去均值的做法 · 他喜欢多少东西 · 他整体早熟不早熟 · 问卷覆盖度**全部免疫。

## 结果:两个数,反号,而且都是真的

| | Δ(最早一格的稀有度 − 库均值) | 库内分位 | 对人内置换零 |
|---|---:|---:|---:|
| **原始年龄** | **−0.2345** | **0.3252** | **49.4× / 54.5×** |
| **扣掉人群时间表** | **+0.0767** | **0.5314** | **14.5×** |

**原始年龄上:人从大家都有的东西开始。** 最早那一格在这个人自己库里按罕见度排,落在
**第 33 百分位**。种植正对照单调(−0.2345 → +0.0052),`#114` 的回忆偏差实际只贡献 17%。

**扣掉时间表后:反过来。** 最早那一格比随机抽的更罕见(第 53 百分位),与 `#128b` 同向。
`corr(Δ, S)` 匹配后 **+0.0532(5.1×)**,置换零 26%,保留 104%。

## 机制:我的第一个解释被自己的检验否定了

我写下的解释是「argmin 由左尾决定,而题目均值对左尾是盲的」。**测了,是错的。**

| 题目层 Spearman(稀有度, ·) | ρ | p |
|---|---:|---:|
| 起始年龄 **10 分位**(我的解释) | −0.091 | 0.628 |
| 起始年龄 **均值**(`#128` 用的) | +0.011 | 0.954 |
| 起始年龄 **中位数** | **+0.437** | **0.014** |

真正的机制是**中位数**:罕见类别确实来得更晚,而**均值对此完全盲**。

⚠ **这修正了 `#128` 的一句话**:「人群层的题目回归几乎为零(r = +0.064)—— 这是纯人层效应」
是在**均值**上算的,而均值在这里是错的汇总。`#128b` 的数字不受影响(双向去均值精确移除
题目均值),但它的**范围陈述**错了:人群时间表**确实**按常见→罕见排列。

## 判定

**两个层次,两个方向,都成立。**

- **人群层**:版图从大家都有的东西开始,罕见的更晚(中位数 +0.437)。
- **人层**:每个人相对这条共享曲线**提前了自己那一份**,而口味越罕见的人提前得越多。
