# R448 · 「潜变量」这个词不能用 —— 但不是因为它被排除了

`#403d③`:「合起来更强」**不等于**「存在一个潜变量」。本轮测它。

## ⚠⚠ 秩检查(跑之前)杀掉了一半的设计
| 设计矩阵 | 秩 / 列数 | |
|---|---:|:--|
| `[1, BOTH_sum, z(S), −z(五题)]` | **3 / 4** | **秩亏 —— `BOTH_sum` 的系数不可识别** |
| `[1, BOTH_min, z(S), −z(五题)]` | **4 / 4** | 满秩 —— 可跑 |

`BOTH_sum` 是两个成分的**精确线性组合** ->
**那个版本的检验不是「跑出来是零」,是「按构造不可能跑」。**
`min` 是**非线性**的,所以只有它可以携带成分之外的东西。**跑之前就把一半的设计关掉了。**

## 结果:`BOTH_min` 控制两成分后**塌掉**
| | |
|---|---|
| 不控制两成分 | **+0.1238** (se 0.0132) |
| **控制两成分后** | **+0.0181** (se 0.0234) |
| offset 零(`lib.nulls.perm_in`) | −0.0012 ± 0.0241 · 95 分位 **0.0459** |
| | **+0.80 sd -> 未越阈** |

## ⚠ 但这个零**也不可发布**
guard 26:**MDE = 0.080**,而有意义的幅度是 **0.05** —— **1.6× 偏大**。
**⇒ 我既不能说「它带着成分之外的东西」(没越阈),也不能说「它什么都不带」(看不见那么小的东西)。**
> **「潜变量」这个词不能用 —— 而理由是「没有证据支持它,且这个设计也证不了它不存在」,
> 不是「它被排除了」。这两句话在页面上占的位置不同。**

## ⚠ 一个**不是零**的旁证:在「治疗性」上,两半不对等
同一模型里:`z(S)`(冷门)**+0.0468** · `−z(五题)`(常规也管用)**+0.1234**。
**在两格的区分上(`#403a`)两半是对等的;在「治疗性」上,几乎全是「常规也管用」那一半在做工。**
⚠ 两个系数各自没有单独的阈(本轮的阈是给 `BOTH_min` 建的)-> **这是描述,不是判定。**

## 对照
秩检查 ✅ · 负对照**越阈率 5.0%** ✅ · offset 零非退化 ✅ · guard 26 **FAIL**(已如实记)。

## IMPOSSIBLE
① `min` 的非线性可能只是**截断**,而截断本身能解释一点方差 —— **那不是「潜变量」**;
② 「治疗性」与两成分本来就有关(`#398b`)-> 这不是干净的外部结局,只是**没参与构造**的结局;
③ 「还在」不等于「是一个心理构念」。

## 一句关于人的话
没有。**产出是:一个在花计算之前被秩检查杀掉的设计,和一个被精确划定边界的「不能说」。**
