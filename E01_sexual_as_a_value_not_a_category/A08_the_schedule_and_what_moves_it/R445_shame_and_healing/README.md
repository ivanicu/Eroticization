# R445 · 既深深羞耻、又觉得这件事在治愈自己的人,有 **1,790 个** —— 比偶然还多

页面把羞耻与「治疗性」当作两个独立的结局在处理(四条路 vs 两条路),**但从没量过它们的联合分布。**
⚠ **这一轮不控制任何东西** —— 问的是**这些人存不存在**,而控制会把一群真实的人变成一个残差,**残差里没有人**。

## ① 线性上,它们几乎完全无关
**`corr(羞耻, 治疗性) = +0.0005`**(n=15,501)。**不是负相关,是零。**
**⇒ 「羞耻」与「疗愈」不是同一条轴的两端。**

## ② 而「两者都高」比独立期望**还多**
| 格 | 占比 | 人数 |
|---|---:|---:|
| **都高** | **11.55%** | **1,790** |
| 只羞耻 | 21.27% | |
| 只疗愈 | 20.22% | |
| 都低 | 46.96% | |

⚠ **零的种类**:`offset_control` —— **「都高」占比的零绝不是零**,
**两者的边际分布决定了即使完全独立也会有一群人落在那一格**。
零 = **边际不变、配对被打断** = **10.43% ± 0.18%**,95% 区间 [10.08%, 10.77%]。
**实测 11.55% -> +6.13 sd,高于零。**

## ⚠ 一条**正确的**非单调灵敏度曲线(本会话第一条)
MDE 扫描:压制 2%/4%/6% 的「都高」-> 检出 100%/100%/100%;**压制 10% -> 0%**。
**不是 bug**:压掉 10% 恰好把 11.55% 拉到 **10.4%** —— **正落在零的中央**。
> 前几次非单调都是「曲线量错了东西」(`#387c`);**这一次非单调是设计正确的表现** ——
> 因为主量是**与零的偏离**,而不是**值本身**。**同一个形状,两种完全不同的诊断。**

## 对照

## IMPOSSIBLE
① 中位数分割丢强度信息 -> **相关(连续)与四格(离散)同轮都报**;
② 两题同一份问卷自报 -> 同源方差会**抬高**相关,即**偏向「一条轴」**,所以「零相关」方向上**保守**;
③ **「存在这群人」不等于「这群人是一个类型」。**
