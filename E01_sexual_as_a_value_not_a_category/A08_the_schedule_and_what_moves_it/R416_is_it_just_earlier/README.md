# R416 · 那个负号有一半是「他整体就来得早」—— 而剩下的一半这个设计看不见

`#371b` 的负号有两个读法,指向**不同的干预**:
**A「没有框架」**(可干预:给它语言)· **B「本来就更冷门」**(不可由解释缓解)。
B 的最直接版本(`S` = 整体稀有度)已在模型里。**B 还有一个变体没控:整体起始年龄更早。**

⚠ 代数检查(`#331a`):`ord` 是**秩相关**,对人层单调平移不变 -> 与 `EARLY` **无恒等式**。
实测 `corr(ord, EARLY) = +0.1661` · `corr(EARLY, 羞耻) = ` 与 `#332` 一致。

## ⚠ 两处自己的判据用错了,都被结果自己揭穿
**① guard 21 是给**零**用的,而本轮的 kill 是**开火**的。**
第一版无条件调了它,于是它拿一个 NULL 的判据去评一个非零结果并 FAIL。**判据要配结果的种类。**
**② 那条 MDE 扫描种的不是它声称的掉幅。**
我写 `y = −0.029*((1−f)*o + f*e*sign)`,以为「掉幅 = f」。不是 —— `o` 与 `e` 相关 +0.166,
控制 `e` 既拿走 `e` 那份、也拿走共线那份,实现的掉幅不等于 `f`。
**告密者是它自己**:扫描说「种植 50% 只有 60% 检出」,而实测 48% 却在地板之上 **+9.69 sd**。
> **一条声称比实测更迟钝的灵敏度曲线,通常不是设计弱,是曲线量错了东西。**
换成**掉幅自己的 bootstrap 区间** —— 它回答的正是「这个掉幅有多准」。
