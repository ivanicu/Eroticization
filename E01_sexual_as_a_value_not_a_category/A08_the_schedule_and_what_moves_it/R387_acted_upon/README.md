# R387 · 那 42% 也不是「能不能被实施」

`#341c`:开放问题照旧。人眼里有一个显而易见的读法(更羞耻的一端有真实对象与后果)——
**但那是一个名字,而这里已死过五次命名。所以不起名,问一个可测的代理。**

代理:问卷里已有的 **「我已经实践/试验过所有让我兴奋的东西」**(`41kpfir`),
逐类别算「报了这一类的人在这道题上的平均分」。

## ⚠⚠ 共享方法方差:先报,而它这次不成问题
人层 `corr(已实践, 羞耻)` = **−0.0433** —— 两道题在人层几乎不相关,
**所以「一致地在两道题上都说是」这个担心在这里不成立。**

## 结果:吃不掉
| | R² | 置换分位 |
|---|---:|---:|
| 单独(`corr(残差, 类别层已实践)` = **−0.1667**) | **0.0278** | **0.366** |
| 四个已有量 | 0.0236 | — |
| 五个量(加上它) | 0.1811(增量 +0.1575) | **0.366** |

置换零:单独 **0.0329 ± 0.0429** · 五量 **0.1646 ± 0.0927** —— **两个都落在零里。**

- **正对照**(只由该代理驱动的合成残差):R² **0.7986** —— 判据完全有能力抓到。
- **负对照**(随机残差):R² **0.0393 ± 0.0559**,与解析 1/31 = 0.032 一致。
- **guard 21**:分位 0.366 · MDE **0.117** · 灵敏度已证明 · 有意义量 0.30 —— **这个零可以发布。**

## ⇒ 开放问题又活过一个候选
方向是负的(−0.1667:拥有者实践得越多、残差羞耻越少),**符合直觉,但与噪声分不开。**

⚠ **边界**:「已实践」混着**机会**与**意愿**,**不能读成「可实施性」本身。**
