# R419 · 这份问卷里没有第三个 `form` 指标 —— 而页面上那个 `+0.468` 是 `2r`

页面上最脆的一步:`form` 的 Spearman–Brown 可靠性只有 **0.380**,而 disattenuation **拿它当分母**。
**若有第三个同构念的题,α 会升,分母会稳。** 找。

## ① 最像的那个是 `biomale`,而它不是同一个构念
93 个数值型候选,对 `form` 残差(去掉六坐标)求 |r|:
`biomale` **0.2100** · `givepain` 0.1255 · 「被支配唤起」0.1214 · 「被臣服唤起」0.1182 …
⚠ offset 零(**同样多(93)的合成噪声列取最大值**,200 次)= **0.0400 ± 0.0062**,95 分位 0.0517
-> 实测 0.2100 **越阈**(最大值天然为正,所以这个零绝不是零)。
**⇒ `form` 的残差有很大一块是性别的 —— 与 `#325` 的「两个指标在性别上分歧极大」一致。**

## ② 前 25 个候选里,同构念的:**0**
判据 = (a) 与 `animated`、`written` **都**正相关且比值在 [0.5, 2];(b) α({a,w,X}) > α({a,w})。
⚠ `#374b` 的教训照搬 —— **一个从未开火过的判据,它的每一个「不是」都是沉默,不是无罪**:
- **正对照**(真的第三个平行指标):**开火**,r_a +0.562 · r_w +0.542 · **α₃ 0.7038** vs α₂ 0.3633
- **负对照**(纯噪声):**不开火**,α₃ 0.1786

**⇒ 「`form` 是这份问卷测得太粗的一个维度」不是待办,是最终结论。**

## ③ ★ 而页面上有一处**算术**自相矛盾 —— 不需要新数据就能定
`#316` 写:「可靠性 **0.380**(`animated`↔`written` = **+0.468**)」。SB(r) = 2r/(1+r) 是恒等式:
| | |
|---|---|
| 若 r = +0.468 | SB = **0.6376** ≠ 0.380 |
| 若 SB = 0.380 | r = **+0.2346** ≠ +0.468 |
| 而 2 × 0.2346 | = **0.4691** ≈ 0.468 |

实测(掩码 `ok` + 两题都有作答,n=**6,478**):**r = +0.2345 · SB = 0.3799**。
**⇒ 页面把 SB 的分子 `2r` 当成了 `r`。可靠性 0.380 是对的,`+0.468` 是错的,改成 +0.2345。**
