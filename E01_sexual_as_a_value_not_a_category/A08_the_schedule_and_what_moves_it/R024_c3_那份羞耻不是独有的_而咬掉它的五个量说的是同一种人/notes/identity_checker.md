# R420 · 页面算术核对器 —— 4 条三元组全部对上,而覆盖率只有 **3.1%**

⚠ **这是 CLOSURE,不是 FRONTIER**(§0.2)。它不分离任何世界,它**保护已有结论**。

`#375c` 靠的不是新数据,是让页面上两个数**互相约束**。本轮把那一招做成常驻仪器。

## 结果
| | |
|---|---|
| 抽到的恒等式三元组 | **4** / 页(SB · CI-lo · CI-hi · sd 距离) |
| 不一致 | **0** |
| 页面加粗数字 | ~130 / 页 |
| **覆盖率(诚实下限)** | **≈ 3.1%** |

**⇒ 「0 条不一致」的意思是「我能核的那 3% 里没有错」,不是「整页算术干净」。**

## ⚠ 而第一版报了 **6 条不一致** —— 全是假阳性,且本轮 IMPOSSIBLE 栏预言过它
第一版用**标量容差**。但印出的数是**四舍五入**的:
`± 0.0034` 的真值在 [0.00335, 0.00345] -> `(0.2219−0.0884)/sd` 的真值范围是 **38.667–39.881**,
而页面印的 **+38.9 在里面**。
> **一个标量容差把「排版」报成了「错误」,而它的方向是制造假警报。**
> 假警报比漏报更贵:它会让我去改一个**本来是对的**数。
修法:**区间算术** —— 每个印出的数按它自己的位数展成区间,恒等式在区间上求值,
**只有当印出值的区间与恒等式的区间不相交时才判不一致。**
