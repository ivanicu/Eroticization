# R443 · 两种**互不相关**的性响应方式,都让这件事更像疗愈

`#398c` 撞见两道题,都与「治疗性」残差正相关,且都不是已知的四条路。本轮做那次欠下的复制。

## ⚠ 而第一件事就把我的框架推翻了:`corr(P1, P2) = **+0.0314**`
| | 题 |
|---|---|
| **P1** | 「**如果伴侣被某样东西唤起,我也能被它唤起**,即使我平常并不觉得那东西色」 |
| **P2** | 「我能被伴侣做我喜欢的事唤起,**即使我知道他自己并不被唤起**」 |

**它们在内容上几乎相反**:P1 = **我吸收对方的兴奋**;P2 = **我不需要对方的兴奋**。
而 `r = +0.031` —— **几乎正交,和内容一致。**

## 结果:两道**各自**存活
| | 单独放(另一道**完全不进模型**) | 一起放 | 单变量零 |
|---|---:|---:|---:|
| **P1** | **+0.1038** (se 0.0121) | +0.1030 | 0.0241 **越阈** |
| **P2** | **+0.0661** (se 0.0121) | +0.0648 | 0.0261 **越阈** |

一起放几乎不动(−0.8% / −2.0%)—— **因为它们本来就不相关。**

## ⚠ 我预注册的**标签**错了,而**断言**是对的
我注册的是「两道各自越阈 -> **一个构念的两个指标**」。
**断言(各自越阈)成立;而「一个构念」这个名字被 `r = 0.031` 推翻** ——
**一个共同因子必然在指标之间诱导相关,而这里没有。**
> **⇒ 它们是两件不同的事,各自独立地预测同一个结局。**
> 这比「一个构念的两个指标」信息量**更大**:一个构念只是一条路,两件不相关的事是**两条**。
> 而我差点因为门 PASS 就把那个名字写上页面 —— **门检验的是断言,不是我给断言起的名字。**

## ⚠ 而共同点是什么,只能是**假设**,不是结论
两道都在描述**在不是自己默认的情形下也能被唤起**。
**这是我读出来的,不是测出来的**(`r = 0.031` 恰恰说明没有一个共同因子把它们绑在一起)。
**下一轮才能测它。**

## IMPOSSIBLE

   所以「不相关」这个结论方向上是**保守**的;
