# R378 · 羞耻有三条路,而其中两条之间有一点重叠

符号约定:三条都指向「更多羞耻」(`EARLY = −起始均值`)。
⚠ 关键控制先报:`corr(起始均值, S)` = **−0.1952** · `corr(EARLY, c3⁻)` = +0.1372 ·
`corr(S, c3⁻)` = +0.2051 —— **三者两两都只弱相关。**

## 三条路的增量,量级相当
| | ΔR²(去掉它之后掉多少) |
|---|---:|
| `c3⁻` 广度型 | **0.949pp** |
| `S` 位置 | **0.491pp** |
| **`EARLY` 起始早** | **0.484pp**(= `S` 的 **99%**) |
| (控制)类别数 | 0.001pp |

主效应模型 **R² = 3.075%**。**起始年龄是一条和「位置分」一样粗的独立路。**

## 交互:三个里有一个不是零
| | 系数 | 置换零 | \|零\| ≥ \|观测\| |
|---|---:|---:|---:|
| `S × c3⁻` | −0.0108 | +0.0011 ± 0.0099 | 0.300 |
| **`S × EARLY`** | **−0.0395** | −0.0012 ± 0.0124 | **0.000** |
| `c3⁻ × EARLY` | +0.0039 | +0.0015 ± 0.0145 | 0.767 |

**`S × EARLY` = −0.0395,是它自己置换零展布的 3.2 倍。负号 = **次可加** ——
「口味冷门」和「来得早」加起来,比两份之和**少**。**

⚠ **多重性**:三个交互一起测,而置换只做了 30 次 -> **分辨率下限 1/30 ≈ 0.033**;
Bonferroni 校正到 3 个检验后,证据是**边缘**的。**报 PLAUSIBLE,不报 CONFIRMED。**

正对照(种入 `S × EARLY` = 0.15):读出 **+0.1394**,另两个 −0.0095 / +0.0035 —— 判据准。
三个交互合计只给 R² 加 **0.196pp**(3.075% → 3.271%)。

## ⇒ 读法
- **`#308a` 站得住**:`S` 与 `c3⁻` 相加(交互落在零里,分位数 0.300)。
- **新的**:`EARLY` 是**第三条同等粗细**的路。
- **PLAUSIBLE**:`S` 与 `EARLY` 之间**次可加** —— 而这与 `#130` 的人群时间表一致
  (早来的兴趣本来就更冷门,`corr = −0.1952`),**两条路在源头上就有一点是同一件事。**
