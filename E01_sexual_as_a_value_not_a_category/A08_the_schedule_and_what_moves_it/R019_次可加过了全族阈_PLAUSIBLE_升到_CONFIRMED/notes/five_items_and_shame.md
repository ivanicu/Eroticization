# R439 · 同一个分数,同时带来更多羞耻**和**更强的「我能停下来」

页面上有两条线:**羞耻线**(羞耻→少做→觉得改不掉;而**羞耻本身不预测「能不能改」**,`#384a`)与
**可塑性线**(常规的东西越不色 → 越觉得能停下来,`#392c` 翻正方向后)。**它们是同一条吗?**

## 结果:世界 A(同源)
| | |
|---|---|
| 五题 → 羞耻(原始) | **+0.0827** |
| **控制 `S`/`c3⁻`/类别数后** | **+0.0657** (se 0.0126) |
| offset 零(**`lib.nulls.perm_in`**,掩码内打乱) | +0.0015 ± 0.0126 · 95 分位 **0.0247** |
| 距零 | **+5.10 sd,越阈** |

**⇒ 常规的东西对他越不色,他**越羞耻** —— 而同一个分数也让他**越觉得自己能停下来**。**
⚠ 而 `#384a` 已证明**羞耻与「能不能改」彼此不相关**(+0.0135,有功率的零)。
**⇒ 这个分数是两件**彼此无关**的事的共同前项。**

## ⚠ 负对照的第一版是**空的设计**,当场就 FAIL 了 —— 而它按构造 5% 的时候会
它是**一次抽样**,而阈**就是同一个分布的 95 分位**。
> **一个从建阈的同一个分布里抽出来的单次负对照,不可能提供信息:
> 它 5% 的时候「失败」,而那正是阈的定义。**
改成**越阈率**:200 次独立抽样,**8.5%**(合格区间 1–12%,阈按定义应给 ≈5%)。

## 对照
guard 26(MDE 扫描 **0.05 ≤ 有意义 0.05**,擦线)· **阳性参照**(真实数据:`c3⁻ ↔ 羞耻` = **+0.1093**,开火)·
负对照越阈率 8.5% · offset 零非退化。**五个门全过。**

## IMPOSSIBLE
① 五题与 `S` 只相关 −0.021、与类别数 −0.146 -> 控制它们不是过度控制(两个数都小);
② 全自报,同源方差;③ MDE 0.05 恰等于有意义幅度 —— **擦线,强度不宽裕**。

**更多的羞耻,和更强的「我要是想停,是停得下来的」。**
**而这两样彼此并不相关。**
