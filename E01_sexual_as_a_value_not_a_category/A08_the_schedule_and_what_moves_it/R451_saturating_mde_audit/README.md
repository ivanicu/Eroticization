## ⇒ 修的不是正则,是**接口**(`#383a` 第三次应用)
**「主量是离散还是连续」在代码里没有标记 —— 那就让调用者声明它。**
`guard 26` 现在接受 `main_quantity`(`continuous` / `discrete_count`)与 `sweep_detection`:
- **离散但没给扫描** -> **FAIL**(「MDE 单独不可采信」);
- **离散且扫描每一级都 100%** -> **FAIL**(「MDE **不可测**,不是很小」);
- 离散且扫描不饱和 -> 正常判定;
- **不传 `main_quantity` 的旧调用,逐字节不变。**
**8 个攻击向量**,含「打错直接 `ValueError`」与「离散+饱和时即使种在争议之下也 FAIL」。
