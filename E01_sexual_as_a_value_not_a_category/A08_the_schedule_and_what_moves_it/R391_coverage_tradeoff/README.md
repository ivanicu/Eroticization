# R391 · 宽口径对 `c3` 几乎免费,而它把 `S ↔ 羞耻` 抬了 45%

`#345c`:`cov>=8` 把 n 从 15,503 砍到 6,717,而那正是 `#390` 功效不够的来源。

## 三档口径
| | n | `c3` 分半 \|cos\| | `c3⁻ ↔ 羞耻` | **`S ↔ 羞耻`** |
|---|---:|---:|---:|---:|
| `cov>=8`(**当前口径**) | 6,717 | **0.8426** | **+0.1278** | **+0.1185** |
| `cov>=6` | (中间) | — | +0.1290 | **+0.1477** |
| `cov>=4` | **12,720** | **0.7586** | **+0.1290** | **+0.1715** |

正对照(两半都用全样本 C)|cos| **1.0000**;负对照(随机 32 维)**0.1526 ± 0.1109**。

## ① 宽口径对 `c3` 几乎是免费的
**n 从 6,717 到 12,720(√n 增益 1.38×,MDE 降到 73%),而 `c3` 的分半 |cos| 只掉 10%
(0.8426 → 0.7586),`c3⁻ ↔ 羞耻` 纹丝不动(+0.1278 → +0.1290)。**
⇒ **`#390` 可以用宽口径重跑。**

## ⚠⚠ ② 但它把一个**已发表**的数抬了 45%
**`S ↔ 羞耻`:+0.1185(cov≥8)→ +0.1477(≥6)→ +0.1715(≥4)。**

> **这是一个新的、量级很大的口径旋钮,而它落在页面上的一个头条数字上。**

⚠ 方向值得注意:`S` 在低覆盖的人身上是从**更少**的块估的 —— **噪声更多本该把相关压低**,
而它**升高**了。**所以低覆盖的人不只是更吵,他们在系统上不一样。**
**本轮不解释这一点**(那需要它自己的设计);**只把它登记为旋钮并标注方向反常。**
