## ⚠ 一条更一般的:**合成分不等于共同因子**
`form` 是两个 z 分的**平均**,它同时带着**共享**方差与**各自独有**的方差。
**所以「合成分与 X 的相关」可以几乎全部来自一个指标,而合成分看起来仍像一个维度。**
**任何用两指标 composite 报的相关,都该同时报两个指标各自的那一个。**
