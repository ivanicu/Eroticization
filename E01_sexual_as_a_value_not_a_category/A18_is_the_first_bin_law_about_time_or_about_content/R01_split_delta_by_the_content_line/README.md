# R01 · 把 Δ 按内容线切开

## 内容线不解释它

六个连贯分割,每个的两侧各算一次 Δ(两侧下采样到共同的 k=10):

| 分割 | Δ_A | Δ_B | 差 | 倍数 |
|---|---:|---:|---:|---:|
| PC1(早/晚) | −0.0154 | −0.3308 | +0.3154 | 2.7× |
| PC2 | −0.3428 | −0.1754 | −0.1673 | 7.3× |
| PC3 | −0.3377 | −0.1694 | −0.1684 | 6.6× |
| **PC4(物件/叙事)** | −0.3674 | −0.1364 | **−0.2310** | **9.4×** |
| PC5 | −0.3458 | −0.1072 | −0.2385 | 8.1× |
| PC6 | −0.4168 | −0.0849 | −0.3319 | 9.1× |

**每个分割的两侧都差很多,而 PC4 一点都不特别**(超出其余中位数 **0.2×**)。
所以「最早那一格更常见」**不是**关于"哪种东西先被认成性的"。

## 第四个死掉的机制:稀有度离散度

`corr(|Δ|, sd(该侧稀有度)) = **+0.191**`,而归一化后离散系数**纹丝不动**(0.55 → 0.55)。

(前三个:左尾 `#130d` 死 · 中位数时间表 `#131c` 被削弱 · 审查 `#132a` UNVERIFIED。)

## 而真正在动的东西找到了:谁够格进入分析

| 相关(12 个侧格) | 值 |
|---|---:|
| **corr(\|Δ\|, 合格者的平均类别数)** | **+0.661** |
| corr(\|Δ\|, log 合格人数) | −0.570 |
| corr(\|Δ\|, 该侧稀有度离散度) | +0.191 |

**\|Δ\| 从 0.0154 到 0.4168 —— 27 倍**,而合格者的平均类别数从 17.5 到 27.0。

> **「最早报告的那批兴趣更常见」不是一条普遍规律。它的强度随这个人喜欢的东西有多广而变:
> 口味越广的人,他最早的那批越集中在大家都有的东西上。**

## 判定

`#130a` 的 Δ = −0.2345 **不是一个常数,是一个关于特定纳入规则所选出的人群的数**。
它的范围陈述必须加上"在什么纳入条件下"。
