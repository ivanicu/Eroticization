# R494 · 同一个数,两个零,相反的判决

⚠ **FRONTIER**。`#449` 的 NEXT:假对照失败是因为**杠是用错的零建的**。

## ① 只换零,**不换判据**(换两样就是移门柱)
判据始终是「四个结局里最大 \|b\| 越过 95 分位」。

| | |
|---|---:|
| **观测 max\|b\|** | **0.04975** |
| 零 A(打乱**人**)· 95 分位 | **0.04680** -> **越阈** |
| 零 A 均值 | 0.02810 |
| **零 B(随机**六块划分**)· 95 分位** | **0.07254** -> **未越** |
| 零 B 均值 / 中位 | 0.04040 / 0.03839 |

**对照**:两个零**明显不同**(0.0468 vs 0.0725)· 零 B **有功率**(均值 0.0404 < 观测)。

## ★★ ② 两个零排除的是不同的世界
- **打乱人** -> 排除「这个量与结局无关」;
- **重抽划分** -> 排除「**随便哪六块都行**」。

**对一个关于特定内容的主张,只有第二个才是正在被提出的那个问题。**
在它之下,n=2,490 时 -> **ANY_SIX_WOULD_DO。**

## ⚠ ③ 这**不触及**载荷那条结果
`#444c`/`#445b` **从一开始就用块标签零**,在全样本上 **4.3 sd**、**20/20 复制**。
本轮定下的是更窄的一件事。

## 一句关于人的话(方法轮)
**一个数在这里显不显著,取决于拿哪个零去问它 ——**
**而正确的零由「你要排除哪个世界」决定,不由「哪个更严」决定。**

## IMPOSSIBLE
① n=2,490 的子样本由题目决定;② 500 次划分零 -> 95 分位分辨率有限;
③ **本轮没有否定体液内容效应**,只否定了「在这一臂、这个样本量上它是特定于这六块的」。
