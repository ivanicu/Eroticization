# R265 · 双约束零:两侧边际都保住了,而它不是一个零

## 走法与硬前置

对一对类别 `(j,k)`,取值对为 `(a,b)` 与 `(b,a)` 的两个人,**各自在自己内部交换**:
行多重集不变、两列一进一出净零。**硬前置全部通过**:

    观测数 ✅ · 人内多重集(抽 419 人)✅ · 题内多重集(全 31 题)✅ · 总和 ✅

## 但正对照失败,而失败的原因是结构性的

    种植后 Δ −0.0744  ->  施加双约束零后 **−0.0796**(不但没毁,还略强)

**为什么**:我种的信号把「题均值 × 稀有度」的相关从 **+0.064 推到 +0.997** ——
**信号被写进了题内边际本身**,而一个**保边际的零按定义保住它**。

> **而一个不改边际的种植,就是从这个零自己的参照集里抽一个样本 —— 那不是种植。**

**所以:双约束零对这个估计量,在结构上不可能有一个有效的正对照。**
`#219` 注册的那个判定(D 接近 A/B 还是接近 C)**取不到数**。

## 两个诊断,一个成立一个不成立

- **不成立**:我先猜"种植让镜像伙伴消失、约束集变刚性"。
  实测镜像伙伴 真实 **31.6%** vs 种植 **24.2%** —— **没有塌,猜错了。**
- **成立**:零值**不随轮数变化**(rounds 1/3/8 → −0.0531 / −0.0550 / −0.0561)——
  **它不是在采样约束集,是被推到一个固定构型。**

## 顺带记下:那个"零"值本身

双约束重排给出 **−0.0566**,是真实 Δ(−0.0328)的 **173%**,**而且同号**。
**不引用它** —— 一个没有有效正对照的零,它的数值不可读。

## 结构上做不到

`Δ` 是**两侧去均值之后**的量,而两侧去均值移除的正是两侧边际 ——
**所以"固定两侧边际"与"Δ 想测的东西"在定义上纠缠**,
这不是实现问题,是这个零与这个估计量不匹配。
