# R342 · 用一个能通过正对照的结局侧代理,再问一次 —— 它也没通过

`#296a`:答题风格代理收回 −18.5%。它失败的原因是结构性的(人层的三个数压不动逐结局的信度),
所以换成**逐结局**的量:人层自助的 R² 噪声底 `sd_k`。

## 门 ① 的失败是干净单调的,不是噪声
给组 1 的 6 个结局加噪,扫描噪声强度:

| 加噪强度 | 那 6 格的 `sd_k` 比 | 那 6 格的平均 R² |
|---:|---:|---:|
| 0.00 | 1.000× | 0.0244 |
| 0.35 | 0.960× | 0.0212 |
| 0.70 | 0.855× | 0.0159 |
| 1.40 | 0.666× | 0.0088 |
| 2.00 | **0.581×** | 0.0062 |

**信度降,`sd_k` 跟着降 —— 与我注册的方向完全相反,而且是干净的单调关系。**

> **在 R² ≈ 0 的区间,R² 的自助 sd 量的是**效应**,不是**噪声**。**
> 一个有界统计量的抽样 sd 在边界处塌缩,所以它**恰恰在噪声底最要紧的区间失效**。

⚠ 门 ② **过了**(收回 **+67.8%**)—— 但那是**跑完之后**才知道的,
按跑之前写下的门,门 ① 没过就不读第二臂。**看到结果再挑哪个门算数,就是没有门。**
