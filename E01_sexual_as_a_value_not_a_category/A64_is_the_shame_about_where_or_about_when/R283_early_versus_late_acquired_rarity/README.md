# R283 · 羞耻贴的是「你现在敞开在哪」,还是「你什么时候开始敞开在那儿」

起始仪器带着块仪器**没有的东西:时间**。对每个人,把他报告了起始年龄的类别
按**他自己的**起始年龄中位数劈成早/晚两半,各算一次**平均罕见度**。

## 结果:两个注册的世界都不对,而第三个结果是可分辨的
| | 分半信度 | 单独 beta | 解衰减 | **同时放进去(n = 4,574)** |
|---|---:|---:|---:|---:|
| **早半** | 0.5163 | **+0.1822 ± 0.0088** | **+0.2536** | **+0.1307 ± 0.0137** |
| 晚半 | 0.3949 | +0.1079 ± 0.0150 | +0.1716 | +0.0788 ± 0.0157 |

**晚−早 = −0.0519,是自身展布的 2.5× —— 可分辨地为负。**
两个都在联合模型里存活(早 9.5× · 晚 5.0×)。置换羞耻的零 −0.0026 ± 0.0094。
正对照两端都过:只贴晚半的合成结局 → 晚−早 +0.3127;与两半等相关 → +0.0227。

⚠ **信度差不能解释它**:早半信度更高(0.5163 vs 0.3949),这本会天然抬高它的 beta ——
但**解衰减之后早半仍然更强**(+0.2536 vs +0.1716)。

> **注册的 kill 预测「晚半更强」,实测是早半更强,而且可分辨。
> 世界①(两半相当)与世界②(晚半更强)都不对。**

## ⚠ 最强的替代解释是活的,而且我在跑之前就登记了它
`#114` 测到人**把最爱的兴趣记得更早**(−0.2000 年/评分 sd)。
若早半因此富集了「爱得最深」的兴趣,而羞耻跟强度走,就会造出这个图样。
**所以这是一条关于「这份自报时间线」的事实,不是关于真实发展顺序的事实。**

## 一句关于人的话
羞耻贴的**不是你后来走进去的地方**,而是**你最早就想要的那些东西有多冷门**。
(而这有一个平淡的可能:最早的欲望是在你还没有任何框架去把它正常化之前形成的。
这份数据分不开这个解释与「记忆把最爱的推早了」,两个都活着。)
