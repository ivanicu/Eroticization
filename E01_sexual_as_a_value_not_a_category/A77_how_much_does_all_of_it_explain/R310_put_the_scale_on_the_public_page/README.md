# R310 · 把「这一切到底有多大」写进公开页第一段

**类型:PRODUCTION**。`#264a` 的 kill 要求这条进公开页第一段,不能只写在某一行的作用域里。

## 措辞必须给三个数,而不是一个
只给「中位 1.4%」会被读成「所以这些发现没意义」。所以段落同时给:
**地板 0.14% · 中位 1.4% · 上限 7.8%**,外加正对照的 **49%** —— 证明仪器不是瞎的。

**明确挡住的两种误读**:
① **不**是说发现是空的(地板 0.14%,每个维度都过了自己的全族阈值);
② **不**是说性偏好基本随机(1.4% 是**这六个坐标**的射程,不是可解释性的上限)。

外加 `#264c`:**最不可靠**的那个维度(位置分 0.432)贡献了**最大**的增量 R²(0.715%)——
**信度与解释力是两回事。**

## 顺带修准两个过期计数
开头写着「206 轮 / 164 条」,实测 **309 个轮目录 / 最大条目号 264**。已改。

## ⚠ 双语页的同一个失败模式第二次出现
锚点用**英文小标题的字面文字**去找中文页 → 抛错,而英文那一半已经提交推送
(`#243` 修正过一次的同一个模式)。

> **双语页的锚点不能用文字,必须用结构**(第 n 个二级标题,或一个稳定的注释锚)。
> **文字锚在翻译过的文档里天然不稳,而失败是静默的 ——
> 一边成功一边失败时,两个版本从此说不同的话。**
