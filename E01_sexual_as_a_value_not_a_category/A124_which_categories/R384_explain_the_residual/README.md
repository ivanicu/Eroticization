# R384 · 那四成,这个项目现有的量一个也解释不了

`#338b`:类别层羞耻的残差是抽样噪声的 **4.94 倍** —— 里面有真东西。
**而命名死过五次,所以问一个不需要命名的问题:那四成能不能被**已有的量**解释?**

## ⚠ 注册时列的一项不可算,如实报
`#327` 的 `c3⁻` 载荷是**块**仪器上的,而起始类别与块**题目不相交**(`#303` 里有 `assert`)——
**没有一一对应,不硬凑映射。** 改用类别层可算的四个已有量。

## 结果:解释得比随机还少
| | 系数 | 偏相关 |
|---|---:|---:|
| ① 该类别的平均起始年龄 | +0.0186 | +0.1032 |
| ② 该类别起始年龄的 sd | −0.0081 | −0.0349 |
| ③ 拥有者的平均 `S` | −0.0148 | −0.0338 |
| ④ 拥有者的平均 `c3⁻` | +0.0335 | +0.0838 |

**R² = 0.0236**,而**置换零(打乱残差 2000 次)是 0.1323 ± 0.0831**
(解析期望 4/31 = 0.129)—— **零里 95.7% 的次数比观测还大。**

- **正对照**(只由 ① 驱动的合成残差):R² **0.7991** —— **判据完全有能力抓到一个真解释。**
- **负对照**(随机残差):R² **0.1350 ± 0.0841**,与解析期望一致。

## ⇒ 一个有功效的零 = 一个诚实的开放问题
**类别层羞耻里,稀有度解释了 58%;剩下的 42% 是真的(噪声底的 5 倍),
而这个项目现在拥有的每一个量都解释不了它。**

**它是什么样的**(`#338b` 的描述,**不是名字**):
比稀有度预测的更羞耻 —— `humiliation` · `gender` · `bestiality` · `incest`;
更不羞耻 —— `vore` · `brutal` · `creepy/creature`。

## 一句关于人的话
**有些性兴趣带来的羞耻,比「它有多冷门」能解释的多,有些则少。**
这一部分是真的,而这个项目手里现有的任何一把尺子都量不到它。
