# R383 · 稀有度解释了类别层羞耻的 58%,而残差里剩的东西是它的 5 倍噪声底

⚠⚠ **跑之前写下的**:这是**人层羞耻的重排**,**不是**「他为**这一类**羞耻」——
后者需要逐类别的羞耻题,而问卷**没有**。**下面读到的一切都是「报了这一类的人整体更羞耻」。**

## ① 稀有度解释掉一大半(跑前已声明会高)
31 个类别,每类别 n 从 **403** 到 **13,826**,平均羞耻从 **+0.370** 到 **+1.154**。
`corr(类别平均羞耻, rar_j)` = **+0.7583**(R² **0.575**;按 1/se² 加权 R² **0.652**)。

## ② 残差里剩的东西,是抽样噪声的 5 倍
**残差 sd 0.1450 vs 各类别 se 中位 0.0294 → 4.94×**;
负对照(**打乱人、保持类别结构**)残差 sd **0.0307 ± 0.0064** —— 正好落在抽样水平。
加权与未加权残差相关 **+0.9621**。

**比稀有度预测的更羞耻**(残差前 5):
`humiliation…` +0.301 · `gender…` +0.300 · `bestiality…` +0.242 · `incest…` +0.202 · (+0.170)

**比稀有度预测的更不羞耻**(残差后 5):
`vore` −0.298 · `brutal…` −0.178 · `creepy/creature…` −0.162 · (−0.162) · (−0.156)

⚠⚠ **这是一张描述性的表,不是一个名字。**
`#201`(媒介偏好)与 `#202`(表征 vs 真人)就是看着这样一张排序讲故事,然后被数据杀掉的。
**本轮不给它起名。**

正对照(只给一个类别的人 +1.0):残差最大的正是那一类(+0.865 vs 其余中位 −0.048)。

## 一句关于人的话
**一类性兴趣有多冷门,解释了「有这类兴趣的人有多羞耻」的将近六成。**
剩下的四成不是噪声 —— 它是抽样误差的五倍 —— 但这一轮不去说它是什么。
