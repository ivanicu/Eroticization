# R263 · 晚半上,三种零

`#217b`:零方案的分歧**只在受限的 `>18` 半上** —— 而那正是 `#214` 的 −0.224
与 `#216` 的 −0.4344 所在的地方。

`>18` 半 Δ = **−0.3034**(人层 bootstrap sd **0.0166**),复现 `#214`。

| 零 | 零值 | **净值** | 零占效应 | 负对照 |
|---|---:|---:|---:|:--:|
| A 题内跨人(`perm_null`) | −0.1197 ± 0.0233 | **−0.1837** | 39% | PASS |
| B 人内打乱 | +0.0525 ± 0.1169 | **−0.3559** | 17% | PASS |
| **C curveball 固定边际** | **−0.1983 ± 0.0423** | **−0.1052** | **65%** | **FAIL** |

**三个净值极差 = 0.2507 = 15.1× Δ 自身展布。**

## 结论:没有唯一的数,只能报区间

    晚半的净 Δ ∈ **[−0.356, −0.105]**,取决于用哪一种零

**`#214` 的 −0.224 与 `#216` 的 −0.4344 都只是这个区间里的点。**

## ⚠ 而最保守的那一种零,负对照直接失败

**curveball 固定边际**是本项目用得最多的零(34 轮)。在它下面:
**零 = −0.1983,是效应的 65%** —— **`negative_control` FAIL**。
**也就是说:保留每人条目数与每题被报人数之后,光靠边际就能造出晚半六成的 Δ。**

## 结构上做不到

三种零**问的是三个不同的问题**,所以"它们该一致"本身不是先验:
A 毁人层配对、保留每题值分布 · B 毁"这个人哪个类别配到哪个年龄" · C 固定双边边际。
**本轮判的不是它们该不该一致,而是它们给出的净值能不能被当作同一个数引用 —— 不能。**
