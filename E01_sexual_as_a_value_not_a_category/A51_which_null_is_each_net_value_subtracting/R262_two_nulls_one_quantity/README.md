## ② `#128` 主 Δ,两种零并排

    主 Δ = **−0.0328**(bootstrap sd 0.0035)—— 精确复现 `#128`
    零 A 题内跨人:+0.0022 ± 0.0016  ->  净 **−0.0350**
    零 B 人内打乱:+0.0040 ± 0.0062  ->  净 **−0.0368**
    两个净值之差 = **0.0018**,自身展布 0.0035 -> **0.5×,不可分辨**

**注册的 kill 不开火:主 Δ 上两种零一致。**
**所以 `#216c` 的警告是局部的** —— 分歧发生在**受限的 `>18` 半**(n=1,944),不在主量上。

## 本轮修掉的错:same_scale 家族

第一版 `rho_vec` 用 `need=6` 且**不套 `KEEP`**,算出 Δ = **−0.0401** 而不是 −0.0328 ——
`R173` 的 `betas` 只在 `KEEP`(≥8 个起始年龄)上取人。
**同一个名字,不同的人群。** 对齐后精确复现。
⚠ 而在**错的人群**上,两种零的差是 1.4×;**在对的人群上是 0.5×** —— 结论没变,但差点在错的底子上下判断。
