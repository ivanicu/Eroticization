## 第 10 条守卫

`lib/gates.py` 的 `has_error_bar(name, value, spread, spread_source)` —— 调用者必须**命名展布的来源**:

| 来源 | 判 | 它能回答的问题 |
|---|---|---|
| `bootstrap_人层` | PASS | 换一批人还会是这个数吗 |
| `split_跨劈分` | PASS | 换一种分法还会是这个数吗 |
| `seed_跨种子` | PASS(展布 >0 时) | 只在种子真的驱动真实臂时才有意义 |
| `analytic_解析` | PASS | 公式(如相关系数的 delta 法) |
| **`null_零臂`** | **FAIL** | **这是地板,不是误差棒** |

自测:四种输入,一通三挂(零臂 / 零展布 / 来源名不在名录)。

## 本轮修掉的自己的四个错(全在覆盖检查上)

1. `check_coverage` 的分子分母来自**同一个正则** —— 一个**不可能失败的检查**。分母改成独立计数。
2. 表格正则不限区域 → 命中账本各处的其它表(69 行,混进一个 `0`)。锁到第一条散文条目之前。
3. 只解析散文条目 → 漏掉 `#1`–`#16`(住在顶部表格里),而那是**最早的**那批,
   **最可能没有精度陈述** —— 偏差方向对我有利,必须补。
4. 分子用 `^## Entry (\d+),`(要求逗号),分母用 `^## Entry (\d+)` ——
   **两把不同的尺**,静静吞掉 3 条(`#81` `#103` `#123` 头部没有逗号)。

**一个覆盖检查最容易骗过自己的方式,就是分子分母不是同一把尺。**
