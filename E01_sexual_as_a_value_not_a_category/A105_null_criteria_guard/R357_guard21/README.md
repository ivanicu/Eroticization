不算数。**散文不是执行**(P9)。

⚠ **这是 Closure**(工具),不是 Frontier。

## 守卫做什么
一轮必须声明结论是 `EFFECT` 还是 `NULL`。
- `EFFECT` -> 本守卫不干预。
- `NULL` -> **三样必须同时在场**,三缺一 FAIL:
  ① **置换分位数**(观测落在零的哪里)· ② **MDE / CI 宽度**(能看见的最小效应)·
  ③ **正对照实际证明过的灵敏度**(种进去看见的,不是算出来的);
  再加一条内容性检查:**MDE 必须小于一个有意义的效应量**,否则这个零只说明「我看不见」。

**为什么是这三样**:没有分位数,读不出观测落在零的哪里;
没有 MDE,「没看见」和「没有」分不开;没有正对照,MDE 只是一个公式,不是一次观察。

## ⚠ 边界(写进守卫的 docstring 里)
**它检的是证据是否到齐,不检那些数算得对不对。** 一个编造的 MDE 一样能通过 ——
**它挡的是遗漏,不是造假。**
