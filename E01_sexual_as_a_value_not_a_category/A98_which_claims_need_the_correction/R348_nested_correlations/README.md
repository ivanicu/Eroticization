## ⚠ 但那 28% 是**仪器的**,不是声明的
把一个**真值 +0.25** 的相关种在同一个 `c3` 上,同一套嵌套程序把它掉 **39%**;
真值 +0.10 时掉 **57%**。`c3` 的 |r| = 0.128 落在两者之间,**预期衰减约 50%,实测只有 28%。**

> **留出读数对一个由数据估出来的潜变量,量的是「这个潜变量重不重现」,
> 而不是「这个声明真不真」。种植是唯一能把两者分开的东西。** → **guard 19**

**⇒ `+0.1286` 不必降级** —— 但必须注明它是**对这一份样本的 `c3`** 报的。

## 我担心的那个误设不成立
第一版把合成结局锚在**第 1 折的 c3** 上(各折 c3 不同,衰减像是构造出来的)。
改锚到**全样本 c3** 后:+0.1545 vs +0.1530 —— **几乎一样**。
衰减来自 `c3` 估计量自身的噪声,与真相关挂在哪个 c3 上无关。

## 先报「不需要这个修正」的声明(免得整片扣上去)
