# R414 · 在一个人自己身上,冷门的东西是**后**到的 —— 远比人口时间表能解释的多

⛔ **先记一条:`#369` 的 NEXT 跑不了,而证据早就写在项目里。**
我写的是「人×类别格子 + **人固定效应**」。`R382` 的 IMPOSSIBLE 一栏白纸黑字:
**羞耻是人层的一个数,格层回归的因变量在人内是常数。**
**人固定效应会把一个人内恒定的结局整片吸收 —— 那个设计的因变量方差恰好是 0。**
换法:不要人内**回归**,要人内**摘要**。

`ord_i` = 该人**自己**的类别里,「起始年龄」与「类别稀有度」的秩相关。**正 = 冷门的对他是后到的。**

## ② `ord ↔ 羞耻` = **−0.032**,方向是「早到的更羞耻」——但**低于自己的 MDE**
控制类别数与 `S` 后:**−0.03229**(se 0.01233,95% CI [−0.056, −0.008]),距零 **−2.48 sd**,越阈。
先算的 MDE:`+0.030` 检出 67.5% · **`+0.040` 检出 82.5%** -> **MDE = 0.040**。
**实测 0.032 < MDE 0.040 —— 这一次它越了阈,但同样大小的效应有约三分之一的重复会漏掉它。**
**⇒ 方向可报,强度不可报;不进页面,先复制。**
