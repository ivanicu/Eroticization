**且两个口径是不同的人群**(`#346b`)。

## ⇒ 两句话,而它们是同一句
1. **那条次可加不集中在「两样都最高」的那一撮人身上。**
2. **而 3×3 的分辨率放不下它** —— 回归里 |t| = 4.47 的东西,在九格上每一格都淹在噪声里。

**⇒ 它是一个平滑、分布式的乘性调节,不是一个角落效应。**
