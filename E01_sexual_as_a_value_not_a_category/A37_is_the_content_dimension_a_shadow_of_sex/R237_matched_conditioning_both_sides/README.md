# R237 · 两侧,同一个条件集

`#191c`:`#164`(位置侧)只去性别、保留 102%;`#236`(内容侧)去性别**+勾选数**、保留 54%–83%。
**两个数不在同一把尺上。** 本轮两侧都用「**只去性别 + 边际评估**」——
条件集与残差化一致(`#191a` 的教训)。

## 结果:同一把尺下,内容侧丢得比位置侧多

| 结局 | 侧 | 去性别前 | 去性别后 | 保留 |
|---|---|---:|---:|---:|
| 羞耻 | **位置 S** | +0.1185 | +0.1119 | **94%** |
| `animated` | **位置 S** | **+0.1193** | +0.1083 | 91% |
| `animated` | 内容 C | −0.0413 | −0.0331 | **80%** |
| `written` | 内容 C | −0.0545 | −0.0169 | **31%** |
| `biomale` | 位置 S | +0.0990 | **−0.0213** | 塌掉 ✅ |
| `biomale` | 内容 C | +0.1212 | **−0.0126** | 塌掉 ✅ |

**注册的 kill(内容侧保留 >90%)不开火:80% 与 31%。**
所以 `#236` 的 54% **不是**主要由勾选数造成的 —— **内容侧确实比位置侧更受性别影响**,
`written` 尤其(只剩 31%)。

负对照:内容种植与位置种植去性别后**都保留 100%**。

## 两件必须单独说的事

**① `written`/位置侧的「536% 保留」是零基数上的比值,无定义。**
去性别**前**它就是 `+0.0087`(0.7× 自身展布)。
`require_resolvable_first` 已把该族之后的比较判为 MOOT。

**② `#188` 那句「位置贴羞耻、内容贴媒介」,有一部分是控制勾选数造出来的。**
**边际**评估下,位置侧对 `animated` = **+0.1193(10.0×)**,
与它对羞耻的 **+0.1185** 在同一把尺上**不可分**。
`#188` 的分工图是在**给定勾选数**之后才那么干净的 —— 原始结构里位置同时贴两者。

## 结构上做不到

「只去性别」的保留率与「去性别+勾选数」的保留率**永远不可比**。
本轮产出的是前者的两侧对照,**不是对 `#236` 的替代**。
