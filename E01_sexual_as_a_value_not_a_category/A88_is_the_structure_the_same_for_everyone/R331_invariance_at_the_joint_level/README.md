# R331 · 结局层的不变性,改用联合 R² 曲线

`#285b`:结局层不可用 —— 随机劈的展布 **0.4247**,因为每个坐标各自的 29 格剖面本身就不稳。
**改比六个坐标合起来的联合 R² 曲线。**

## 修法生效:降噪 26 倍
| | 随机劈的展布 |
|---|---:|
| 每个坐标各自的剖面(`#285b`) | **0.4247** |
| **六个合起来的联合 R² 曲线** | **0.0161** |

## 结果:结局层也不不变,而且是 12.8×
| | |
|---|---:|
| 按性别劈 | **+0.6667** |
| **随机劈同样大小** | **+0.8728 ± 0.0161** |
| **差** | **−0.2061,12.8× 展布** |

正对照**两端都完美**:① 加入已知按性别不同的合成量 → 差 **−0.2553**;
② 加入 **`agreeableness`**(与 `biomale` 只相关 **−0.0749**,真实存在且几乎不随性别变)→ 差 **−0.0016**。
⚠ ② 用的是**真实变量**,不是纯噪声(`#285c` 的教训)。

两组差最大的三格:
`I sometimes find peop…` **1.9% vs 5.0%** · `I find the thought of…` **3.2% vs 0.6%** ·
`animated` **6.4% vs 8.9%**。曲线中位:组 0 **1.85%** · 组 1 **1.67%**。

> **这六个坐标在两个人群里,不只是**构造**不同(`#285a`,载荷层 2.6×),
> **预测**也不同(本轮,12.8×)。**
> **它们不是「人的坐标」,至少不是同一套坐标。**
