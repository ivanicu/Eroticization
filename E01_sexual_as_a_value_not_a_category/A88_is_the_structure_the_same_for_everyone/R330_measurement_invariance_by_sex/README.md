# R330 · 这套结构对不同的人是不是同一套

这个项目**控制**过性别(`#252a`),**但从没问过这六个坐标对不同性别是不是同一个东西**。
这不是控制问题,是**测量不变性**问题 ——
**若结构因人群而异,那它不是「人的坐标」,是「这个样本里占多数那群人的坐标」。**

两组 n = **3,232 / 3,485**(`biomale` = 0 / 1),各自**独立**重建六个坐标。

## ① 载荷层:可分辨的差别
| | |
|---|---:|
| 按性别劈(前 3 维子空间复现) | **0.7695** |
| **随机劈同样大小** | **0.8385 ± 0.0263** |
| **差** | **−0.0690,2.6× 展布** |

> **块层结构在两个人群里**不是**完全同一个 —— 差别不大(0.77 vs 0.84),但可分辨。**

## ② 结局层:这一格不可用
按性别劈 +0.3112 vs 随机劈 **+0.4195 ± 0.4247** —— **随机劈的展布是 0.42**,
即「任意两组的剖面相关」本身就在 −0.4 到 +0.8 之间乱跳。**在这个组大小上,这一格测不出东西。**
(六个坐标分别:+0.697 · +0.461 · **−0.525** · −0.075 · +0.668 · +0.640 —— 其中 c1 甚至反号。)

## ⚠ 而正对照②坏了,原因值得记
我用**纯噪声**当作「已知不随性别变的量」,期望它判不出差别。
实测性别劈 −0.1505 vs 随机劈 +0.5433 → **−0.6938**,远不是 ≈0。
**因为纯噪声根本没有稳定的剖面** —— 它在任意两组之间的剖面相关都是噪声,
**所以它测的不是「不变」,是「没有东西可以不变」。**

> **一个「应当判不出差别」的正对照,必须用一个**真的存在、只是不随分组变化**的量,
> 不能用一个**根本不存在**的量。**
> ⚠ 这是 `#254c`「比值/投影类的量做不了加法式正对照」的近亲:
> **正对照的失败,几乎总是因为我给它的那个东西不具备被检验的性质。**

## 判决
注册的 kill 要求**两层都不可分辨**才判「结构不变」。
载荷层可分辨(2.6×),结局层不可用 ⇒ **`UNVERIFIED`,而「结构不变」没有被证明。**

## 一句关于人的话
这六个坐标在男性和女性身上,**不是完全同一套** ——
差别不大,但它在最能测准的那一层上是可分辨的。
**这个项目此前一直把性别当作要扣掉的东西;它可能也是一条需要分开报的线。**
