# R349 · `c3` 是一条轴,还是一个旋转的选择 —— 是轴,但是一条软的

`#303b`:`c3` 的相关在嵌套下掉 28%,而那全部是**这个估计量的噪声**。**这一轮直接量它。**

| | 逐条 \|cos\| | 特征值间隙 |
|---|---:|---:|
| `c1` | **0.9569 ± 0.0168** | λ1−λ2 = +0.6279 |

| **三维子空间重叠** | **0.8524 ± 0.0324** | — |

- **正对照**(两半都用全样本 C):逐条 |cos| **1.0000** · 子空间 **1.0000**。
- **负对照**(随机 32 维):逐条 **0.1394 ± 0.1119** · 子空间 **0.0940**(解析 3/32 = 0.0938)。
- **参照**:`S` 的结构(选项流行度)在同样的劈半下重现 **+0.9973**(`#293a`)。

## 世界 A,但是弱的那一版
`c3` 单条 **0.796** 只比三维子空间的 **0.852** 低一点 ——
**它不是简并空间里的任意旋转**(那样单条会掉到子空间以下很多),**它是一条真的方向,但软。**
而 `c1`(0.957,间隙 0.63)是硬的。

> **羞耻的两条路不是同样结实的两个东西:**
> `S` 的结构重现到 **0.997**,`c3` 的方向重现到 **0.80** ——
> 而 `#303b` 说的那 28% 衰减,**就是这 0.80 的后果**。

## 按 `#300a` 的规矩:先发明一个能弄坏它的旋钮
`c3` 是从**选项劈分**的 A/B 交叉相关里估的 —— 换选项劈分种子:
**500 → 0.7800 · 900 → 0.7766 · 1200 → 0.8159**,极差 **0.039**。**没弄坏。**
