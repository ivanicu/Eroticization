# R246 · `animated` 与 `written` 是不是一条轴的两端

`#188` 起,**六轮**把它们读成「媒介偏好」(画的 vs 写的)。**而从没量过。**

## 不是

| | |
|---|---:|
| **`corr(animated, written)`** | **+0.2507 ± 0.0085(29.4×,n=14,188)** |
| 正对照刻度:`corr(biomale, written)` | **−0.2673** ← 「确实二选一」长这样(`#239`) |
| 负对照:`corr(written, written)` | +1.0000 |

**强正相关。它们不是二选一,是同时出现。**

三预测子分解上**符号全同 3/3**:

| 结局 | S(位置) | Cres(内容) | rho_i(何时) |
|---|---:|---:|---:|
| `animated` | **+0.0720** ★ | **−0.1035** ★ | **−0.0722** ★ |
| `written` | +0.0024 | **−0.0600** ★ | **−0.0318** ★ |

内容侧与时间侧对两者**同向**;只有位置侧把它们分开(`animated` ★,`written` 不显著)。

## 所以那个名字要撤

**内容维度预测的不是"你选画的还是写的"** ——
它预测的是**两者共有的那个东西**,而 `animated` 与 `written` 共有的最明显一点是:
**都不是真人。**

⚠ **但本轮不给新名字。** 上面那句是**事后解释**,而它没有被检验 ——
`#194c` 刚记过这个形状:**一个解释被它旁边的测量借去可信度**。
本轮只判"旧名字错了"。

## 结构上做不到

两道都是"我觉得 X 有情色感"的**正向**李克特,一个人可以两个都高 ——
**李克特上的"二选一"本来就不该期待强负相关**。
所以 kill 的判据写的是 `corr ≥ 0`,**不是** `corr > −0.15`;本轮判**符号**,不判"够不够负"。
