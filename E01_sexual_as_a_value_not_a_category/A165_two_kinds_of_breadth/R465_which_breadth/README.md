# R465 · 「广度」不是一个东西 —— 而落单的那一个正是 `form` 劈开的那一个

`#420a`:同一个预测量对「性行为计数」是 **−0.076**、对「恋物类别计数」是 **+0.049**。
**⇒ 那么页面上每一处「广度」都必须问:是哪一种?**
⚠ 这一步是**列举**不是猜(`#407b`)—— 五个量都在模型里当过控制项或主量。

## ⇒ 结构:四个是一件事,一个不是
`ncat` · `COVB` · `PICKS` 三者两两 **+0.83 ~ +0.86** —— **「你在这份问卷里卷入了多少」**;
`恋物类别计数` 与它们 +0.62 ~ +0.74 —— 同一族的边缘;
**`性行为计数` 与所有其它量只有 +0.26 ~ +0.51 —— 它是落单的那一个。**

**⇒ 「广度」至少是两个东西:「你对多少种东西有兴趣」与「你实际做过多少事」。**
**而 `#420` 证明 `form` 把这两者推向**相反**的方向 —— 落单的那一个,正是被劈开的那一个。**

## ⚠ 而 guard 26 第一版的框法是错的
判据是「估计的相关 **≥0.6**」,而我把 **0.6 本身**当争议幅度种进去 ——
**在阈值上种,估计落在阈两侧各半,按构造只有 ~50% 检出。那不是功率不足,是阈值的定义。**
(与 `#406b` 的饱和同族:**主量的形状决定了扫描能不能量它**。)
改问「**真值要低于 0.6 多少才判得准**」-> **0.58 就已经 30/30**,**MDE = 0.02**,而实测偏离 **0.34**。
