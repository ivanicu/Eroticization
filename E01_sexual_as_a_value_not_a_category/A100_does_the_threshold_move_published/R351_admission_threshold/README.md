# R351 · 那个准入门槛动不动已发表的数 —— 在方向还认得出来的区间里,不动

`#305a`:`Cmat` 里 `mm.sum() > 200` 的块对准入门槛,能把重现度从 0.68 撬到 0.96。
**那它动不动公开页面上的 `c3 ↔ 羞耻`?**

## 全样本,五个门槛
| 门槛 | 置零格子 | 与发布版的 \|cos\|(c3) | **`c3 ↔ 羞耻`** |
|---:|---:|---:|---:|
| 0 | 9.4% | 0.9988 | **−0.1254** |
| 100 | 9.4% | 0.9988 | **−0.1254** |
| **200(发布口径)** | 9.6% | 1.0000 | **−0.1278** |
| 400 | 22.9% | 0.9466 | **−0.1218** |
| 800 | **53.7%** | **0.3858** | −0.0853 |

**|cos| ≥ 0.95 的门槛(0 / 100 / 200)极差 0.0024;把 400(|cos| 0.9466)也算进来是 0.0060** ——
两者都远小于 `#348` 的嵌套噪声 0.0359。
⚠ 全五个门槛的极差是 **0.0425**,略高于那个噪声 —— **而那 0.0425 全部由门槛 800 一格贡献。**
门槛 800 时矩阵已经掉了一半,方向本身塌到 0.386,那不是「旋钮动了数」,是**估计量坏掉了**。

**⇒ 这不是一个威胁已发表数字的未列旋钮,它是一条退化边界。**

- **正对照**:门槛 0 与 100 给出相同的数(−0.1254 / |cos| 0.9988)。
- **负对照**:`S` 不经过 `C`,`S ↔ 羞耻` 跨五个门槛 **+0.118523 逐位不变**(极差 0.00e+00)。

## ⚠ 而未对齐符号的第一版会印出一个假发现,并且通过全部门
第一版报的是「**跨门槛符号翻转,−0.1278 … +0.1218,极差 0.2497**」——
门槛 400 处 |cos| = 0.9466(方向 95% 一致)**却翻号**。
**那两件事不可能同时为真**:`|cos|` 取了绝对值,而 `eigh` 的特征向量符号是任意的。

> **|cos| 高而派生相关翻号,是「符号没对齐」的签名,不是一个发现。**
> 这是本项目第三次撞上特征向量符号(`R210:73` · 这里)。→ **guard 20**

## 一句关于人的话
「把开放性花在哪里」跟羞耻的那个数,**不取决于我在块对上设多少人的门槛** ——
只要那个门槛还留得下一个认得出来的方向。
