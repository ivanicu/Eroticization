⚠ **FRONTIER**。`#457` 的 NEXT:两个结局彼此无关(−0.0022)却被同一个「何时」同时推动 ——
**它们各自还被什么别的推动?**

## ⚠ ① 事前算术,写在跑之前(`#457` NEXT 的自订规矩)
若两个结局近乎正交,则在一组能解释它们的预测量上,
`Σ r(X,Y₁)·r(X,Y₂)` **应当近乎抵消** -> **「每个量都同时推两个」在算术上近乎不可能**。
⇒ **所以本轮问的不是「有没有只推一个的」(必然有),而是「哪些一致、哪些相反」。**

**而这条预注册没通过它自己的对照:Σ = −0.02544(阈 0.02)。**
原因很具体:**那个恒等式要求预测量彼此正交,而这六个不正交。**
**我把一个近似写成了恒等式,而我自己的对照抓住了它。** 下面的结果**不依赖**它。
