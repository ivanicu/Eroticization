**区间一来,那句话可能变。它变了 —— 往强的方向。**

## ⇒ 措辞升级
以前:「点估计落在中间带 -> **UNVERIFIED**」——**听起来像「我们没测出来」。**
现在:「**整段 95% 区间都在中间带内**」——
**这是测出来了:POWER 与 SUBSTANCE 共享 31–43% 的方差,
既不是一个构念(那要 >49%),也不是确认不同(那要 <20%)。**

> **一个 UNVERIFIED 可以是「仪器不够」,也可以是「答案本来就在中间」。
> 区间是唯一能分开这两者的东西。**
