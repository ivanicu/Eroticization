# R02 · 接缝检验:「ρ 与 z_resid 是同一件事」跨到 S 上还成立吗?

跑之前写死的预测:既然 `corr(z, ρ) = −0.5718` 是**负**的,那么
`corr(z_resid, S)` 应当与 `#129e` 的 `corr(ρ, S) = −0.0404` **符号相反、量级相当**。

## 预测命中

| | 值 | 类别数残差 | 自助展布 |
|---|---:|---:|---:|
| **预测** corr(z_resid, S) ≈ −corr(ρ, S) | **+0.0404** | | |
| **实测** corr(z_resid, S)(匹配后) | **+0.0370** | 0.003 sd | 0.0099 |
| corr(ρ, S)(匹配后) | −0.0404 | 0.003 sd | 0.0102 |
| **判别量** corr(z,S) + corr(ρ,S) | **−0.0034** | | 0.0142(**0.2×**) |

正对照(种植与 S 相关的径向信号):corr(z,S) **−0.3442** · corr(ρ,S) **+0.4982** —— 符号相反,两者都被拉动。
负对照(按人置换 S):+0.0078 · +0.0030。

## 但"一致"不等于"证明了相同"

判别量的 95% 上界是 **0.0317**,而效应本身只有 **0.0370** ——
**这个设计只能排除大于效应 86% 的差异。**

> **判定:CONSISTENT,不是 PROVEN。** 接缝没有裂,但它也没有被焊死。

## 我又用反了一个门

假设本身是**「两者相同」**,而 `require_resolvable_first` 是为**「我要它非零」**设计的 ——
它把想要的结果报成 FAIL,并把整族标 MOOT。

**正确的形式是等价界(TOST 式):差的置信区间必须落在预先指定的边界内。**
已落地为 `lib/gates.py::equivalent_within`(**第九个守卫**),边界必须在跑之前指定。

## 立住的

**「口味越罕见的人,他偏离共享时间表的方向越朝罕见」这句话,不依赖我用哪个统计量。**
用"他最早那个有多罕见"测,和用"他整体上罕见的来得多早"测,对同一个人格特质给出一致的答案
(+0.0370 vs −0.0404,符号按定义相反)。`#129e` 的读法不变,而它现在有了第二个独立测量。
