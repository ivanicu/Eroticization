# R338 · S 在两组里怎么不一样:是块的权重,还是「什么算冷门」本身

`#292b`:漂移在 **S 这个量本身**。S = 「每块内所挑选项的平均稀有度」再跨块平均,
所以这句话可以拆成两句可测的。

## 两层都可分辨,而第二层是决定性的
| | 按性别劈 | 随机劈同样大小 | 差 | |
|---|---:|---:|---:|---:|
| ① **块层载荷谱**(每块与留一总 S 的相关) | +0.7678 | +0.9159 ± 0.0191 | **−0.1480** | 3.9× |
| ② **块内选项流行度**(逐块相关取中位,32 块) | **+0.9039** | **+0.9973 ± 0.0003** | **−0.0935** | **148.6×** |

**随机劈时两组的块内流行度相关是 +0.9973** —— 同一群人随机分成两半,对「哪些选项常见」的估计
几乎完全一致。**而按性别劈只有 +0.9039。**

正对照完美:把组 1 的 8 个块的**人**打乱 →
① 载荷谱 +0.7678 → **+0.5100**(掉了);② 流行度 +0.9039 → **+0.9039**(**分毫不动**,
因为打乱的是人不是选项流行度)。

> **⇒ 注册的 kill 的第二支:两组不只是**不同的块在起作用**,
> 他们**眼里什么算冷门,本身就不一样**。**

## ⚠ 这是对这个项目最底层构造的一条批评
`rar = −log(选项流行度)` 是在**合并样本**上算一次、然后给**每一个人**用的。
本轮说:**这个向量在两组里不是同一个。**
而 **S · D · `atypicality` · 越轨/普通两半 —— 每一个稀有度相关的量都用它。**

⚠ 但**不越写**:这**不**说明那些量是错的;它说明它们的**尺子是合并出来的**,
而合并的尺子在两组里量出来的不是同一件事。

## 一句关于人的话
两组人不是对同一批「冷门的东西」有不同的偏好 ——
**他们眼里什么算冷门,本身就不一样。**
同一群人随机分两半时,这个分歧几乎不存在(0.997);按性别分开时,它是 0.904。
