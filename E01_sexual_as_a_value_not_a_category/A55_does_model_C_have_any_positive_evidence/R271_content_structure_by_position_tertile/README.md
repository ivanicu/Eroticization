# R271 · 内容结构会不会随位置分升高 —— C(递归)的第一个正面检验

**换方向**(`#225` 的 NEXT)。`#179` 之后 B 已经被杀,而 **C 从没被正面问过一次**。
C 有一个 A 与 B 都不预测的具体预测:**若赋值会回流重塑表征,位置维上越强的人,
内容维度应当越有结构**。

## 设计
按 `S`(位置分)分三层,各层各算一次**内容分半信度**(`#165` 同款:块劈半 → 各半算
块内主成分人分 → 跨人相关 → Spearman-Brown),各层各带自己的置换零。
**跑之前写下的最强混杂**:`corr(S, 勾选数) = +0.607`,勾得多的人信度天然更高。
控制:三层内按勾选数卡钳匹配,并排报匹配前后两条曲线。

## 结果
| 层 | n | 信度 | 展布(5 种子) | 置换零 | 净 | 匹配后净 |
|---|---:|---:|---:|---:|---:|---:|
| 低 S | 2,237 | 0.1495 | 0.1031 | 0.0215 | 0.1280 | 0.0452 |
| 中 S | 2,243 | 0.0518 | 0.0231 | 0.0484 | 0.0034 | 0.1470 |
| 高 S | 2,237 | 0.2230 | 0.1022 | 0.0241 | 0.1989 | 0.0382 |

**注册的 kill 没有触发,但它也没有被判成"C 被否"** —— 两个具名缺陷让这一格读不出来:

1. **卡钳匹配没成**:三层勾选数中位 49/69/98 → 匹配后 49/62/69,**仍然递增**。
   最强混杂没有被真正控制住。
2. **分辨率不够**:展布 ±0.10 压过了 0.15 的量本身。正对照要 `g=0.6` 的极强种入
   (0.13 → 0.78)才看得见梯度 —— `#165b`:**对照的强度必须匹配它所判之物的可观测量级**,
   这个正对照比可观测量强了一个数量级,它证明的是"管道通",不是"这一格有分辨率"。

⇒ **`UNVERIFIED`,而这不是无罪释放。**

## 但随后的梯度检查找到了真正的原因(`results/sign_probe.py`)
`np.linalg.eigh` 返回的特征向量**符号是任意的**,而 `R210:73` 把 32 个块的 `Z@pc`
**直接相加**,从没对齐符号。实测 32 个块:**17 个 PC1 平均载荷为正,15 个为负。**

> **内容分是一个 ±breadth 的相消混合。**

而且 **25/32 个块的 PC1 载荷全同号** —— 这些块的第一主成分本来就是"愿意勾多少"
(breadth),不是"内容口味"。两件事都直指同一个地方:**这把尺子本身没装对。**
