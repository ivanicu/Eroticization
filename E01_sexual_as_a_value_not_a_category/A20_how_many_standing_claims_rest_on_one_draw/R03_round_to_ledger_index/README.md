- `#143` 重跑 `A02/R10` 去"重新定价"一条 `Entry 24` 在 **118 条之前**就已作废的声明

**犯三次之后,应该由工具而不是由纪律来防。**

## `tools/round_status.py`

`readme_ledger_audit.py` 做 README → 账本;这个做**反方向**:轮次 → 账本,
并把**最后一条提到它的条目**顶出来。

关键在于它的**兄弟轮次检测** —— 而那一条是照着骗过我的那一格调出来的:
`Entry 101` 的正文写的是**裸 `R15`**,不是 `E01·A11·R15`,所以按引用格式匹配抓不到它。
改成扫**这一轮自己那条条目的正文**,找里面提到的**兄弟轮次** + 取代/修正类词汇。

现在查 `A11/R14` 会直接打出:

```
A11/R14   [101]   101   1   ⚠ 必读
     └─ Entry 101 正文提到兄弟轮次 ['R15']
     └─ `R15`'s fix is not a better regression: **curveball preserves each person's pick count exactly**
```

**这正是上一轮会救我的那句话。**
